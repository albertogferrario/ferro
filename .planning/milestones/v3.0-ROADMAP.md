## Milestone Summary

**Key Decisions:**
- Serde tagged enum for Component (`type` field) -- clean JSON serialization
- Serde untagged enum for Visibility -- clean `{"and": [...]}` syntax
- ComponentNode wraps Component via flatten -- shared key/action/visibility
- ButtonVariant aligned to shadcn/ui (6 variants) -- CVA pattern consistency
- Simple slash-separated paths (not full JSONPath) -- trivial implementation
- url field added directly to Action struct -- simpler than separate type
- Callback-based resolver Fn(&str) -> Option<String> -- keeps crate decoupled
- GET actions wrap in `<a>`, non-GET render as-is -- only safe HTTP method for links
- Modal uses details/summary for no-JS progressive enhancement
- All layouts/partials/registry in single layout.rs module -- simpler than separate files
- Blocking reqwest for Anthropic API in CLI -- CLI main is synchronous
- Component catalog as hardcoded const string -- fast, no file I/O
- Sonnet default instead of Opus -- ~5x cost reduction for generation
- json_ui_generate returns context, not AI output -- consuming agent IS the LLM

**Issues Resolved:**
- None significant -- clean execution across all 10 phases

**Issues Deferred:**
- ferro-storage unimplemented trait methods (pre-existing, unrelated)
- Flaky shared state test (pre-existing, unrelated)

**Technical Debt Incurred:**
- COMPONENT_CATALOG duplicated in MCP crate (cannot share across workspace)
- Tabs SSR renders only default_tab content (tab switching requires JS)
