## Tech Debt

2 items across 2 phases. No blockers.

### Phase 107: Component Details
- **BELL_SVG duplication:** `BELL_SVG` const in `render.rs` is private. `layout.rs` contains an identical inline SVG literal instead of importing via `pub(crate)`. Visually identical today but creates a two-place maintenance burden if the bell icon changes.

### Phase 103: Surface Elevation
- **SRF-06 contrast pair 6:** Dark mode primary-on-background measured at 4.45:1 (0.05 below WCAG AA 4.5:1). Accepted as design trade-off — lowering primary L further would break pair 5 (primary-foreground on primary). Documented in Phase 103 SUMMARY decision log.
