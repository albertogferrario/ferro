## Milestone Summary

**Key Decisions:**
- #[serial] over per-test MetricsStore refactor (minimal change, same safety)
- S3 facade returns S3Driver that errors on use (avoids panic at initialization)
- Instructional output for provider/routes instead of auto-modify (safer for custom code)
- 401 via FrameworkError::domain not Unauthorized (401 is authentication, 403 is authorization)
- AuthUser counts as one FromRequest param per handler (existing framework constraint)
- serde_json preserve_order enabled (ResourceMap needs insertion-order field output)
- Relative URLs for pagination links (works behind reverse proxies)
- OnceLock<DashMap> for rate limiter registry (static, thread-safe)
- Fail-open on cache errors and missing limiters (availability over strictness)
- WS upgrade intercept before middleware chain (upgrade needs raw hyper Request)
- Always include error hints (developer-facing APIs, not user-facing endpoints)

**Issues Resolved:**
- Test isolation failures from global MetricsStore (fixed with serial_test)
- Env var contamination in queue tests (fixed with EnvGuard drop pattern)
- S3 driver panics on configuration (replaced with NotImplemented errors)
- Inconsistent JSON error response key names (normalized to "message")
- MCP command list incomplete (updated from 32 to 40 commands)
- Outdated broadcasting docs referencing non-existent APIs (complete rewrite)

**Issues Deferred:**
- COMPONENT_CATALOG duplication across crates (cannot share code across workspace)

**Technical Debt Incurred:**
- TCP loopback test helper for constructing hyper Request (no public constructor)
- serde_json preserve_order is a crate-wide feature flag
