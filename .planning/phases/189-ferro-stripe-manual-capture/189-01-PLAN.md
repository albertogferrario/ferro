<objective>
Add `CheckoutBuilder::manual_capture()` so a consumer can authorize card funds at checkout without charging (booking deposit hold), and ensure manual capture composes correctly with Connect `destination()` charges.

This plan delivers STRIPE-MC-01 (the builder flag sets `capture_method=manual` in payment mode only) and STRIPE-MC-04 (manual capture composes with `destination()` — one merged `payment_intent_data` carries both). It implements D-01 (runtime pre-flight mode guard, no typestate builder) and D-08 (builder-level composition test).

Purpose: gestiscilo-it v6.3 booking deposits need a checkout that authorizes funds without immediate charge, and that still works when routing to a connected account.
Output: extended `error.rs` (1 new variant) + extended `checkout.rs` (field + setter + guard + merged construction + 3 unit tests).
</objective>
