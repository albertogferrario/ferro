**field_map.rs** — Two public functions mapping FieldMeaning to JSON-UI component JSON:

1. `pub fn field_to_display(field: &FieldDef) -> serde_json::Value` — Maps FieldMeaning to display (read-only) component JSON. Exhaustive match on all 18 FieldMeaning variants:

| FieldMeaning | Component JSON | Notes |
|---|---|---|
| Identifier | `{"type": "Text", "content": "", "element": "span", "key": "{name}-display"}` with data_path | Muted/secondary |
| ForeignKey | Return `serde_json::Value::Null` | Hidden — resolved via relationship |
| EntityName | `{"type": "Text", "content": "", "element": "span", "key": "{name}-display"}` with data_path | Bold/primary text |
| Email | `{"type": "Text", ...}` with data_path | |
| Phone | `{"type": "Text", ...}` with data_path | |
| Url | `{"type": "Text", ...}` with data_path | |
| ImageUrl | `{"type": "Avatar", "src": "", "alt": "", "key": "{name}-avatar"}` with data_path for src | |
| Money | `{"type": "Text", ...}` with data_path | |
| Percentage | `{"type": "Progress", "value": 0, "key": "{name}-progress"}` with data_path | |
| Quantity | `{"type": "Text", ...}` with data_path | |
| Status | `{"type": "Badge", "text": "", "variant": "default", "key": "{name}-badge"}` with data_path | |
| Category | `{"type": "Badge", "text": "", "variant": "secondary", "key": "{name}-badge"}` with data_path | |
| Boolean | `{"type": "Badge", "text": "", "variant": "outline", "key": "{name}-badge"}` with data_path | |
| FreeText | `{"type": "Text", ...}` with data_path | Multi-line |
| CreatedAt | `{"type": "Text", ...}` with data_path | |
| UpdatedAt | `{"type": "Text", ...}` with data_path | |
| DateTime | `{"type": "Text", ...}` with data_path | |
| Sensitive | Return `serde_json::Value::Null` | Never displayed in read-only |
| Custom(_) | `{"type": "Text", ...}` with data_path | Default treatment |

Use `serde_json::json!()` macro for construction. Add `"data_path": format!("/data/{}", field.name)` to each component for data binding. Add `"label": field_display_name(&field.name)` where appropriate.

2. `pub fn field_to_input(field: &FieldDef) -> serde_json::Value` — Maps FieldMeaning to input component JSON for forms. Exhaustive match:

| FieldMeaning | Component JSON |
|---|---|
| Identifier | `{"type": "Input", "input_type": "hidden", ...}` |
| ForeignKey | `{"type": "Select", ...}` with empty options (populated at integration time) |
| EntityName | `{"type": "Input", "input_type": "text", "required": true, ...}` |
| Email | `{"type": "Input", "input_type": "email", ...}` |
| Phone | `{"type": "Input", "input_type": "tel", ...}` |
| Url | `{"type": "Input", "input_type": "url", ...}` |
| ImageUrl | `{"type": "Input", "input_type": "url", ...}` |
| Money | `{"type": "Input", "input_type": "number", "step": "0.01", ...}` |
| Percentage | `{"type": "Input", "input_type": "number", "min": "0", "max": "100", ...}` |
| Quantity | `{"type": "Input", "input_type": "number", ...}` |
| Status | `{"type": "Select", ...}` with empty options |
| Category | `{"type": "Select", ...}` with empty options |
| Boolean | `{"type": "Switch", ...}` |
| FreeText | `{"type": "Input", "input_type": "textarea", ...}` |
| CreatedAt | `{"type": "Input", "input_type": "text", "disabled": true, ...}` (read-only in forms) |
| UpdatedAt | `{"type": "Input", "input_type": "text", "disabled": true, ...}` (read-only in forms) |
| DateTime | `{"type": "Input", "input_type": "text", ...}` (JSON-UI InputType has no datetime-local, use text) |
| Sensitive | `{"type": "Input", "input_type": "password", ...}` with NO data_path (never pre-filled) |
| Custom(_) | `{"type": "Input", "input_type": "text", ...}` |

Every input includes: `"key"`, `"name": field.name`, `"label": field_display_name(&field.name)`, `"data_path"` (except Sensitive), `"required": field.required`.

3. `pub fn field_to_column(field: &FieldDef) -> serde_json::Value` — Maps FieldMeaning to a Table column definition JSON:
   ```json
   {"key": "field_name", "label": "Field Name", "format": "currency|date|datetime|boolean|null"}
   ```
   Use ColumnFormat mapping: Money→"currency", CreatedAt/UpdatedAt/DateTime→"datetime", Boolean→"boolean", Date→"date". Others → no format field.

**relationship_map.rs** — One public function:

| Nested | `{"type": "Table", ...}` with columns from target (simplified — just name column) and data_path |
| Hidden | Return `serde_json::Value::Null` |
