Atomic flip SQL (SET expressions read pre-update values on both backends):
  SQLite:   INSERT INTO deployment_pointers (owner_key, deployment_id, previous_deployment_id, updated_at)
            VALUES (?1, ?2, NULL, ?3)
            ON CONFLICT (owner_key) DO UPDATE SET
              previous_deployment_id = deployment_id, deployment_id = ?2, updated_at = ?3
            RETURNING previous_deployment_id
  Postgres: ... VALUES ($1, $2, NULL, NOW())
            ON CONFLICT (owner_key) DO UPDATE SET
              previous_deployment_id = deployment_pointers.deployment_id, deployment_id = $2, updated_at = NOW()
            RETURNING previous_deployment_id

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| consumer → Deployments API | `owner_key`, `source_ref`, `artifact_location` strings + `deployment_id` i64 cross into SQL execution |
| concurrent callers → deployment_pointers | Two promotes may race on the same pointer row |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-186-04 | Tampering (SQL injection) | promote.rs / deployment.rs raw SQL | mitigate | All caller input bound via `Statement::from_sql_and_values` with `Value::String`/`Value::BigInt` — never string-interpolated. Acceptance criteria grep for `Statement::from_sql_and_values`. Severity: high vector, fully mitigated → does not block. |
| T-186-05 | Tampering (torn state) | atomic pointer flip | mitigate | Single UPDATE inside `conn.begin()` transaction; DB atomicity serializes concurrent promotes; race test is the proof artifact (no torn state assertion). Severity: medium, mitigated. |
| T-186-06 | Denial of Service (stale rollback) | promote guard | mitigate | promote rejects rows with `artifact_deleted_at` set (Error::ArtifactDeleted), preventing promotion to a deployment whose artifacts were GC'd. Severity: low, mitigated. |
| T-186-07 | Elevation of Privilege (promote non-ready) | promote guard | mitigate | promote rejects non-`ready` status (Error::NotReady) — a draft/failed build cannot go live. Severity: low, mitigated. |
</threat_model>
