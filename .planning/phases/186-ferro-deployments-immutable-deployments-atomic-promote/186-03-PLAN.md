| Threat ID | Category | Component | Disposition | Mitigation Plan |

Document in the crate docs (Plan 04) and storage.rs rustdoc that the consumer owns authz; preview URLs are not a security boundary. Severity: low, accepted by design. |
| T-186-09 | Denial of Service | unbounded artifact size | accept | `byte_size` is recorded but NOT enforced here; size limits are a consumer/storage-tier concern. Documented as out-of-scope for this crate. Severity: low, accepted. |
| T-186-10 | Tampering (path traversal) | DeploymentStorage path arg | mitigate | Paths are prefixed with `deployments/{deployment_id}/`; ferro-storage object keys are not filesystem paths in the S3 driver. Note the prefix bounds the key namespace per deployment. Severity: low, mitigated by prefix scoping. |
