<objective>
Rename the ferro-json-ui type / render / touch-constant surface from POS-domain
names to domain-neutral structural names (part 1 of the SC-0 vocabulary
neutralization). This plan owns the compile-atomic core: the Rust struct and
`render_*` renames plus the `POS_*` constant renames must land together because
`render/atoms.rs` references both the renamed types AND the renamed constants.

Purpose: Establish the FINAL public vocabulary before any Phase 255 runtime module
or Phase 256 renderer is written, so downstream code never targets a name that
later changes.

Output: `ProductTileProps`->`TileProps` (field `product_id`->`item_id`),
`ProductGridProps`->`TileGridProps`, `CartPanelProps`->`SelectionPanelProps`
(consumer-specific `show_staff`/`show_people` REMOVED), `CategoryNavProps`->
`FilterTabsProps`, `render_product_tile`->`render_tile`,
`data-product-categories`->`data-filter-tokens`, and the six `POS_*` constants
renamed without the domain prefix (class VALUE strings unchanged). No behavioral
change beyond the attribute-name rename; component count stays 47.
</objective>
