**Update authentication docs** in `docs/src/features/authentication.md`:

Add a new section after the existing "Accessing the Authenticated User" section titled "## Handler Extractors". Content should cover:

1. **AuthUser<T>** — Inject the authenticated user as a handler parameter. Returns 401 if not authenticated. Show example:
```rust
use ferro::{handler, AuthUser, Response, HttpResponse};
use crate::models::users;

#[handler]
pub async fn profile(user: AuthUser<users::Model>) -> Response {
    Ok(HttpResponse::json(serde_json::json!({
        "id": user.id,
        "name": user.name,
        "email": user.email
    })))
}
```

2. **OptionalUser<T>** — Same but returns `None` for guests. Show example:
```rust
use ferro::{handler, OptionalUser, Response, HttpResponse};
use crate::models::users;

#[handler]
pub async fn home(user: OptionalUser<users::Model>) -> Response {
    let greeting = match user.as_ref() {
        Some(u) => format!("Welcome back, {}!", u.name),
        None => "Welcome, guest!".to_string(),
    };
    Ok(HttpResponse::json(serde_json::json!({"greeting": greeting})))
}
```

3. **Deref behavior** — Note that `AuthUser<T>` implements `Deref<Target=T>` so you access fields directly: `user.name` not `user.0.name`.

4. **Limitation** — Note that AuthUser/OptionalUser count as a FromRequest parameter, so they cannot be combined with FormRequest types in the same handler. If both are needed, use Request and call Auth::user_as::<T>() manually.

Keep the existing documentation sections intact. The new section complements, not replaces, the Auth facade documentation.
