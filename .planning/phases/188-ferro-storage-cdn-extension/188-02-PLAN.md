    PurgeApi impl:
    ```rust
    #[async_trait]
    impl PurgeApi for DoSpacesCdn {
        async fn purge(&self, paths: &[String]) -> Result<(), Error> {
            if paths.is_empty() {
                return Ok(()); // Pitfall 5
            }
            let Some(id) = &self.config.endpoint_id else {
                tracing::info!("DO_SPACES_CDN_ID not set — CDN purge is a no-op");
                return Ok(()); // criterion 3
            };
            if self.config.api_token.is_empty() {
                return Err(Error::cdn("DIGITALOCEAN_ACCESS_TOKEN not set"));
            }
            let url = format!("{}/v2/cdn/endpoints/{}/cache", self.api_base(), id);
            let mut batches = 0usize;
            for chunk in paths.chunks(BATCH_SIZE) {
                self.throttle().await;
                let resp = self.client
                    .delete(&url)
                    .bearer_auth(&self.config.api_token)
                    .json(&serde_json::json!({ "files": chunk }))
                    .send()
                    .await
                    .map_err(|e| Error::cdn(e.to_string()))?;
                if resp.status().as_u16() != 204 {
                    let status = resp.status().as_u16();
                    let body = resp.text().await.unwrap_or_default();
                    return Err(Error::cdn(format!("DO CDN purge status {status}: {body}")));
                }
                batches += 1;
            }
            tracing::info!("purged {} paths in {} request(s)", paths.len(), batches);
            Ok(())
        }
    }
    ```
    SECURITY: the tracing::info! line logs counts only — never the token, never the full URL with credentials. Do not add a Debug-print of self.config anywhere.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| ferro-storage → DO API | Outbound HTTPS DELETE carrying the DO bearer token; the only network egress in the phase |
| consumer → purge(paths) | Semi-trusted relative paths placed into a JSON body |
| env → DoSpacesCdnConfig::from_env() | DIGITALOCEAN_ACCESS_TOKEN + DO_SPACES_CDN_ID read from process env |
| test → api_base override | pub(crate), test-only; never reachable from untrusted input |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-188-04 | Information Disclosure | DIGITALOCEAN_ACCESS_TOKEN in Debug/logs | mitigate | DoSpacesCdnConfig does NOT derive Debug — a manual impl prints "<redacted>" for api_token; the only tracing line logs counts, never the token or auth header. Asserted by the `"<redacted>"` grep + the manual-Debug grep in Task 1 acceptance. |
| T-188-05 | Tampering / Injection | consumer-supplied purge paths | mitigate | Paths go into the body via `serde_json::json!({"files": chunk})` — serde escapes them. No shell, no manual string interpolation of paths into the URL or body. The URL contains only the trusted env CDN id. |
| T-188-06 | Spoofing / SSRF | API base endpoint | mitigate | Production base is the fixed constant `https://api.digitalocean.com`; the `api_base` override is `pub(crate)` and only set in tests. CDN id comes from trusted env. No untrusted input constructs the request URL. |
| T-188-07 | Info Disclosure (transport) | token over the wire | mitigate | reqwest with rustls-tls (Plan 01 dep); HTTPS only; cert verification left at default (never disabled). |
| T-188-08 | Denial of Service (accidental) | wrong-endpoint purge when unconfigured | mitigate | Missing DO_SPACES_CDN_ID → logged no-op returning Ok(()) (criterion 3); no request is ever sent to a wrong/empty endpoint. Asserted by do_adapter_noop_missing_id (.expect(0)). |
| T-188-09 | Denial of Service | exceeding DO's 5 req/10s | mitigate | Internal sliding-window throttle (tokio::sync::Mutex<VecDeque<Instant>>) serializes; do_adapter_throttle_serializes asserts the 6th request waits. |

block-on-high: all high-severity items (token leak T-188-04, SSRF T-188-06) are mitigated with grep-asserted controls. No unmitigated high severity → gate passes.
