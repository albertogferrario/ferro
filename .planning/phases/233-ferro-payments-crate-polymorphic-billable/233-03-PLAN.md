<objective>
Implement the six lifecycle methods on the `payment_intents` entity:
`create_reserved`, `mark_paid`, `mark_released`, `mark_refunded`, `find_active_for`,
`find_by_stripe_session`. State transitions use `ferro_orm::GuardedUpdate` atomic
conditional UPDATEs so a stale precondition is a no-op (0 rows) rather than a
lost-update race.

Purpose: this completes the phase's data-layer contract. The guarded-update no-op
semantics are the by-construction race resolution the webhook/reaper phases (235/236)
rely on ("second writer no-ops" — D-09) without a read-then-write window.

Output: `intent/lifecycle.rs` (with inline lifecycle tests); updated `intent/mod.rs`
and `lib.rs` re-exports.
</objective>

GuardedUpdate builder (ferro-orm/src/guarded.rs):
```rust
GuardedUpdate::new(entity)                       // E: EntityTrait
  .filter(col.eq(val))                            // IntoCondition, AND-combined, repeatable
  .set_value(col, Value)                          // literal
  .set_expr(col, SimpleExpr)                      // expression
  .exec_at_most_one(&conn) -> Result<bool, GuardedError>  // Ok(true)=1 row, Ok(false)=0 rows no-op, Err(TooManyRows)/Err(EmptyUpdate)/Err(Db)
  .exec_one(&conn)         -> Result<(), GuardedError>     // Err(NoRowsAffected) on 0 — do NOT use for lifecycle
```
USE exec_at_most_one for all transitions (Pitfall 3 — 0 rows is the designed no-op).
EVERY transition MUST call .set_value at least once (Pitfall 1 — empty builder = GuardedError::EmptyUpdate). The status column is always set, so this is naturally satisfied.

Value variants needed: Value::String(Some(Box::new("paid".to_string()))) for the status TEXT column; chrono timestamp via Value (use sea_orm's chrono Value variant, e.g. Value::ChronoDateTimeUtc(Some(Box::new(now))) — verify the exact variant name against the installed sea-orm chrono Value enum if it differs).

GuardedError -> PaymentError mapping (no #[from] in 233 — map manually per PATTERNS.md "Error Handling"):
GuardedError::Db(e) -> PaymentError::Db(e); other GuardedError variants -> PaymentError::Db(sea_orm::DbErr::Custom(e.to_string())).

Transition source-status guards (D-09 / design-spec status lifecycle reserved|paid|released|failed|refunded):
- mark_paid:     filter Status == Reserved  -> set Status=paid, PaidAt=now
- mark_released: filter Status == Reserved  -> set Status=released, ReleasedAt=now
- mark_refunded: filter Status == Paid      -> set Status=refunded, RefundedAt=now
(create_reserved: plain insert; find_active_for: Status is_in [Reserved, Paid]; find_by_stripe_session: StripeSessionId == session_id.)
