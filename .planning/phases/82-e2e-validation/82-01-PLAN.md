    Follow the exact patterns from `ferro-cli/src/commands/make_api.rs` templates:

    1. **Migration** (`app/src/migrations/m20260228_create_api_keys_table.rs`):
       - Create table `api_keys` with columns: id (pk, auto-increment), name (string, not null), prefix (string_len(16), not null), hashed_key (string_len(64), not null), scopes (text, nullable), last_used_at (timestamp nullable), expires_at (timestamp nullable), revoked_at (timestamp nullable), created_at (timestamp not null, default current_timestamp).
       - Add index `idx_api_keys_prefix` on prefix column.
       - Copy the exact schema from `generate_api_key_migration()` in make_api.rs.

    2. **Register migration** (`app/src/migrations/mod.rs`):
       - Add `mod m20260228_create_api_keys_table;` and include in Migrator::migrations() vec.

    3. **Entity** (`app/src/models/entities/api_keys.rs`):
       - SeaORM entity with DeriveEntityModel matching the migration columns.
       - Use `DateTimeUtc` for timestamp fields (matching make_api.rs `generate_api_key_model()`).
       - Add to `app/src/models/entities/mod.rs`.

    4. **Model** (`app/src/models/api_key.rs`):
       - Re-export entity: `pub use super::entities::api_keys::*;`
       - Add `pub type ApiKey = Model;`
       - Add `Model::query()` method returning `QueryBuilder::new()`.
       - Follow exact pattern from `generate_api_key_model()`.
       - Add to `app/src/models/mod.rs`.

    5. **Provider** (`app/src/providers/api_key_provider.rs`):
       - Implement `ApiKeyProvider` trait with `verify_key()` method.
       - Query by prefix, check revocation and expiry, verify hash with `verify_api_key_hash()`.
       - Parse scopes from JSON string to `Vec<String>`.
       - Follow exact pattern from `generate_api_key_provider()`.
       - Add to `app/src/providers/mod.rs`.

    6. **Bootstrap** (`app/src/bootstrap.rs`):
       - Add `bind!(dyn ApiKeyProvider, ApiKeyProviderImpl);` after the UserProvider binding.
       - Import `ApiKeyProvider` from ferro and `ApiKeyProviderImpl` from providers.
  </action>

  <action>
    Follow the `ferro make:api` output patterns from make_api.rs:

    1. **API module** (`app/src/api/mod.rs`):
       - Declare submodules: `pub mod docs; pub mod routes; pub mod user_api;`

    2. **User API handlers** (`app/src/api/user_api.rs`):
       - Follow `generate_api_controller()` pattern from make_api.rs.
       - `index`: GET list with pagination — use `Model::query().paginate(page, per_page).all().await`, return JSON array with PaginationMeta. Use the UserResource for transformation.
       - `show`: GET by id — `Model::find_by_id(id).await`, return JSON or 404.
       - `store`: POST create — parse JSON body, create ActiveModel, insert, return 201 with created record.
       - `update`: PUT by id — parse JSON body, find record, update fields conditionally (if let Some pattern), save, return updated.
       - `destroy`: DELETE by id — find record, delete, return 204 No Content.
       - Each handler uses `#[handler]` macro and returns `Response`.
       - Import from `crate::models::users` (Entity, Model, Column, ActiveModel).

    3. **Docs handlers** (`app/src/api/docs.rs`):
       - Follow `generate_api_docs()` pattern exactly.
       - `api_docs()` handler serving ReDoc HTML via `openapi_docs_response()`.
       - `openapi_json()` handler serving JSON spec via `openapi_json_response()`.
       - Use `OpenApiConfig` with title from `ferro::env("APP_NAME", "API".to_string())`.
       - api_prefix: `"/api/"`.

    4. **API routes** (`app/src/api/routes.rs`):
       - Follow `generate_api_routes()` pattern.
       - `pub fn api_routes() -> GroupDef` returning group at `/api/v1` with CRUD routes for users.
       - Apply `ApiKeyMiddleware::new()` and `Throttle::named("api")`.
       - Route names: `api.users.index`, `api.users.store`, `api.users.show`, `api.users.update`, `api.users.destroy`.

    5. **Main module** (`app/src/main.rs`):
       - Add `mod api;` declaration alongside the other module declarations.

    6. **Root routes** (`app/src/routes.rs`):
       - Import `crate::api::routes::api_routes` and `crate::api::docs::docs_routes`.
       - Add `api_routes().into()` and `docs_routes().into()` to the routes! macro.
       - Remove the existing `/api/users` route from the routes! macro (line 39-41) to avoid conflicts. The new API routes replace it.
  </action>
