<objective>
Implement the two image transforms: `image_transcode` (pure-Rust `image` decode + Lanczos3 resize +
`ravif` AVIF encode + JPEG fallback, bounded by a `rayon` thread pool default ≤2, deterministic
`{stem}-{width}w.{ext}` variant naming, never upscaling) and `responsive_images` (lol_html rewriter
turning `<img src>` into `<picture><source type="image/avif" srcset=…><img …></picture>` by
discovering the emitted variants in the asset set). Lands the SC-3 test (variants, no-upscale,
bounded concurrency).

Purpose: Delivers ASSET-F-03 (AVIF+JPEG responsive variants, zero C deps, bounded ≤2) and completes
ASSET-F-04 (responsive_images rewriter). The whole-collection Transform model lets responsive_images
discover variants statelessly — no shared mutable pipeline context.
Output: Two compiling, tested image transforms; the seven-transform built-in set is complete.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| caller → image_transcode | Untrusted tenant image bytes decoded by the `image` crate (potential decode bomb) |
| caller → responsive_images | Untrusted tenant HTML parsed by lol_html |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-187-09 | Denial of Service | Image decode bomb / oversized image → OOM | mitigate | `image::load_from_memory` returns Result (no `.unwrap()`); the rayon pool bounds concurrent encodes to default ≤2 (D-09) so peak memory stays bounded on a 512MB instance; the no-upscale width filter caps output dimensions to <= source. Document the max-concurrency guard in the README (Plan 04). |
| T-187-10 | Denial of Service | Malformed image panics the encode thread | mitigate | decode + ravif encode return Result; errors surface as Error::transform; CPU work runs under the consumer's spawn_blocking (D-08), isolating from the async executor |
| T-187-11 | Denial of Service | responsive_images lol_html parser panic on malformed HTML | mitigate | rewriter.write/end return Result mapped to Error::transform; no `.unwrap()` |
| T-187-12 | Tampering | Upscaled variants waste bandwidth / leak source-size assumptions | mitigate | width filter `w <= src.width()` runs FIRST (Pitfall 4); SC-3 light test asserts a narrow source emits zero variants |
</threat_model>
