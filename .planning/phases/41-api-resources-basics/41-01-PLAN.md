- `ResourceMap` struct with `fields: Vec<(String, ResourceValue)>` where `ResourceValue` is a private enum `{ Present(serde_json::Value), Missing }`.
- `ResourceMap::new() -> Self` — empty builder.
- `.field(key: &str, value: impl Into<serde_json::Value>) -> Self` — always includes field.
- `.when(key: &str, condition: bool, value: impl FnOnce() -> serde_json::Value) -> Self` — includes field only when condition is true. When false, field is simply not added (no sentinel).
- `.unless(key: &str, condition: bool, value: impl FnOnce() -> serde_json::Value) -> Self` — opposite of when.
- `.merge_when(condition: bool, fields: impl FnOnce() -> Vec<(&str, serde_json::Value)>) -> Self` — conditionally merge multiple fields.
- `.when_some<T: serde::Serialize>(key: &str, value: &Option<T>) -> Self` — includes field only if Option is Some.
- `.build() -> serde_json::Value` — finalize into a JSON object, stripping Missing values. Use `serde_json::Map` for ordered output preserving insertion order.

Implement `Default` for `ResourceMap` (delegates to `new()`).

`mod.rs`:
- `pub mod resource;`
- `pub mod resource_map;`
- Re-export public types: `pub use resource::Resource;` and `pub use resource_map::ResourceMap;`

Do NOT implement `Into<serde_json::Value>` for types — the `field()` method should accept `impl Into<serde_json::Value>` which serde_json already provides for primitives. For complex types, callers use `serde_json::json!()`.

  <action>
Create `resource.rs` with the `Resource` trait:

```rust
pub trait Resource {
    /// Transform this into a JSON value for API responses.
    /// Request is available for context-dependent field selection (auth, roles, etc).
    fn to_resource(&self, req: &Request) -> serde_json::Value;

    /// Return a JSON HTTP response with the resource data.
    fn to_response(&self, req: &Request) -> HttpResponse {
        HttpResponse::json(self.to_resource(req))
    }

    /// Return a JSON HTTP response wrapped in {"data": ...} envelope.
    fn to_wrapped_response(&self, req: &Request) -> HttpResponse {
        HttpResponse::json(serde_json::json!({"data": self.to_resource(req)}))
    }

    /// Return a wrapped response with additional top-level fields merged.
    /// Example: resource.to_response_with(&req, json!({"meta": {"version": "v1"}}))
    /// Output: {"data": {...}, "meta": {"version": "v1"}}
    fn to_response_with(&self, req: &Request, additional: serde_json::Value) -> HttpResponse {
        let mut response = serde_json::json!({"data": self.to_resource(req)});
        if let (Some(obj), Some(add)) = (response.as_object_mut(), additional.as_object()) {
            for (k, v) in add {
                obj.insert(k.clone(), v.clone());
            }
        }
        HttpResponse::json(response)
    }
}
```
