Create `ferro-cli/src/commands/make_resource.rs` implementing `ferro make:resource UserResource`.

**Command behavior:**
- Accepts a resource name argument (e.g., `UserResource`, `PostResource`)
- If name doesn't end with "Resource", append it (e.g., `User` → `UserResource`)
- Creates `src/resources/{snake_name}.rs` (e.g., `src/resources/user_resource.rs`)
- Optionally accepts `--model entities::users::Model` to add the model attribute

**Template** (add to `ferro-cli/src/templates/mod.rs`):
```rust
pub const RESOURCE_TEMPLATE: &str = r#"use ferro::{ApiResource, Resource, ResourceMap, Request};
use serde_json::json;

#[derive(ApiResource)]
{model_attribute}pub struct {name} {
    pub id: i32,
    // Add fields from your model here
    // #[resource(rename = "display_name")]
    // pub name: String,
    // #[resource(skip)]
    // pub password_hash: String,
}
"#;
```

Where `{model_attribute}` is either empty or `#[resource(model = "{model_path}")]\n` depending on --model flag.

**Registration:**
- Add `pub mod make_resource;` in `ferro-cli/src/commands/mod.rs`
- Add the command to CLI dispatch in `ferro-cli/src/main.rs` (follow pattern of make_controller, make_auth, etc.)
- Print success message: "Resource created: src/resources/{snake_name}.rs"
- Print instruction: "Add `pub mod {snake_name};` to src/resources/mod.rs"

Follow existing patterns in `make_controller.rs` for file creation, directory existence checks, and snake_case conversion.

Create `app/src/resources/user_resource.rs`:
```rust
use ferro::{ApiResource, Resource};

#[derive(ApiResource)]
#[resource(model = "crate::models::entities::users::Model")]
pub struct UserResource {
    pub id: i32,
    pub name: String,
    pub email: String,
}
```

Only include id, name, email — exclude password_hash, remember_token, timestamps. This demonstrates the field selection use case.

Add `pub mod resources;` to `app/src/main.rs` (check where other modules are declared).
