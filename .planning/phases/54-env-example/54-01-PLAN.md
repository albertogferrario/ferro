   - `REDIS_URL` — full Redis URL, takes precedence over host/port/password/database (queue, cache, broadcast all check this)
   - `CACHE_TTL` — default TTL in seconds, default 3600
   - `CACHE_MEMORY_CAPACITY` — max entries for memory store, default 10000
   - `QUEUE_PREFIX` — Redis key prefix, default "ferro_queue"
   - `QUEUE_BLOCK_TIMEOUT` — seconds to block waiting for jobs, default 5

   - `FILESYSTEM_LOCAL_ROOT` — root path for local disk, default "./storage"
   - `FILESYSTEM_LOCAL_URL` — public URL for local files (optional)
   - `FILESYSTEM_PUBLIC_ROOT` — root path for public disk, default "./storage/public"
   - `FILESYSTEM_PUBLIC_URL` — public URL for public files, default "/storage"
   - `BROADCAST_MAX_SUBSCRIBERS` — per channel, default 100
   - `BROADCAST_MAX_CHANNELS` — total, default 1000
   - `BROADCAST_HEARTBEAT_INTERVAL` — seconds, default 10
   - `BROADCAST_CLIENT_TIMEOUT` — seconds, default 30
   - `BROADCAST_ALLOW_CLIENT_EVENTS` — boolean, default false
   - `SLACK_WEBHOOK_URL` — Slack notification webhook (optional)
   - `MAIL_ENCRYPTION` — "tls" or "none", default "tls"
   - `FERRO_DEBUG_ENDPOINTS` — enable debug routes, default from APP_DEBUG
   - `FERRO_COLLECT_METRICS` — enable metrics collection, default false
   - `FERRO_AI_MODEL` — override AI model for CLI, default "claude-sonnet-4-5"

3. **Vars to FIX** (present but inaccurate):
   - `AWS_ENDPOINT` → `AWS_URL` (code uses `AWS_URL`)
   - Session `SESSION_SECURE` default is `true` in code, template says `false`
   - `MAIL_FROM_NAME` default should match `APP_NAME` pattern
