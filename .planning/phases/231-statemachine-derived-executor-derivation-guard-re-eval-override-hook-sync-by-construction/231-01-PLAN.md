    Define the serializable plan (schema-only, NO closures, derives matching the crate convention):
    ```rust
    #[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize, JsonSchema)]
    pub struct TransitionPlan {
        /// ActionDef.name that produced this plan.
        pub action: String,
        /// = ActionDef.transition_trigger; the StateMachine event name.
        pub event: String,
        /// Every Transition.from carrying this event (multi-source aware, Pitfall 2).
        pub from_states: Vec<String>,
        /// Transition.to — the single target. Replaces the hand-written `match`.
        pub to_state: String,
        /// Transition.guard, if any — re-checked LIVE at execution (EXEC-02, Plan 02).
        #[serde(skip_serializing_if = "Option::is_none")]
        pub guard: Option<String>,
        /// Transition.actions ∪ ActionDef.effects — override-hook inputs (Plan 02).
        #[serde(default, skip_serializing_if = "Vec::is_empty")]
        pub effects: Vec<String>,
    }
    ```

    Define the pure derivation:
    ```rust
    pub fn derive_transition_plan(
        svc: &crate::ServiceDef,
        action_name: &str,
    ) -> Result<TransitionPlan, crate::Error> { ... }
    ```
    Implementation steps (no DB, no async, no closures):
    1. Find the action: `svc.actions.iter().find(|a| a.name == action_name)` → `Error::Validation(format!("no action '{action_name}'"))` when absent.
    2. Read `action.transition_trigger.as_deref()` → `Error::NoTransitionTrigger(action_name.into())` when `None`.
    3. Read `svc.state_machine.as_ref()` → `Error::NoStateMachine(svc.name.clone())` when `None`.
    4. `let matches = sm.states_for_event(event);` → `Error::UndeclaredTransition { action: action_name.into(), event: event.into() }` when empty (this is the EXEC-04 fact, by construction).
    5. Collect `to_state`: take `matches[0].to.clone()`. If ANY `t.to != to_state`, return `Error::AmbiguousTransition { event: event.into() }` (fan-out is a real error per Pitfall 2 / Assumption A1, not a silent first-pick).
    6. `from_states`: `matches.iter().map(|t| t.from.clone()).collect()`.
    7. `guard`: the transition-level guard. Since all matches share one event/target, take `matches[0].guard.clone()` (if matches carry differing guards, that is acceptable — guard is per-transition; dedup with action.preconditions happens in Plan 02, not here).
    8. `effects`: union of `matches[0].actions` and `action.effects`, order-preserving, deduped by string equality.
    Return the `TransitionPlan`.

    Add the new `Error` variants in `ferro-projections/src/error.rs` (thiserror, mirroring existing style):
    ```rust
    #[error("action '{0}' has no transition_trigger")]
    NoTransitionTrigger(String),
    #[error("service '{0}' has no state machine")]
    NoStateMachine(String),
    #[error("action '{action}' transition_trigger '{event}' matches no declared transition")]
    UndeclaredTransition { action: String, event: String },
    #[error("event '{event}' fans out to multiple target states — ambiguous transition plan")]
    AmbiguousTransition { event: String },
    ```

    Add `mod executor;` and re-exports to `ferro-projections/src/lib.rs`:

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| caller → ServiceDef registration (boot) | An app registers a `ServiceDef`; a malformed transition_trigger could create a silent unguarded write path if accepted |
| derivation → declared facts | `derive_transition_plan` must read ONLY from declared `Transition.to`/`guard`; introducing any other to-state source re-opens the duplication |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-231-01 | Tampering | derive_transition_plan to_state | mitigate | to_state is sourced ONLY from `Transition.to`; ambiguous fan-out is a hard `Err`, never a silent first-pick (Task 1 step 5) |
| T-231-02 | Elevation of Privilege | ServiceDef::validate drift gate | mitigate | validate() round-trips against derive_transition_plan so any registered transition action is guaranteed derivable; undeclared trigger is fatal at boot (Task 2) |
