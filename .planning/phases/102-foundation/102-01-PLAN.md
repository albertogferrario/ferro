<objective>
Fix the Tailwind v4 font token namespace bug and wire Inter Variable font loading into all JSON-UI pages.

Purpose: The `--font-family-sans` token name is a Tailwind v3 convention that v4 ignores entirely. This means the `font-sans` utility class has never worked in any JSON-UI page. Fixing the namespace and loading Inter via Bunny Fonts CDN establishes the typography foundation for all subsequent visual phases.

Output: All JSON-UI pages render text in Inter Variable with correct `--font-sans` token resolution, Bunny Fonts CDN link in head, and `font-sans` on body.
</objective>
