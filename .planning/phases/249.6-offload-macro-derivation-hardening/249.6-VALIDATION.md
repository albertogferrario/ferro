---

## Sampling Rate

- **After every task commit:** Run the per-crate quick command for the crate that task touched (`cargo test -p ferro-macros --test offload_macro` for macro emission; `cargo test -p ferro-queue` for queue/handle).
- **After every plan wave:** Run BOTH `cargo test -p ferro-macros` (full crate, not just the UI test) AND `cargo test -p ferro-queue` — the macro-gate blindspot means the UI test alone misses broken emission.
- **Before `/gsd-verify-work`:** `cargo fmt --all -- --check && cargo clippy --all --all-targets -- -D warnings && cargo test --all-features` green (after `df` check).
- **Max feedback latency:** ~60 seconds (per-crate).
