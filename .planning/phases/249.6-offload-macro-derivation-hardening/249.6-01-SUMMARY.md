# Phase 249.6 Plan 01: WR-01 and WR-03 Macro Hardening Summary

Two latent defects in `ferro-macros/src/offload.rs` closed: a silent double-reference pass-through in `owned_type` (WR-01) and two `.expect()` panics in the generated `handle()` / `handle_with_value()` bodies (WR-03).

## What Was Built

**WR-01 — spanned compile error for `&&T` / `&Ref<'a>` parameters (SC#1).**
The inner `other =>` arm of `owned_type` previously emitted the inner type verbatim for any non-`str`, non-slice inner type, including inner `Type::Reference` values. A one-line `matches!(other, Type::Reference(_))` guard now intercepts that case before emission and returns `syn::Error::new_spanned(ty, "…")` — the span is anchored on `ty` (the outer `&T` token), matching the existing `&mut` arm pattern. The `str` and `Slice` arms are untouched; owned `T` falls through to the unchanged `Ok(quote! { #other })` path.

**WR-03 — fallible service resolution at both generated handle sites (SC#3).**
`App::make::<dyn #trait_ident>()` returns `Option<Arc<dyn Trait>>`. Both `handle()` (line 392-396) and `handle_with_value()` (line 404-413) previously called `.expect(#expect_msg)`, turning a missing container binding into an unrecoverable panic. Both are now:
```
.ok_or_else(|| ::ferro::queue::Error::job_failed(#job_ident_str, #expect_msg))?
```
Both return types are already `Result<_, ::ferro::queue::Error>`, so `?` composes without additional bindings. The `?` operator provably cannot panic — a missing binding becomes a recorded `Err`, visible in job introspection rather than silently exhausting retries.

**compile-fail fixture `double_ref_param.rs`.**
Created at `ferro-macros/tests/ui/offload/fail/double_ref_param.rs`, structurally identical to `mut_ref_param.rs`. The trybuild runner picks it up via the existing `fail/*.rs` glob. The `.stderr` companion is intentionally absent — it will be generated by `TRYBUILD=overwrite cargo test -p ferro-macros --test offload_macro` in Plan 03 (Wave 2) after all macro-emission changes land. Plan 03 must bless the snapshot before committing.
