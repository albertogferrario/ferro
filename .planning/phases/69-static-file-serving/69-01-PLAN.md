<objective>
Add built-in static file serving so production Ferro binaries serve Vite build output and common root files from `public/` without manual route setup.

Purpose: Every Ferro app with a frontend currently 404s on `/assets/*` in production because there's no static file serving. This was discovered during mkmenu deployment and required a manual workaround controller. This should work zero-config for all Ferro apps.
Output: `try_serve_static_file()` function in framework, integrated into server.rs request handling, with security protections and correct cache headers.
</objective>

  <name>Task 1: Create static_files module with try_serve_static_file()</name>
  <files>framework/Cargo.toml, framework/src/static_files.rs, framework/src/lib.rs</files>
  <action>
1. Add `mime_guess = "2"` to `framework/Cargo.toml` `[dependencies]` section (already used in ferro-storage).

2. Create `framework/src/static_files.rs` with an async function:

```
pub(crate) async fn try_serve_static_file(request_path: &str) -> Option<hyper::Response<Full<Bytes>>>
```

The function must:
- Reject empty paths, paths with null bytes
- Reject dotfiles/hidden directories: any path segment starting with `.` (prevents serving `.env`, `.git/`, etc.)
- Build filesystem path: `public/` + trimmed request path
- Canonicalize both `public/` dir and file path, verify file path `starts_with()` canonical public dir (directory traversal protection)
- Return None if public/ doesn't exist, file doesn't exist, or path is a directory
- Read file with `tokio::fs::read()` (full read into memory — Vite assets are <1MB)
- Detect MIME type with `mime_guess::from_path()`, fallback to `application/octet-stream`
- Set cache headers: `public, max-age=31536000, immutable` for paths starting with `/assets/` (Vite hashed output), `public, max-age=0, must-revalidate` for everything else (favicon.ico, robots.txt, etc.)
- Set Content-Type and Content-Length headers
- Build response as `hyper::Response<Full<Bytes>>` directly — NOT through HttpResponse (which stores body as String, corrupting binary files like images/fonts/wasm)

3. Add `pub(crate) mod static_files;` to `framework/src/lib.rs` (NOT public — this is internal to the framework, users don't call it directly).

  <files>framework/src/server.rs, framework/src/static_files.rs</files>
  <action>
1. In `framework/src/server.rs` `handle_request()`, modify the `None =>` arm (lines 177-201) to try static files BEFORE the fallback handler:

```rust
None => {
    // Try static file serving (only GET/HEAD — no filesystem check for POST, PUT, etc.)
    if method == hyper::Method::GET || method == hyper::Method::HEAD {
        if let Some(response) = crate::static_files::try_serve_static_file(&path).await {
            return response;
        }
    }

    // Then try fallback handler (e.g., Inertia SPA catch-all)
    if let Some((fallback_handler, fallback_middleware)) = router.get_fallback() {
        // ... existing fallback code unchanged ...
    }
}
```

Static files MUST be checked before the fallback because the fallback is typically an Inertia SPA catch-all that would serve HTML for `/assets/main.js` requests.

Only check on GET/HEAD — POST/PUT/DELETE to non-existent routes should not trigger filesystem checks.

For HEAD requests, the same response is returned (hyper handles stripping the body for HEAD automatically at the HTTP layer).
