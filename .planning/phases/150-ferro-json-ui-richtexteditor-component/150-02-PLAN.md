`ferro-json-ui/src/assets/quill.rs` submodule. Compute the SHA-384 SRI hashes for

    character set before committing.

  <action>
    Run, in sequence:

    ```bash
    # 1. Fetch quill.js and compute its SRI hash
    JS_SRI="sha384-$(curl -sL https://cdn.jsdelivr.net/npm/quill@2.0.3/dist/quill.js | openssl dgst -sha384 -binary | openssl base64 -A)"
    echo "JS_SRI=${JS_SRI}"

    # 2. Fetch quill.snow.css and compute its SRI hash
    CSS_SRI="sha384-$(curl -sL https://cdn.jsdelivr.net/npm/quill@2.0.3/dist/quill.snow.css | openssl dgst -sha384 -binary | openssl base64 -A)"
    echo "CSS_SRI=${CSS_SRI}"

    # 3. Sanity-check both values: prefix must be sha384-, body must be exactly 64 chars
    for VAR in JS_SRI CSS_SRI; do
      VAL="${!VAR}"
      if [[ "${VAL}" != sha384-* ]]; then
        echo "FATAL: ${VAR} does not start with sha384-: ${VAL}" >&2
        exit 1
      fi
      BODY="${VAL#sha384-}"
      if [[ ${#BODY} -ne 64 ]]; then
        echo "FATAL: ${VAR} body length is ${#BODY}, expected 64: ${VAL}" >&2
        exit 1
      fi
      echo "${VAR} OK"
    done
    ```
