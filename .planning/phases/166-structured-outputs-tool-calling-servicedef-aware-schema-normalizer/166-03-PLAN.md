    In ferro-ai/src/schema/mod.rs, modify `for_structured_output` so the FIRST step (before `resolve_refs`) is:
    ```rust
    const PROJECTION_DEF_NAMES: &[&str] =
        &["FieldMeaning","Intent","ServiceDef","Cardinality","ActionDef","GuardDef","StateDef"];

    fn has_projection_defs(schema: &Value) -> bool {
        schema.get("$defs").and_then(|d| d.as_object())
            .map(|defs| PROJECTION_DEF_NAMES.iter().any(|n| defs.contains_key(*n)))
            .unwrap_or(false)
    }

    /// Close an untagged-Custom projection enum: replace the `anyOf` with its first
    /// (closed-enum) branch, dropping the open `{"type":"string"}` Custom escape hatch (D-06).
    /// Vocabulary is taken from the branch's own `enum` array — never hardcoded (D-08).
    fn close_projection_enum(defs: &mut Map<String, Value>, name: &str) {
        if let Some(entry) = defs.get_mut(name) {
            let desc = entry.get("description").cloned();
            if let Some(branches) = entry.get("anyOf").and_then(|a| a.as_array()) {
                // pick the branch that actually carries the closed `enum`
                if let Some(closed) = branches.iter()
                    .find(|b| b.get("enum").is_some())
                    .cloned()
                {
                    let mut closed = closed;
                    if let (Some(d), Some(obj)) = (desc, closed.as_object_mut()) {
                        obj.entry("description").or_insert(d);
                    }
                    *entry = closed;
                }
            }
        }
    }
    ```
    Then in `for_structured_output`, before extracting `defs` for ref resolution:
    ```rust
    let mut root = schema;
    if has_projection_defs(&root) {
        if let Some(defs_mut) = root.get_mut("$defs").and_then(|d| d.as_object_mut()) {
            close_projection_enum(defs_mut, "FieldMeaning");
            close_projection_enum(defs_mut, "Intent");
        }
    }
    // ... then the existing Plan 02 flow: clone defs, resolve_refs, drop $defs, normalize_node
    ```
    Note: use `.find(|b| b.get("enum").is_some())` rather than blindly taking `branches[0]` — this is robust if schemars ever reorders branches (defends A2). The Plan 01 probe confirms branch[0] is the closed one, but the find-based extraction is correct regardless of order.
    Add inline `#[cfg(test)]` tests:

    - `non_projection_schema_not_closed`: a schema with `$defs` containing only a non-projection type with an `anyOf` is NOT closed (left as-is aside from generic normalization).
  </action>
