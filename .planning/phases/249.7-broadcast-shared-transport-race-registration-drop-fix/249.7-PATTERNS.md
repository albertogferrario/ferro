## Pattern Assignments

### `ferro-broadcast/src/broadcaster.rs` (state + builder + fan-out)

**Changes:** (1) Make `BroadcasterInner.transport` and `.authorizer` interior-mutable via `parking_lot::RwLock`. (2) `with_transport` becomes `async`, mutates the shared inner in place, and awaits a readiness signal. (3) `with_authorizer` mutates the shared inner in place (stays sync). (4) `fan_out` reads transport via clone-then-drop to avoid holding a guard across `.await`.

#### Analog 1 — `parking_lot::RwLock` on shared mutable state (ferro-events/src/dispatcher.rs lines 29–32, 102–106, 160–172)

This is the workspace precedent for wrapping shared mutable state in `Arc` behind a `parking_lot::RwLock`, taking a write guard to mutate, and immediately dropping the guard before any async work.

**Struct field + read-guard-drop-before-await pattern** (lines 29–32, 160–172):
```rust
pub struct EventDispatcher {
    listeners: RwLock<HashMap<TypeId, Vec<ListenerEntry>>>,
}

// Read: collect under the guard, drop guard, then do async work outside it.
pub async fn dispatch<E: Event>(&self, event: E) -> Result<(), Error> {
    let handlers: Vec<ListenerFn<E>> = {
        let listeners = self.listeners.read();  // guard acquired
        match listeners.get(&type_id) {
            Some(entries) => entries.iter()
                .filter_map(|e| e.handler.downcast_ref::<ListenerFn<E>>().cloned())
                .collect(),
            None => return Ok(()),
        }
    };  // <-- guard drops here, before any .await
    for handler in handlers {
        handler(&event).await  // .await is safe — guard is gone
    }
}
```

**Write-guard pattern** (lines 102–106):
```rust
let mut listeners = self.listeners.write();
let list = listeners.entry(type_id).or_default();
list.push(entry);
// guard drops at end of block — no .await in scope
```

Apply this pattern to `BroadcasterInner`:
- `transport: parking_lot::RwLock<Option<Arc<dyn BroadcastTransport + Send + Sync>>>`
- `authorizer: parking_lot::RwLock<Option<Arc<dyn ChannelAuthorizer>>>`
- In `fan_out`: `let transport = self.inner.transport.read().clone();` — clone the `Arc` out from under the guard; the guard drops at the semicolon; only then does `.await` appear.

**Target shape** (mutate in place, async, await readiness):
```rust
pub async fn with_transport(self, transport: Arc<dyn BroadcastTransport + Send + Sync>) -> Self {
    // D-03: mutate shared inner — existing clients/channels are preserved.
    *self.inner.transport.write() = Some(transport.clone());

    // D-01 readiness channel.
    let (ready_tx, ready_rx) = tokio::sync::oneshot::channel::<()>();
    let (tx, mut rx) = mpsc::channel::<BusEnvelope>(256);
    let loop_transport = transport.clone();
    tokio::spawn(async move {
        if let Err(e) = loop_transport.subscribe_loop(tx, ready_tx).await {
            warn!(error = %e, "broadcast transport subscribe loop ended with error");
        }
    });
    let deliver = self.clone();
    tokio::spawn(async move {
        while let Some(envelope) = rx.recv().await {
            if envelope.origin == deliver.inner.origin_id { continue; }
            deliver.send_to_channel_local_only(&envelope.channel, &envelope.message).await;
        }
    });
    // D-02: await readiness; degrade gracefully on failure (D-06).
    match tokio::time::timeout(Duration::from_secs(5), ready_rx).await {
        Ok(Ok(())) => {}
        Ok(Err(_)) => { warn!("subscribe_loop ended before signalling ready — degraded to local-only"); }
        Err(_)     => { warn!("timed out waiting for transport attach — degraded to local-only"); }
    }
    self
}
```

### `ferro-broadcast/src/transport/memory.rs` (InMemoryTransport impl)

**Change:** Accept and fire `ready` immediately after `self.tx.subscribe()`.

**Current** (lines 31–50):
```rust
async fn subscribe_loop(
    &self,
    sink: tokio::sync::mpsc::Sender<BusEnvelope>,
) -> Result<(), Error> {
    let mut rx = self.tx.subscribe();   // <-- subscription established here
    loop {
        match rx.recv().await {
            Ok(envelope) => {
                if sink.send(envelope).await.is_err() { break; }
            }
            Err(broadcast::error::RecvError::Lagged(n)) => {
                warn!(dropped = n, "in-memory broadcast bus lagged");
            }
            Err(broadcast::error::RecvError::Closed) => break,
        }
    }
    Ok(())
}
```

**Target shape** (fire ready immediately after `tx.subscribe()`):
```rust
async fn subscribe_loop(
    &self,
    sink: tokio::sync::mpsc::Sender<BusEnvelope>,
    ready: tokio::sync::oneshot::Sender<()>,
) -> Result<(), Error> {
    let mut rx = self.tx.subscribe();   // subscription established
    let _ = ready.send(());             // D-01: signal immediately; ignore Err (caller timed out)
    loop {
        match rx.recv().await {
            Ok(envelope) => {
                if sink.send(envelope).await.is_err() { break; }
            }
            Err(broadcast::error::RecvError::Lagged(n)) => {
                warn!(dropped = n, "in-memory broadcast bus lagged");
            }
            Err(broadcast::error::RecvError::Closed) => break,
        }
    }
    Ok(())
}
```

The `ready.send(())` is a non-async call that cannot fail in a way requiring propagation — the `Err` case means `with_transport` already timed out and dropped its receiver, which is not an error for the loop. Use `let _ = ...` to discard it.

```rust
        // ...deserialization and sink.send...

```

**Target shape** (fire ready immediately after `pubsub.subscribe()` succeeds):
```rust
async fn subscribe_loop(
    &self,
    sink: tokio::sync::mpsc::Sender<BusEnvelope>,
    ready: tokio::sync::oneshot::Sender<()>,
) -> Result<(), Error> {
    let mut pubsub = self.client.get_async_pubsub().await?;
    pubsub.subscribe(&self.channel).await?;   // subscription established
    let _ = ready.send(());                   // D-01: signal before entering receive loop
    let mut stream = pubsub.into_on_message();
    while let Some(msg) = stream.next().await {
        // ...deserialization unchanged...
        match serde_json::from_str::<BusEnvelope>(&payload) {
            Ok(envelope) => {
                if sink.send(envelope).await.is_err() { break; }
            }
            Err(e) => {
                warn!(error = %e, "dropping malformed bus envelope from redis");
                continue;
            }
        }
    }
    Ok(())
}
```

If `pubsub.subscribe(...)` fails with `?`, `ready` is dropped without sending — `with_transport` observes `Err(RecvError)` and degrades gracefully per D-02. This is the correct path.

## Shared Patterns

### `parking_lot::RwLock` — clone-then-drop before `.await`
**Source:** `ferro-events/src/dispatcher.rs` lines 160–172
**Apply to:** `fan_out` in `broadcaster.rs`; `subscribe` where it reads `authorizer`

```rust
// Collect/clone under the guard, then drop guard before any .await.
let handlers: Vec<_> = {
    let listeners = self.listeners.read();  // guard lives only in this block
    // ... collect into an owned Vec ...
};   // guard dropped here
for handler in handlers {
    handler(&event).await   // .await is now safe
}
```

The equivalent for `fan_out`:
```rust
let transport = self.inner.transport.read().clone(); // Arc<dyn ...> cloned; guard drops at semicolon
let Some(t) = transport else { return; };
// ... build envelope ...
t.publish(&envelope).await?;  // .await safe — no guard held
```

### Readiness-signal pattern — `oneshot` with D-02 degradation
**Source:** Locked in CONTEXT.md D-01/D-02; confirmed by RESEARCH.md §Code Examples
**Apply to:** `with_transport` in `broadcaster.rs` (caller side); `subscribe_loop` impls (sender side)

```rust
// Sender side (subscribe_loop impl):
let _ = ready.send(());   // fire after subscription is established; Err means caller timed out — ignore

// Caller side (with_transport):
match tokio::time::timeout(Duration::from_secs(5), ready_rx).await {

    Ok(Err(_)) => { warn!("subscribe_loop ended before signalling ready — degraded"); }
    Err(_)     => { warn!("timed out waiting for transport attach — degraded"); }

```

### `#[async_trait]` on existing trait — adding a parameter
**Source:** `ferro-broadcast/src/transport/mod.rs` lines 31–46; confirmed by RESEARCH.md
**Apply to:** `BroadcastTransport::subscribe_loop` (trait) and all impls

Adding a parameter to an `#[async_trait]`-decorated method is safe and does not break object safety — the macro desugars to a boxed future regardless. The `dyn BroadcastTransport + Send + Sync` usage in `broadcaster.rs` continues to work.

### Consuming builder shape — `(self) -> Self` preserved
**Source:** `ferro-broadcast/src/broadcaster.rs` lines 67–78 and 90–120 (current shape)
**Apply to:** `with_transport` (now `async`) and `with_authorizer` (stays sync)

Both builders retain `self` by value and return `Self` — the only change is:
- `with_transport` gains `async` and `.await`
- `with_authorizer` removes the `Arc::new(BroadcasterInner {...})` reallocation and writes through `RwLock`
