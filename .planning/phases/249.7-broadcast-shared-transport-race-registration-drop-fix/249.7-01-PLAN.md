<objective>
Close the two concurrency defects in `ferro-broadcast`'s shared fan-out transport (246.1
REVIEW WR-02 + WR-03) with a single coherent source change, and update every non-test and
test call site so the whole workspace compiles at the plan boundary.

- WR-02 (lost-wakeup window): add a `tokio::sync::oneshot::Sender<()>` readiness parameter
  to `BroadcastTransport::subscribe_loop`; each impl fires it the instant its subscription is
  established; `with_transport` becomes `async` and awaits it (bounded, degrade-on-failure per
  246.1 D-06).
- WR-03 (registration drop / clone divergence): keep a single shared `Arc<BroadcasterInner>`
  for the broadcaster's whole life and all clones; make `transport` and `authorizer`
  interior-mutable via `parking_lot::RwLock<Option<Arc<...>>>`; `with_transport`/`with_authorizer`
  mutate the shared inner in place instead of allocating fresh empty `DashMap`s.

Purpose: A delta published immediately after subscription is never dropped, and a client
registered (or a `Broadcaster` cloned) before transport installation still receives deltas.
This hardens OFFLOAD-04's cross-process delta path.

Output: Modified `ferro-broadcast` source (trait + both transport impls + broadcaster),
plus `.await` insertions at every `with_transport` call site and the `FailingTransport` mock
signature update — leaving `cargo build`/`cargo test --all-features` compiling.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| worker replica → shared bus (Redis pub/sub) | A worker publishes a `BusEnvelope`; other replicas' SUBSCRIBE loops receive it. Internal, cross-process, same trust domain (operator-provisioned Redis). |
| bus envelope → local subscriber delivery | A received envelope from another origin is delivered to local sockets after echo suppression (D-03). |

No new external input surface is introduced. The oneshot readiness signal and the
`parking_lot::RwLock` interior mutability are internal concurrency mechanics; no client-facing
API, no new auth path, no new deserialization boundary.

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-249.7-01 | Denial of Service | `with_transport` awaiting readiness | mitigate | Bounded `tokio::time::timeout(READY_TIMEOUT=5s, ready_rx)`; on timeout or sender-drop, log `warn!` and return the broadcaster degraded to local-only. A stalled/absent subscription cannot block boot indefinitely (246.1 D-06 never-fail-caller preserved). |
| T-249.7-02 | Denial of Service | `fan_out` / `subscribe` / `check_auth` reading the interior-mutable fields | mitigate | Never hold a `parking_lot::RwLock` guard across `.await` — clone the `Arc` out from under the guard and drop it before any await (clippy `await_holding_lock` enforces; ferro-events precedent). Prevents executor-thread deadlock/stall. |
| T-249.7-03 | Tampering | echo suppression across the shared inner change | accept | 246.1 D-03 echo suppression (`envelope.origin == origin_id` drop) is preserved verbatim in the async `with_transport` delivery task; the shared-inner refactor does not alter it. Verified by the retained Phase 247 suite (SC#3). |
| T-249.7-04 | Spoofing | bus envelope authenticity (T-246.1-06) | accept | Pre-existing, documented trust boundary (IN-04): the bus is trusted; envelope signing is explicitly out of scope for this phase. Operator-provisioned Redis is the trust anchor. No change here. |

No high-severity threats. The realistic surface is the two DoS/stall vectors intrinsic to the
fix itself (T-249.7-01/02), both mitigated by construction (bounded timeout, clone-then-drop).
