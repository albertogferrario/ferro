STEP 1 — Write `benchmark/contracts/conformance/test_conformance.py` exactly:
```python
# test_conformance.py — BASE_URL env points at a running app; asserts the shared contract.
import os, requests

BASE = os.environ["BASE_URL"].rstrip("/")

def test_json():
    r = requests.get(f"{BASE}/json")
    assert r.headers["content-type"].startswith("application/json")
    assert r.json() == {"message": "Hello, World!"}

def test_db():
    o = requests.get(f"{BASE}/db").json()
    assert set(o) == {"id", "randomNumber"} and 1 <= o["id"] <= 10000

def test_queries_clamps():
    assert len(requests.get(f"{BASE}/queries?n=600").json()) == 500
    assert len(requests.get(f"{BASE}/queries?n=0").json()) == 1
    assert len(requests.get(f"{BASE}/queries?n=5").json()) == 5

def test_updates_returns_k():
    assert len(requests.get(f"{BASE}/updates?n=7").json()) == 7
```

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| conformance/oha client → apps | HTTP requests against the two local benchmark services |
| toolbox container → compose network | Load gen + static count run inside the benchmark project network |
| committed results/ → public git | Benchmark numbers + hardware metadata become a public artifact |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-229-09 | I (Info disclosure) | committed results/ | accept | results/ holds synthetic benchmark numbers + non-secret hardware metadata (cpu/ram/os). No PII, no credentials. .gitignore excludes app `.env` so DB creds never land in git. |
| T-229-10 | R (Repudiation) | results honesty (D-10) | mitigate | internal.md reports every number; public.md is a verified strict subset with an "expected, not a finding" caveat — results are auditable from committed raw JSON, preventing misrepresentation. |
| T-229-11 | T (Tampering) | parse_oha success gate | mitigate | parse_oha rejects runs with success_rate < 0.99, so a degraded/saturated run cannot silently produce trustworthy-looking headline numbers. |

Scope note: local-only benchmark stand-up; throwaway Postgres password; only input is the
clamped `n` param. Committed results contain no secrets. N/A-level production surface.
