  - tracing = "0.1"
  - tracing-subscriber = { version = "0.3", features = ["env-filter"] }
  - clap = { version = "4", features = ["derive"] }

Add `"ferro-api-mcp"` to workspace members in root Cargo.toml.

Create `ferro-api-mcp/src/lib.rs`:
- Declare modules: `pub mod error;`, `pub mod types;`
- Leave placeholder comments for future modules: spec, schema, http, service, server

Create `ferro-api-mcp/src/error.rs`:
- Use thiserror for error types
- Define `Error` enum with variants:
  - `SpecFetch(String)` — failed to fetch OpenAPI spec from URL
  - `SpecParse(String)` — failed to parse OpenAPI JSON
  - `UnsupportedVersion(String)` — OpenAPI version not 3.0.x
  - `UnresolvedRef(String)` — $ref could not be resolved
  - `HttpClient(String)` — HTTP client error during API call
  - `ApiError { status: u16, body: String }` — API returned error status
  - `ToolExecution(String)` — error during tool execution
  - `Server(String)` — MCP server error
- Implement Display via thiserror derive

Create `ferro-api-mcp/src/types.rs`:
- `#[derive(Debug, Clone, PartialEq)]` on all types
- `ParamLocation` enum: Path, Query, Header
- `ApiParam` struct: name (String), location (ParamLocation), required (bool), schema (serde_json::Value), description (Option<String>)
- `ApiOperation` struct: tool_name (String), method (String), path (String), description (String), parameters (Vec<ApiParam>), request_body_schema (Option<serde_json::Value>), input_schema (serde_json::Value)
- `input_schema` field holds the merged JSON Schema for MCP tool input (built later by schema module)
- Default input_schema to `serde_json::json!({"type": "object", "properties": {}})` in a `new()` constructor or leave as Value for the schema module to populate
