<feature>
  <name>OpenAPI spec parser</name>
  <files>ferro-api-mcp/src/spec.rs</files>
  <behavior>
    Core function: `parse_spec(json: &str) -> Result<Vec<ApiOperation>, Error>`

    Test cases for RED phase:

    1. Version validation:
       - Input: spec with `"openapi": "3.0.3"` → Ok (parses successfully)
       - Input: spec with `"openapi": "3.1.0"` → Err(UnsupportedVersion)
       - Input: spec with `"openapi": "2.0"` → Err(UnsupportedVersion)

    2. Operation extraction:
       - Input: spec with GET /api/users → ApiOperation { method: "GET", path: "/api/users", tool_name: "api.users.index" (from operationId) }
       - Input: spec with POST /api/users + DELETE /api/users/{id} → 2 ApiOperations
       - Input: spec with no operations → empty Vec

    3. Tool naming:
       - Input: operation with operationId "api.users.index" → tool_name = "api_users_index" (dots replaced with underscores)
       - Input: operation without operationId → tool_name = "get_api_users" (generated from method + path)
       - Input: multiple ops, one with operationId, one without → both get unique names

    4. Parameter extraction:
       - Input: GET /api/users/{id} with path param → ApiParam { name: "id", location: Path, required: true }
       - Input: GET /api/users?page=1 with query param → ApiParam { name: "page", location: Query, required: false }
       - Input: operation with no params → empty parameters vec

    5. Request body extraction:
       - Input: POST with application/json requestBody containing schema → request_body_schema = Some(schema)
       - Input: GET with no requestBody → request_body_schema = None

    6. $ref resolution:
       - Input: parameter with `$ref: "#/components/schemas/User"` → resolved to inline schema from components
       - Input: requestBody with `$ref: "#/components/schemas/CreateUserRequest"` → resolved
       - Input: unresolvable $ref → Err(UnresolvedRef) or skip with warning (log + continue)

    7. Description extraction:
       - Input: operation with summary "List users" and description "Returns all users" → description = "List users - Returns all users"
       - Input: operation with summary only → description = summary
       - Input: operation with neither → description = tool_name

    Also implement: `async fn fetch_spec(url: &str) -> Result<String, Error>` (fetch JSON from URL via reqwest). This is not unit-tested (network) but used in integration.
  </behavior>
  <implementation>
    Create `ferro-api-mcp/src/spec.rs` with:

    1. `pub async fn fetch_spec(url: &str) -> Result<String, Error>` — reqwest GET, return body text
    2. `pub fn parse_spec(json: &str) -> Result<Vec<ApiOperation>, Error>` — main entry point:
       - Deserialize with `serde_json::from_str::<openapiv3::OpenAPI>(json)`
       - Validate version starts with "3.0"
       - Extract operations from paths
       - Resolve $ref references
       - Build ApiOperation for each (method, path, operation) tuple
    3. `fn resolve_schema_ref(spec: &OpenAPI, reference: &str) -> Option<serde_json::Value>` — lookup in components.schemas, convert openapiv3 Schema to serde_json::Value via serde
    4. `fn generate_tool_name(operation_id: Option<&str>, method: &str, path: &str) -> String` — operationId with dots→underscores, or fallback to method_path
    5. `fn extract_parameters(spec: &OpenAPI, params: &[ReferenceOr<Parameter>], path_params: &[ReferenceOr<Parameter>]) -> Vec<ApiParam>` — merge operation + path-level params
    6. `fn extract_request_body(spec: &OpenAPI, body: &Option<ReferenceOr<RequestBody>>) -> Option<serde_json::Value>` — extract JSON schema from application/json media type
    7. `fn build_description(operation: &Operation) -> String` — combine summary + description

    For $ref resolution: openapiv3 uses `ReferenceOr<T>` enum. When encountering `ReferenceOr::Reference { reference }`, strip the `#/components/schemas/` prefix, look up in `spec.components.as_ref()?.schemas`, serialize the found Schema to serde_json::Value. For unresolvable refs, log a warning with tracing::warn! and skip (don't fail the whole parse — graceful degradation).

    Add `pub mod spec;` to lib.rs.
  </implementation>
</feature>
