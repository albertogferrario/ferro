```rust
//! Content-hashed static asset bundles.
//!
//! Re-exports the leaf `ferro-bundle` crate and adds the framework-aware
//! [`Bundle::serve`] adapter that maps a [`crate::Request`] to an
//! [`crate::HttpResponse`]. Register bundles at boot (or lazily via the
//! [`crate::asset!`] macro), then mount `Bundle::serve` on `/bundles/{filename}`.

pub use ferro_bundle::{mime_from_ext, Bundle, BundleResponse};

use crate::http::{HttpResponse, Request};

impl Bundle {
    /// Dispatch a request to the bundle registry, returning a framework
    /// [`HttpResponse`]. Mount as the handler for `/bundles/{filename}` and
    /// each registered alias path.
    pub fn serve(req: &Request) -> HttpResponse {
        let path = req.path().to_string();
        let if_none_match = req.header("if-none-match").map(|s| s.to_string());
        let resp = ferro_bundle::serve_path(&path, if_none_match.as_deref());

        let mut out = HttpResponse::bytes(resp.body_bytes().clone()).status(resp.status_code());
        for (name, value) in resp.headers() {
            out = out.header(name.clone(), value.clone());
        }
        out
    }
}
```
NOTE on the import path: use whatever the existing framework module path for `Request`/`HttpResponse` is (grep `use crate::http` vs `crate::Request` usage elsewhere in framework). If `crate::Request`/`crate::HttpResponse` are already re-exported at crate root (they are, per `ferro::Request`), prefer `use crate::{HttpResponse, Request};`.

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-261-03 | Tampering | `Bundle::serve` adapter | accept | The adapter forwards `req.path()` + `if-none-match` verbatim to `serve_path`, which does map lookups only (no filesystem, no dynamic dispatch). Header values are copied 1:1 from the trusted static registry into the response — no request-controlled header injection into the response. |
| T-261-04 | Denial of Service | serve adapter body clone | accept | `body_bytes().clone()` clones a `Bytes` (ref-counted, O(1)); no per-request allocation of the payload. Payloads are compile-time-embedded static bytes, bounded at build time. |
</threat_model>
