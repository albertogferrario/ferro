`ActionError::not_found`, `handle_action_result`).

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| route request → generated handler | the macro-generated prelude crosses untrusted path-param input into a typed lookup. |
| author-supplied URL literals → generated redirect | `on_miss`/`redirect_to`/`form_url` are compile-time string literals authored by the developer, not request input. |
| generated lookup → tenant data | the single seam where cross-tenant reads could occur. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-212-01 | Information Disclosure (IDOR) | generated lookup in resource_get/resource_post | mitigate | The codegen ALWAYS emits `<R as ::ferro::TenantScoped>::find_for_tenant(__resource_id, __tenant.id)` — there is no code path that emits an un-scoped `find_by_id`. The `find =` override still receives `__tenant.id` as its second argument. Acceptance criteria grep for `find_for_tenant(__resource_id, __tenant.id)` in both files. This is the load-bearing security property of the phase. |
| T-212-02 | Elevation of Privilege | open redirect via on_miss/redirect_to/form_url | accept | These URLs are author-supplied compile-time string literals (not request input); they are baked into the binary at expansion time. The action runtime's `is_same_origin` check (action.rs:249) still applies to the `redirect_to` literal handled by `handle_action_result`. Low risk. |
| T-212-03 | Tampering | macro hygiene — generated code resolving in consumer crates | mitigate | All generated paths are absolute `::ferro::...` so the expansion resolves regardless of the consumer's local imports/shadowing. Verified by the trybuild pass fixtures compiling in a separate test crate. |
| T-212-04 | Spoofing/Tampering | `tenant = "expr"` escape hatch evaluates a consumer expression | accept | The expr is author-supplied at the call site (compile-time), emitted verbatim; the consumer owns its correctness (must yield their declared tenant type). Documented; not request-controlled. |
</threat_model>
