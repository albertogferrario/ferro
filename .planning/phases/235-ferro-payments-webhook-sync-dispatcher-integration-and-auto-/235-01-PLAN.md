In `ferro-payments/src/lib.rs`, add `use std::borrow::Cow;` to the imports (top of file, near the other `use` lines). Replace the existing `BillableKind` struct and impl with exactly:

```rust
#[derive(Clone, Debug, PartialEq, Eq)]
pub struct BillableKind(Cow<'static, str>);

impl BillableKind {
    /// Construct from a compile-time string literal (e.g. `BillableKind::new("order")`).
    pub const fn new(s: &'static str) -> Self {
        Self(Cow::Borrowed(s))
    }

    /// Construct from a runtime `String` (e.g. the value read from
    /// `payment_intents.billable_kind` by the webhook handlers).
    pub fn from_string(s: String) -> Self {
        Self(Cow::Owned(s))
    }

    /// Borrow the kind as a string slice. Lifetime is tied to `&self`.
    pub fn as_str(&self) -> &str {
        &self.0
    }
}
```

Notes:
- The `as_str` return type narrows from `&'static str` to `&str`. The breakage audit (235-RESEARCH Finding/Pattern 6 + 235-PATTERNS) confirms no caller stores a `&'static str` result — all consumers accept `&str`.
- `Cow<'static, str>` derives `Clone`, `Debug`, `PartialEq`, `Eq` from its variants — the existing derive list is unchanged.
- Do NOT add a `from_string` re-export change here; `BillableKind` is already publicly re-exported. The `wire_dispatcher` / lifecycle-helper re-exports are added in plan 05 (Wave 3) to avoid touching `lib.rs` in two same-wave plans.
