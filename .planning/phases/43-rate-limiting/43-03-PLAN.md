Add a new template entry for "rate_limiting" or "throttle_middleware" that shows:

1. **Defining named rate limiters** (in bootstrap.rs):
```rust
use ferro::middleware::{RateLimiter, Limit};
use ferro::auth::Auth;

pub fn register_rate_limiters() {
    RateLimiter::define("api", |req| {
        match Auth::id(req) {
            Some(id) => Limit::per_minute(120).by(format!("user:{}", id)),
            None => Limit::per_minute(60).by(get_client_ip(req)),
        }
    });

    RateLimiter::define("auth", |req| {
        Limit::per_minute(5).by(get_client_ip(req))
    });
}
```

2. **Applying to routes** (in routes.rs):
```rust
use ferro::middleware::Throttle;

routes! {
    group!("/api", {
        get!("/users", controllers::users::index),
    }).middleware(Throttle::named("api")),

    group!("/auth", {
        post!("/login", controllers::auth::login),
    }).middleware(Throttle::named("auth")),
}
```

3. **Inline throttle** (no registration needed):
```rust
get!("/health", controllers::health::check)
    .middleware(Throttle::per_minute(10))
```

Follow the existing template format in the file. Match naming conventions.

After editing, rebuild: `cargo build -p ferro-mcp`
