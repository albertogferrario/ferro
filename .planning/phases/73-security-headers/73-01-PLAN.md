<task type="auto">
  <name>Task 1: Create SecurityHeaders middleware with builder pattern</name>
  <files>framework/src/middleware/security_headers.rs</files>
  <action>
Create `framework/src/middleware/security_headers.rs` implementing a post-processing middleware that adds OWASP-recommended security headers to all responses.

**Struct design:** Each header is an `Option<String>` field. `None` means header is not set; `Some(value)` means it's set.

**Default headers (from `new()`):**
- `X-Content-Type-Options: nosniff`
- `X-Frame-Options: DENY`
- `Content-Security-Policy: default-src 'self'; script-src 'self' 'unsafe-inline' 'unsafe-eval'; style-src 'self' 'unsafe-inline'; img-src 'self' data: blob:; font-src 'self' data:; connect-src 'self' ws: wss:; frame-ancestors 'none'`
- `Referrer-Policy: strict-origin-when-cross-origin`
- `Permissions-Policy: geolocation=(), camera=(), microphone=()`
- `Cross-Origin-Opener-Policy: same-origin`
- `X-XSS-Protection: 0` (OWASP recommends disabled — old XSS Auditor can create vulnerabilities)
- `Strict-Transport-Security`: **None by default** (breaks localhost over HTTP)

**Builder methods (consuming self, return Self):**
- `with_hsts()` — enable HSTS with `max-age=31536000; includeSubDomains` (no preload — it's permanent)
- `with_hsts_preload()` — enable HSTS with preload (for users who explicitly want it)
- `without_hsts()` — disable HSTS (same as default, for explicitness)
- `x_frame_options(value: impl Into<String>)` — override X-Frame-Options (e.g., "SAMEORIGIN")
- `content_security_policy(value: impl Into<String>)` — override CSP
- `referrer_policy(value: impl Into<String>)` — override Referrer-Policy
- `permissions_policy(value: impl Into<String>)` — override Permissions-Policy
- `cross_origin_opener_policy(value: impl Into<String>)` — override COOP
- `without(header_name: &str)` — disable a specific header by name (sets its field to None)

**Middleware impl:**
Follow MetricsMiddleware pattern. Call `next(request).await`, then apply headers to BOTH Ok and Err responses via `apply_headers()`. This ensures error pages also get security headers (pitfall #6 from research).

**apply_headers method:**
Private method that takes `HttpResponse`, iterates over all `Some` fields, calls `resp.header(name, value)` for each, returns modified response.

**Important:**
- Do NOT derive Clone/Copy — struct contains heap-allocated Strings
- Implement `Default` delegating to `new()`
- Use `impl Into<String>` for builder method parameters (ergonomic API)
- Keep X-XSS-Protection at 0, not 1 — this is intentional per OWASP
- Include module-level doc comment explaining purpose and OWASP reference
