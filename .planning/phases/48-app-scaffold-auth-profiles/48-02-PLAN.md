<task type="auto">
  <name>Task 1: Create auth provider, resource, and controller</name>
  <files>
    app-proximity/src/providers/auth_provider.rs,
    app-proximity/src/providers/mod.rs,
    app-proximity/src/resources/user_resource.rs,
    app-proximity/src/resources/mod.rs,
    app-proximity/src/controllers/auth_controller.rs,
    app-proximity/src/controllers/mod.rs
  </files>
  <action>
    1. Create providers/auth_provider.rs following app/src/providers/auth_provider.rs exactly:
       - DatabaseUserProvider struct implementing UserProvider trait
       - retrieve_by_id: query by Column::Id
       - retrieve_by_credentials: extract email from JSON, call User::find_by_email
       - validate_credentials: bcrypt verify via ferro::verify
       - Use crate::models::users::{Column, Model as User}

    2. Update providers/mod.rs: pub mod auth_provider; pub use auth_provider::DatabaseUserProvider;

    3. Create resources/user_resource.rs following app/src/resources/user_resource.rs pattern:
       - #[derive(ApiResource)]
       - #[resource(model = "crate::models::entities::users::Model")]
       - Include: id, name, email
       - #[resource(skip)] on: password, remember_token, created_at, updated_at
       - ALSO include (not skipped): bio, latitude, longitude, avatar_url — these are public profile fields

    4. Update resources/mod.rs: pub mod user_resource; pub use user_resource::UserResource;

    5. Create controllers/auth_controller.rs following app/src/controllers/auth_controller.rs pattern:
       - RegisterInput struct with: name, email, password, password_confirmation
       - LoginInput struct with: email, password
       - register handler: validate, check uniqueness, hash password, insert user, Auth::login, return 201
       - login handler: validate, Auth::attempt with find_by_email + verify, return user
       - logout handler: Auth::logout
       - profile handler: Auth::user_as::<users::Model>, return UserResource

       For register: do NOT ask for location fields — those come later via profile edit.

    6. Update controllers/mod.rs to declare: pub mod home; pub mod auth_controller;
  </action>
  <verify>cargo check -p app-proximity 2>&1 | tail -5 — compiles without errors</verify>
  <done>Auth provider, resource, and controller compile. All four auth endpoints defined.</done>
</task>
