<task type="auto">
  <name>Task 1: Create profile show page with JSON-UI and Map</name>
  <files>
    app-proximity/src/controllers/profile_controller.rs,
    app-proximity/src/controllers/mod.rs
  </files>
  <action>
    1. Create controllers/profile_controller.rs with two handlers:

    **show handler** (GET /profile):
    - Extract authenticated user via Auth::user_as::<users::Model>(), 401 if not authenticated
    - Build a JsonUiView using the builder pattern:
      ```
      let view = JsonUiView::new()
          .title("My Profile")
          .component(ComponentNode { ... })
      ```
    - Layout the profile as a Card with:
      - Heading showing user name
      - Text showing email
      - Text showing bio (or "No bio yet")
      - If user has latitude/longitude, include a Map plugin component:
        Build a ComponentNode with key "location-map", component type "Map" (use Component::Plugin with PluginProps):
        ```
        Component::Plugin(PluginProps {
            component_type: "Map".to_string(),
            props: serde_json::json!({
                "center": [user.latitude.unwrap(), user.longitude.unwrap()],
                "zoom": 14,
                "height": "300px",
                "markers": [{
                    "lat": user.latitude.unwrap(),
                    "lng": user.longitude.unwrap(),
                    "popup": user.name.clone()
                }]
            }),
        })
        ```
      - If no location, show text "Location not set"
      - Add an action button linking to the edit page: "Edit Profile" → GET /profile/edit
    - Render with JsonUi::render(&view, &serde_json::json!({}))

    **edit handler** (GET /profile/edit):
    - Extract authenticated user
    - Build a JsonUiView with title "Edit Profile"
    - Create a Form component (Component::Form) with:
      - method: POST to /profile (use HttpMethod::Post)
      - Input fields: name (prefilled), email (prefilled), bio (prefilled, use textarea-like approach or just Input)
      - Input fields: latitude (prefilled, type number), longitude (prefilled, type number)
      - Submit button: "Save Profile"
    - Render with JsonUi::render(&view, &serde_json::json!({}))

    **update handler** (POST /profile):
    - Extract authenticated user
    - Parse form input (name, email, bio, latitude, longitude) from request JSON body
    - Validate: name required, email required + email format, latitude optional numeric in [-90,90], longitude optional numeric in [-180,180]
    - Update user via UpdateBuilder pattern: user model .update().set_name(...).set_email(...).set_bio(...).set_latitude(...).set_longitude(...).save().await
    - On validation error: return JsonUi::render_with_errors with the edit form view
    - On success: redirect to GET /profile (or return success JSON)

    Use ferro imports: JsonUi, JsonUiView, ComponentNode, Component, CardProps, TextProps, FormProps, InputProps, ButtonProps, PluginProps, HttpMethod.

    2. Update controllers/mod.rs: add pub mod profile_controller;

    NOTE: The UpdateBuilder on users::ActiveModel uses the pattern from v2.2: model.update().set_field(value).save(&db).await. Check if the FerroModel derive generates these set_* methods. If not, use ActiveModel with Set() directly for updates — the same pattern as the register handler but with a fetched model converted to ActiveModel.
  </action>
