  <name>Task 1: Create make_projection CLI command</name>
  <files>ferro-cli/src/commands/make_projection.rs, ferro-cli/src/commands/mod.rs</files>
  <action>
1. Create `ferro-cli/src/commands/make_projection.rs` following the established make_* pattern:
   - Public `execute(name: &str)` function
   - Creates `src/projections/` directory if it doesn't exist
   - Creates `src/projections/{name}.rs` with a ServiceDef template
   - Creates `src/projections/mod.rs` if it doesn't exist, adds `pub mod {name};`
   - If mod.rs exists, appends `pub mod {name};` if not already present
   - Prints success message with generated file paths

2. The generated ServiceDef template should be:
   ```rust
   use ferro::{
       DataType, FieldMeaning, ServiceDef,
   };

   /// Build the {Name} service projection.
   ///
   /// Describes the {Name} entity's fields, relationships,
   /// and behavioral semantics for intent derivation and UI rendering.
   pub fn {name}_service() -> ServiceDef {
       ServiceDef::new("{name}")
           .display_name("{Name}")
           .field("id", DataType::Integer, FieldMeaning::Identifier)
           // Add fields matching your model:
           // .field("name", DataType::String, FieldMeaning::EntityName)
           // .field("email", DataType::String, FieldMeaning::Email)
           // .field("status", DataType::String, FieldMeaning::Status)
           // .field("created_at", DataType::DateTime, FieldMeaning::CreatedAt)
           // .field("updated_at", DataType::DateTime, FieldMeaning::UpdatedAt)
   }
   ```

3. Use `to_pascal_case()` for {Name} and snake_case for {name}. If the analyzer.rs has these helpers, reuse them. Otherwise add simple conversions inline.

4. Add `pub mod make_projection;` to `ferro-cli/src/commands/mod.rs`
