  API scaffold complete! Generated for: {Model1}, {Model2}
  ═══════════════════════════════════════════════

    Controllers:  src/api/{model}_api.rs
    Resources:    src/resources/{model}_resource.rs
    Requests:     src/requests/{model}_request.rs
    Routes:       src/api/routes.rs
    Docs:         src/api/docs.rs

  ───────────────────────────────────────────────
  Setup Steps
  ───────────────────────────────────────────────

  1. Wire up routes in src/main.rs:
       mod api;
       // In route registration:
       api::routes::api_routes()
       api::docs::docs_routes()

  2. Register the API key provider:
       App::register::<dyn ApiKeyProvider>(Box::new(ApiKeyProviderImpl::new()));

  3. Run the migration:
       ferro db:migrate

  4. Generate an API key:
       ferro make:api-key "My App"

  5. Verify the API works:
       ferro api:check --api-key fe_live_...

  ───────────────────────────────────────────────
  MCP Integration
  ───────────────────────────────────────────────

  To connect this API to an AI agent via MCP, add to your

      "mcpServers": {
        "{app-name}-api": {
          "command": "ferro-api-mcp",
          "args": [
            "--spec-url", "http://localhost:8080/api/openapi.json",
            "--api-key", "fe_live_..."
          ]
        }
      }
    }

  Claude Code (~/.claude.json):

    }

  ═══════════════════════════════════════════════
