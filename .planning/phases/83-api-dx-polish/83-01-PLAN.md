  <files>ferro-cli/src/commands/make_api_key.rs, ferro-cli/src/commands/mod.rs, ferro-cli/src/main.rs, ferro-cli/Cargo.toml</files>
  <action>
  Create a new `make_api_key` command module in ferro-cli that generates API keys without requiring a database connection.

  1. Add `sha2 = "0.10"` and `rand = "0.8"` to ferro-cli/Cargo.toml dependencies (check if rand is already a transitive dep, add explicitly either way for clarity).

  2. Create `ferro-cli/src/commands/make_api_key.rs` with a `run(name: String, env: String)` function:
     - Replicate the key generation logic from `framework/src/api/api_key.rs`:
       - Generate 43 random base62 characters using `rand::Rng::gen_range`
       - Prefix with `fe_{env}_` (validate env is "live" or "test")
       - Hash full key with SHA-256 hex digest
       - Extract first 16 chars as prefix for database lookup
     - Output formatted result:
       ```
       API Key Generated!

       Raw Key (save this — shown only once):
         fe_live_abc123...

       Database values:
         Name:       {name}
         Prefix:     fe_live_abc12345
         Hashed Key: {sha256_hex}

       Insert SQL:
         INSERT INTO api_keys (name, prefix, hashed_key, created_at)
         VALUES ('{name}', '{prefix}', '{hash}', datetime('now'));

       Rust snippet:
         let key = api_keys::ActiveModel {
             name: Set("{name}".to_string()),
             prefix: Set("{prefix}".to_string()),
             hashed_key: Set("{hash}".to_string()),
             ..Default::default()
         };
         key.insert(db).await?;
       ```
     - Use `console` crate for colored output (green for key, yellow for warning about one-time display).

  3. Register in `ferro-cli/src/main.rs`:
     - Add `MakeApiKey` variant to `Commands` enum with `#[command(name = "make:api-key")]`
     - Parameters: `name: String` (key name, e.g., "Production Bot"), `--env` flag defaulting to "live"
     - Route to `commands::make_api_key::run(name, env)` in match block

  4. Add `pub mod make_api_key;` to `ferro-cli/src/commands/mod.rs`.

  Do NOT depend on the framework crate — replicate the ~20 lines of key generation logic directly. This keeps ferro-cli independent.
  </action>
  <verify>Run `cargo build -p ferro-cli` — should compile. Run `cargo run -p ferro-cli -- make:api-key "Test Key"` — should output a generated key with all sections.</verify>
  <done>Command generates valid API key with raw key, prefix, hash, SQL insert, and Rust snippet. Key format matches `fe_{env}_{43 base62 chars}`. SHA-256 hash is correct.</done>
