<objective>
Add route-level x-MCP customization API so users can override auto-generated tool names, descriptions, hints, and hide routes from MCP.

Purpose: Currently all x-mcp OpenAPI extensions are 100% auto-generated from HTTP method + path patterns. Users cannot customize tool names, descriptions, or hide internal routes from AI agents. This closes the third DX gap discovered during v8.0 validation.
Output: Builder methods on route definitions (`.mcp_tool_name()`, `.mcp_description()`, `.mcp_hint()`, `.mcp_hidden()`) that propagate to the OpenAPI spec.
</objective>

<task type="auto">
  <name>Task 2: Consume x-mcp metadata in OpenAPI spec builder</name>
  <files>framework/src/api/openapi.rs</files>
  <action>
  Modify `build_openapi_spec()` in `framework/src/api/openapi.rs` to:

  1. **Skip hidden routes**: If `route.mcp_hidden` is `true`, skip the `x-mcp-tool-name` and `x-mcp-description` extensions entirely. Instead, add only `x-mcp-hidden: true` extension. The `ferro-api-mcp` consumer already handles `x-mcp-hidden` by skipping the operation at parse time.

  2. **Prefer explicit overrides**: When building x-mcp extensions:
     ```rust
     let tool_name = route.mcp_tool_name.clone()
         .unwrap_or_else(|| mcp_tool_name(&route.method, &route.path));
     let description = route.mcp_description.clone()
         .unwrap_or_else(|| mcp_description(&route.method, &route.path));
     ```

  3. **Add hint extension**: If `route.mcp_hint` is `Some(hint)`, add `x-mcp-hint` to the extensions builder. This is already consumed by `ferro-api-mcp` (appended to description as "\n\nHint: {hint}").

  4. **Add/update tests**: Add test cases in the existing `#[cfg(test)]` module:
     - Route with explicit `mcp_tool_name` override → uses override in spec
     - Route with `mcp_hidden: true` → has `x-mcp-hidden: true`, no tool-name/description
     - Route with `mcp_hint` → has `x-mcp-hint` extension
     - Route with no overrides → uses auto-generated values (existing behavior)

  5. **Re-export**: If `McpRouteConfig` or similar types need to be public, re-export from `framework/src/lib.rs`.
