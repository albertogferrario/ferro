for prefix in ["create_", "update_", "delete_"] {
    if let Some(svc_name) = tool_name.strip_prefix(prefix) {
        if let Some(svc) = services

            let tid = match tenant_id {
                Some(t) => t,
                None => return json!({ "error": { "code": -32603, "message": "auth: tenant required" } }),
            };
            let args = call_params.get("arguments").cloned().unwrap_or_else(|| json!({}));
            let verb = match prefix {
                "create_" => CrudVerb::Create,
                "update_" => CrudVerb::Update,
                _ => CrudVerb::Delete,
            };
            let plan = match derive_crud_plan(svc, verb, &args) {
                Ok(p) => p,
                Err(e) => return json!({ "result": write_tool_error_result(json!({
                    "error_kind": "validation", "message": e.to_string() })) }),
            };
            // CRUD verbs are not ActionDefs; synthesize a minimal ActionDef whose name is
            // the tool name -> drives the audit label + override-hook lookup ("create_order").
            let crud_action = ferro_projections::ActionDef::new(&tool_name);
            // A bare delete passes is_confirmed=false so the kernel seam returns
            // ConfirmationRequired; create_/update_ are non-destructive and execute.
            return match dispatch_write(
                &crud_action, &args, tid, db, dispatcher,
                None /* transition_guard: CRUD has none */, "mcp",
                #[cfg(feature = "confirmation")] false,
                Some(&plan),
            ).await {
                Ok(result) => {
                    let payload = json!({ "status": "ok", "action": tool_name, "result": result });
                    json!({ "result": CallToolResult::structured(payload) })
                }
                #[cfg(feature = "confirmation")]
                Err(WriteError::ConfirmationRequired(ref name)) => {
                    json!({ "result": write_tool_error_result(json!({
                        "error_kind": "confirmation_required",
                        "message": format!("use request_confirm_{name} first"),
                        "request_tool": format!("request_confirm_{name}")
                    })) })
                }
                Err(WriteError::RecordNotFound) => json!({ "result": write_tool_error_result(json!({
                    "error_kind": "not_found", "message": "record not found or already deleted" })) }),
                Err(ref e @ WriteError::Validation(_)) => json!({ "result": write_tool_error_result(json!({
                    "error_kind": "validation", "message": e.to_string() })) }),
                Err(_) => json!({ "result": write_tool_error_result(json!({
                    "error_kind": "internal", "message": "write failed" })) }),
            };
        }
    }
}

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-241-10 | Elevation of Privilege | bare delete_<svc> call | mitigate | The kernel seam (Plan 02) returns ConfirmationRequired for a bare delete; the framing surfaces a confirmation_required envelope and only `confirm_delete_<svc>` (after token validation, is_confirmed=true) reaches the soft-delete. `delete_bare_call_returns_confirmation_required` + `delete_two_step_flow` prove it. |
| T-241-11 | Tampering (token replay/cross-record) | handle_confirm binding | mitigate (reused) | The `{tenant_id, action_name, record_id}` binding check + single-use `ConfirmationStore.confirm()` are reused UNCHANGED; `delete_wrong_record_token_rejected` proves a token issued for one record cannot delete another. |
| T-241-12 | Spoofing | agent supplies tenant in arguments | mitigate | `tid` is the unwrapped authenticated principal (fail-closed -32603 when absent), never read from `arguments`; `derive_crud_plan` excludes the tenant column from the writable set (Plan 01). |
| T-241-13 | Tampering (SQL injection) | derive_crud_plan inputs | mitigate (inherited) | Values flow as `serde_json::Value` into the plan and are bound (never interpolated) by `execute_crud_plan` (Plan 02). The framing passes agent arguments only as bound values. |
| T-241-14 | Information Disclosure | unknown-tool probing | accept | A CRUD verb on an un-opted service falls through to the standard -32601 "Method not found" — identical to any unknown tool, no extra disclosure. Low risk. |

**Out of scope (DEFERRED to Phase 242):** `read_write` scope enforcement, `.mcp_write_ability`
Gate at the call boundary, server-side `tenant_id` injection, and cross-tenant non-disclosure.
The `tools/call` regression-guard extension for the new verbs is **Phase 243**. Phase 241 emits
through `structured` so 243 only adds assertions. The checker should NOT flag these as missing
in Plan 03.
