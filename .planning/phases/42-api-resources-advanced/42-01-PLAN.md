<task type="auto">
  <name>Task 1: Create PaginationMeta and PaginationLinks structs</name>
  <files>framework/src/http/resources/pagination.rs</files>
  <action>
Create `pagination.rs` with two structs:

**PaginationMeta:**
- Fields: `current_page: u64`, `per_page: u64`, `total: u64`, `last_page: u64`, `from: u64`, `to: u64`
- Constructor `PaginationMeta::new(current_page: u64, per_page: u64, total: u64)` — accepts 1-indexed page from API, computes `last_page` (ceiling division), `from` (1-based first item index on page), `to` (1-based last item index on page). Handle edge cases: empty results (from=0, to=0), last page partial fill, page beyond total.
- Derive `Serialize, Clone, Debug` — serializes with snake_case field names for JSON output.
- Method `pub fn links(&self, path: &str, query: Option<&str>) -> PaginationLinks` — generates pagination links. Parse existing query params, replace/add `page=N` for each link. Use relative URLs (path-based, e.g., `/users?page=2`). `prev` is None on page 1. `next` is None on last page.

**PaginationLinks:**
- Fields: `first: String`, `last: String`, `prev: Option<String>`, `next: Option<String>`
- Derive `Serialize, Clone, Debug`

Helper function `build_url(path: &str, query: Option<&str>, page: u64) -> String` — takes existing query string, replaces or adds `page=N` parameter, returns `{path}?{params}`. Use `form_urlencoded` crate (already a dependency via `url` crate in the workspace) for proper encoding. If no existing query params, return `{path}?page={N}`.

**Unit tests:**
- `test_meta_basic` — page 1 of 3 (45 items, 15 per page): current_page=1, last_page=3, from=1, to=15
- `test_meta_last_page` — page 3 of 3 (45 items, 15 per page): from=31, to=45
- `test_meta_partial_last_page` — page 3 of 3 (42 items, 15 per page): from=31, to=42
- `test_meta_empty` — 0 total items: last_page=1, from=0, to=0
- `test_meta_single_page` — 5 items, 15 per page: last_page=1, from=1, to=5
- `test_links_first_page` — prev is None, next is Some
- `test_links_last_page` — prev is Some, next is None
- `test_links_middle_page` — both prev and next are Some
- `test_links_single_page` — both prev and next are None
- `test_links_preserves_query_params` — existing `?sort=name&page=1` → page param updated, sort preserved

  <files>framework/src/http/resources/resource_collection.rs, framework/src/http/resources/mod.rs, framework/src/lib.rs</files>
  <action>
Create `resource_collection.rs`:

**ResourceCollection&lt;T: Resource&gt;:**
- Fields: `items: Vec<T>`, `pagination: Option<PaginationMeta>`, `additional: Option<serde_json::Value>`
- `pub fn new(items: Vec<T>) -> Self` — collection without pagination
- `pub fn paginated(items: Vec<T>, meta: PaginationMeta) -> Self` — collection with pagination
- `pub fn additional(mut self, value: serde_json::Value) -> Self` — add extra top-level fields (builder pattern, returns Self)
- `pub fn to_response(&self, req: &Request) -> HttpResponse` — produces the JSON response:
  - Without pagination: `{"data": [item.to_resource(req), ...]}`
  - With pagination: `{"data": [...], "meta": {...}, "links": {...}}`
  - With additional: merges additional fields at top level alongside data/meta/links
  - Extract path and query from `req.path()` and `req.inner().uri().query()` for link generation

**Update mod.rs:** Add `pub mod pagination;` and `pub mod resource_collection;`. Add `pub use` for PaginationMeta, PaginationLinks, ResourceCollection.
