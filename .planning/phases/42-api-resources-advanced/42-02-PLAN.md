<task type="auto">
  <name>Task 1: Add when_loaded and when_loaded_many to ResourceMap</name>
  <files>framework/src/http/resources/resource_map.rs</files>
  <action>
Add two methods to ResourceMap for ergonomic batch-loaded relationship inclusion:

**`when_loaded`** — for belongs_to / has_one relationships from a batch-loaded HashMap:
```rust
pub fn when_loaded<K, M>(
    self,
    key: &str,
    lookup_key: &K,
    map: &HashMap<K, M>,
    transform: impl FnOnce(&M) -> Value,
) -> Self
where
    K: Eq + Hash,
```
If the key exists in the map, includes the field with the transformed value. Otherwise omits the field (ResourceValue::Missing). This avoids the user having to manually write `.when_some("field", &map.get(&id).map(|m| transform(m)))`.

**`when_loaded_many`** — for has_many relationships from a batch-loaded HashMap:
```rust
pub fn when_loaded_many<K, M>(
    self,
    key: &str,
    lookup_key: &K,
    map: &HashMap<K, Vec<M>>,
    transform: impl FnOnce(&[M]) -> Value,
) -> Self
where
    K: Eq + Hash,
```
If the key exists in the map, transforms the vec slice. Otherwise omits the field.

Add `use std::collections::HashMap;` and `use std::hash::Hash;` imports at the top.

**Unit tests:**

- `test_when_loaded_many_missing` — key not in map → field omitted
- `test_when_loaded_many_empty_vec` — key exists but vec is empty → field included with empty array (it was loaded, just empty)

<task type="auto">

  <files>framework/src/http/resources/resource.rs</files>
  <action>
Add a default method to the Resource trait:

```rust
/// Map a slice of resources to their JSON representations.
///
/// Convenience for `items.iter().map(|item| item.to_resource(req)).collect()`.
///
/// # Example
///
/// ```rust,ignore
/// let users: Vec<UserResource> = /* ... */;
/// let json_array = UserResource::collection(&users, &req);
/// // Returns: Vec<serde_json::Value>
/// ```
fn collection(items: &[Self], req: &Request) -> Vec<serde_json::Value>
where
    Self: Sized,
{
    items.iter().map(|item| item.to_resource(req)).collect()
}
```

This is a simple convenience that avoids repeating the map/collect pattern in every handler.
