<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Handler's `Action.handler` string → resolved URL | Flows through `resolve_action(&mut props.action, resolver)` into `props.action.url` |
| DetailField.input ComponentNode tree → resolved children | Each field's nested components recurse through resolve_component_node |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-147-03 | Tampering | Action URL resolution pipeline — `props.action.url` must only be populated via `resolve_action(&mut props.action, resolver)` | mitigate | This task's resolve_component_node arm delegates to the existing `resolve_action` helper (the same function Form uses). No code path in this plan bypasses it. The resolver callback is supplied by the framework's route registry, making the (handler → url) mapping an integrity-checked function of server-side configuration |
| T-147-04 | Tampering | Validation error propagation path — errors must reach Input inside DetailField without going through a shared-mutable-state side-channel | mitigate | resolve_errors_node's DetailForm arm recurses `resolve_errors_node(&mut field.input, errors, all)` — the same API shape used by Component::Form. No sibling DetailForms can see each other's errors (each field.input owns its own error slot via the existing resolve_errors pipeline). Plan 01's `resolve_errors_propagates_into_detail_form_fields` test asserts end-to-end |
| T-147-05 | Spoofing | Raw `edit_url` / `cancel_url` bypass route-registry resolution | accept | D-16 by design: these are raw hrefs. The author is trusted to build them; the renderer html_escapes them before emission. This is a trust boundary placement decision, not a mitigation gap — handler-based resolution for these is explicitly deferred (147-CONTEXT.md Deferred). Plan 01's `resolve_does_not_touch_edit_or_cancel_url` asserts the resolver never mutates them, preserving the author's chosen value |
</threat_model>
