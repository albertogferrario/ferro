<task type="auto">
  <name>Task 1: Create lang::init() and t()/trans() helpers</name>
  <files>framework/src/lang/init.rs, framework/src/lang/mod.rs</files>
  <action>
Create `framework/src/lang/init.rs` with:

1. **Global Translator storage** using `OnceLock<Translator>`:
   ```
   static TRANSLATOR: OnceLock<Translator> = OnceLock::new();
   ```

2. **`init()` function** that:
   - Reads `LangConfig` from `Config::get::<LangConfig>()` (fallback to `LangConfig::from_env()`)
   - Calls `Translator::load(&config.path, &config.fallback_locale)`
   - On success: stores in `OnceLock`, registers validation bridge via `register_validation_translator(validation_bridge_fn)`
   - On error: logs warning with eprintln (matching session/middleware error pattern) and continues — the app works without translations (validation rules have hardcoded English fallback)
   - The `validation_bridge_fn` is a `fn(&str, &[(&str, &str)]) -> Option<String>` that reads from `TRANSLATOR` + `locale()` and calls `translator.get(locale, key, params)`, returning `Some(result)` if the translator is loaded

3. **`t()` function** (public):
   ```rust
   pub fn t(key: &str, params: &[(&str, &str)]) -> String
   ```
   - Reads `TRANSLATOR` from OnceLock
   - Calls `translator.get(&locale(), key, params)`
   - If no translator loaded, returns key as-is (graceful degradation)

4. **`trans()` function** (public alias for `t()`):
   ```rust
   pub fn trans(key: &str, params: &[(&str, &str)]) -> String
   ```
   Just calls `t(key, params)`. Provides Laravel-familiar naming.

5. **`choice()` function** (public):
   ```rust
   pub fn choice(key: &str, count: i64, params: &[(&str, &str)]) -> String
   ```
   - Uses `TRANSLATOR.get()` + `locale()` to call `translator.choice()`
   - Falls back to key as-is if no translator

Wire into `framework/src/lang/mod.rs`:
- Add `mod init;` declaration
- Add `pub use init::{init as lang_init, t, trans, choice as lang_choice};`
- Keep existing locale/set_locale/LangMiddleware exports unchanged

The `init` function import uses `as lang_init` to avoid collision with the module name pattern. The `choice` uses `as lang_choice` to avoid collision with any existing `choice` in scope.
  </action>

  <done>init.rs created with OnceLock Translator, init() loads from LangConfig, t()/trans()/choice() work, validation bridge auto-registered</done>
</task>
