# Phase 122.2 Plan 07: app.yaml Renderer + do:init Rewrite Summary

New `.do/app.yaml` starter renderer plus rewritten `ferro do:init` command. Replaces the obsolete Phase 122/124 `do:init` (which generated regions, repos, ci.yml, and databases blocks) with a one-shot starter that defers ongoing ownership to the user.

## What Shipped

- **`AppYamlContext` + `render_app_yaml`** (`ferro-cli/src/templates/do.rs`): pure string substitution over `files/do/app.yaml.tpl`. Caller resolves package name, repo, bins, and env keys upfront.
- **`sanitize_do_app_name`**: lowercase → `_`/space → `-` → strip non-`[a-z0-9-]` → collapse runs of dashes → trim. Documented as the only sanitizer kept (DO requires it).
- **`parse_git_remote`**: HTTPS and SSH GitHub URLs → `owner/repo`, `.git` suffix optional. Non-GitHub remotes → `None`.
- **`is_test_like_bin`**: filters bins beginning with `test_`/`test-`/`dev_`/`dev-`/`debug_`/`debug-`. In-source comment names it the ONLY surviving Phase 122.2 heuristic.
- **`app.yaml.tpl`**: starter matching SCOPE §4 verbatim — `region: fra1` hardcoded, `services` block with `web`, `{{WORKERS_BLOCK}}`/`{{ENV_COMMENTS}}` placeholders, no `databases:` block.
- **`commands/do_init.rs` rewrite**: discovers project root, sanitizes package name, auto-detects GitHub repo via `git remote get-url origin` (HTTPS/SSH parsed), reads `[[bin]]` entries via `templates::docker::read_bins`, filters workers, hard-errors when `.env.production` is missing with the SCOPE §4 suggestion text, then renders + writes `.do/app.yaml` with `--force` semantics. **Does NOT touch `.github/workflows/ci.yml`.**

`main.rs` already exposes `do:init` with only `--force`; no clap changes were required.

## Deviations from Plan

**[Rule 3 - Blocker] Module ident `do_` mapped to file `do.rs` via `#[path]`.**
- **Found during:** Task 1
- **Issue:** Plan suggested using `do_` as the Rust ident; file is `do.rs`. Without `#[path]`, Rust would look for `do_.rs` and fail.
- **Fix:** Declared `#[path = "do.rs"] pub mod do_;` in `templates/mod.rs`.
- **Files modified:** `ferro-cli/src/templates/mod.rs`
- **Commit:** `04f8cac6`

**[Rule 3 - Blocker] Plan referenced helpers that don't exist on `project.rs`.**

- **Fix:** Used the real API names in `do_init.rs`. No new helpers added.
- **Files modified:** `ferro-cli/src/commands/do_init.rs`
