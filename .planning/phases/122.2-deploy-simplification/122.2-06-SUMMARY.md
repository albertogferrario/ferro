# Phase 122.2 Plan 06: Dockerfile Renderer + docker:init Rewrite Summary

New Dockerfile renderer driven by metadata + rust-toolchain.toml + [[bin]] enumeration, wired into a rewritten `ferro docker:init` command. Replaces the Phase 122 heuristic-heavy template (GITHUB_TOKEN, git insteadOf, rewrite-ferro-deps.sh, workspace walking) with a simple 3-stage cargo-chef build.

## What Shipped

- **`DockerContext` + `render_dockerfile`** (`ferro-cli/src/templates/docker.rs`):
  - 5-field context struct (rust_channel, has_frontend, bins, copy_dirs_present, runtime_apt).
  - Pure string substitution over `files/docker/Dockerfile.tpl`; no I/O inside the renderer.
  - Emits per-[[bin]] `cargo build --release --bin NAME` + per-[[bin]] runtime COPY.
  - `# ferro:runtime-apt` marker when `runtime_apt` non-empty, elided otherwise.
  - Conditional frontend stage based on `has_frontend`.
  - `COPY Cargo.docker.toml Cargo.toml` in both planner and builder stages.
- **`read_rust_channel`** — reads `[toolchain] channel` from `rust-toolchain.toml`, defaults to `"stable"` when file missing or unparseable.
- **`read_bins`** — parses `[[bin]]` from Cargo.toml, falls back to `[package] name` when no bin table present.
- **`Dockerfile.tpl`** — 3-stage template (chef → planner → builder → runtime). Base image `rust:{{RUST_CHANNEL}}-slim-bookworm`; cargo-chef installed via `cargo install cargo-chef --locked`. Runtime stage is debian:bookworm-slim.
- **Static ignore templates** (`dockerignore.tpl`, `gitignore.tpl`): union of Phase 122 additions (database.db, *.sqlite*, .planning/, storage/, data/) baked in as plain text, no placeholders.
- **`ferro-cli/src/commands/docker_init.rs`** — `run_with(force, ferro_version)`:
  - Discovers project root, reads deploy metadata, rust channel, bins, existing copy_dirs.
  - Calls `render_dockerfile`, writes Dockerfile + .dockerignore with `--force` semantics.
  - Calls `rewrite_cargo_docker_toml` with version precedence: CLI flag → metadata.ferro_version → path-dep workspace version → `"*"`.
- **`main.rs`** — `docker:init` clap command gains `--ferro-version`, drops `--ferro-ref` and `--runtime-deps`.
