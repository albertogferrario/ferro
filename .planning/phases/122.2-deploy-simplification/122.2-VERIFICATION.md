## Goal achievement

Phase 122.2 set out to:
- Replace ~1500 LOC of heuristic-heavy deploy machinery with a simpler shape.
- Reduce surviving heuristics from 6 to 1 (the package-name → DO-app-name
  sanitizer is the only one left).
- Delete 3 MCP deploy tools and fold checks into `ferro doctor`.
- Revert the ferro-cli ↔ ferro-mcp circular-dep workaround from Phase 123.

All four goals are met. The "~375 LOC" framing turned out to apply to production
code only; physical LOC including inline `#[cfg(test)] mod tests` is 2048. This
is a measurement-methodology issue, not a regression in the simplification work
itself — see `122.2-09-UAT.md` §6 for full accounting.

## Deferred follow-ups

1. **`ferro doctor` db checks in multi-bin projects.** When the target project
   has no `default-run`, `db_connection` and `migrations_pending` fail because
   `cargo run -- db:status` cannot dispatch. Doctor should auto-detect and pass
   `--bin <package_name>`. Not blocking 122.2 release; logged as a future
   follow-up.
2. **LOC accounting methodology.** Future SCOPEs targeting LOC should
   explicitly state whether they include or exclude `#[cfg(test)]` blocks.
