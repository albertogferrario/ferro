# Phase 122.2 Plan 05: Deploy Primitives Summary

Three small primitives the new Phase 122.2 deploy renderers (Plans 06, 07, 08) will consume: a `[package.metadata.ferro.deploy]` reader with sensible defaults, a key-only `.env.production` parser, and a path→version Cargo.toml rewriter that produces `Cargo.docker.toml`.

## What Shipped

- **`FerroDeployMetadata` + `read_deploy_metadata`** (`ferro-cli/src/project.rs`):
  - Reads `[package.metadata.ferro.deploy]` from a project Cargo.toml.
  - Defaults: `runtime_apt = []`, `copy_dirs = ["themes","lang","public","migrations"]`, `ferro_version = None`.
  - Missing table → defaults; field type errors bubble as `anyhow::Error`.
- **`read_env_production_keys`** (`ferro-cli/src/deploy/env_production.rs`):
  - ~25 LOC of logic. Yields `Vec<String>` of keys, no value parsing.
  - Skips blanks and `#` comment lines, trims keys, ignores lines without `=`.
  - Hard-errors when the file is missing (per SCOPE §5: `do:init` must yell loudly).
- **`rewrite_cargo_docker_toml`** (`ferro-cli/src/deploy/rewrite_ferro_version.rs`):
  - Walks `[dependencies]`, `[dev-dependencies]`, `[build-dependencies]`.
  - For every entry whose key starts with `ferro` and whose value is an inline table containing `path`, replaces the value with `{ version = "X" }`.
  - Version resolution: `ferro_version_override` → path-dep's `package.version` → `"*"`.
  - Writes `<project_root>/Cargo.docker.toml`, returns its `PathBuf`.
  - Non-ferro deps untouched.
