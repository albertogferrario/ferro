  <action>
1. In ferro-broadcast/Cargo.toml, change `tokio-tungstenite = "0.26"` to `tokio-tungstenite = "0.28"`.

2. In message.rs, the existing types (BroadcastMessage, ClientMessage, ServerMessage) use serde for JSON serialization to/from `String`. The tungstenite 0.28 change is that `Message::Text` now wraps `Utf8Bytes` instead of `String`. This does NOT affect the serde types themselves — they serialize to `String` via serde_json. The adaptation needed is:
   - Add a `use tokio_tungstenite::tungstenite::protocol::Message as WsMessage;` import.
   - Add convenience methods on `ServerMessage` and `BroadcastMessage` to convert to `WsMessage`:
     ```rust
     pub fn to_ws_message(&self) -> Result<WsMessage, serde_json::Error> {
         let json = serde_json::to_string(self)?;
         Ok(WsMessage::Text(json.into()))
     }
     ```
   - Add a `ClientMessage::from_ws_text` method that takes `&str` and returns `Result<ClientMessage, serde_json::Error>` using `serde_json::from_str`.

These methods keep the WS-specific conversion out of the connection handler, making it cleaner.

3. Verify the existing tests in message.rs still pass. They only test serde serialization to String, which is unchanged.

<task type="auto">
  <name>Task 2: Add whisper forwarding to broadcaster</name>
  <files>ferro-broadcast/src/broadcaster.rs</files>
  <action>
Add a `whisper` method to Broadcaster that forwards client events to other subscribers of the same channel (excluding the sender). This is needed for client-to-client messaging (typing indicators, cursor positions, etc.).

```rust
pub async fn whisper(
    &self,
    socket_id: &str,
    channel_name: &str,
    event: &str,
    data: serde_json::Value,
) -> Result<(), Error> {
    // Check client events are allowed
    if !self.inner.config.allow_client_events {
        return Err(Error::Other("Client events are not allowed".into()));
    }

    // Verify client is subscribed to the channel
    let channel = self.inner.channels.get(channel_name)
        .ok_or_else(|| Error::ChannelNotFound(channel_name.to_string()))?;
    if !channel.subscribers.contains(socket_id) {
        return Err(Error::ClientNotConnected(format!(
            "Client {} is not subscribed to {}", socket_id, channel_name
        )));
    }
    drop(channel); // Release DashMap guard before await

    // Forward as a BroadcastMessage to all channel subscribers except sender
    let msg = BroadcastMessage::with_data(channel_name, event, data);
    let server_msg = ServerMessage::Event(msg);
    self.send_to_channel_except(channel_name, socket_id, &server_msg).await;

    Ok(())
}
```

Key: Drop the DashMap guard BEFORE the async `send_to_channel_except` call to avoid deadlocks (consistent with existing pattern in `subscribe`). Only allow whisper if `config.allow_client_events` is true.
