  <action>
Create `docs/src/features/broadcasting.md` covering:

1. **Overview** — What broadcasting provides: real-time WebSocket channels with public/private/presence support

2. **Setup** — How to register the Broadcaster in bootstrap.rs:
```rust
use ferro::{Broadcaster, BroadcastConfig};

let broadcaster = Broadcaster::with_config(BroadcastConfig::from_env());
App::singleton(broadcaster);
```

3. **Channel Types** — Public (no prefix, no auth), Private ("private-" prefix, requires auth), Presence ("presence-" prefix, tracks members)

4. **Channel Authorization** — Implementing ChannelAuthorizer trait:
```rust
use ferro::{ChannelAuthorizer, AuthData};

struct AppChannelAuth;

#[async_trait::async_trait]
impl ChannelAuthorizer for AppChannelAuth {
    async fn authorize(&self, data: &AuthData) -> bool {
        let user_id = data.auth_token.as_deref();
        match data.channel.as_str() {
            c if c.starts_with("private-orders.") => {
                // Check user owns the order
                true
            }
            _ => false,
        }
    }
}
```

5. **Routes** — Registering the broadcasting auth endpoint:
```rust
use ferro::broadcasting_auth;

Route::post("/broadcasting/auth", broadcasting_auth)
    .middleware(SessionAuthMiddleware);
```

6. **Broadcasting from Handlers** — Sending events:
```rust
use ferro::{Broadcast, Broadcaster};

let broadcaster = App::get::<Broadcaster>().unwrap();
Broadcast::new(broadcaster)
    .channel("orders.1")
    .event("OrderUpdated")
    .data(&order)
    .send()
    .await?;
```

7. **Client Connection** — JavaScript WebSocket client example:
```javascript
const ws = new WebSocket('ws://localhost:8080/_ferro/ws');

ws.onopen = () => {
    // Subscribe to public channel
    ws.send(JSON.stringify({ type: "subscribe", channel: "orders" }));
};

ws.onmessage = (event) => {
    const msg = JSON.parse(event.data);
    switch (msg.type) {
        case "connected":
            console.log("Socket ID:", msg.socket_id);
            break;
        case "event":
            console.log("Event:", msg.event, msg.data);
            break;
    }
};
```

8. **Private Channel Auth Flow** — Step-by-step: client connects → gets socket_id → subscribes with auth → server calls /broadcasting/auth → server checks authorizer → subscribes client

9. **Whisper (Client Events)** — Sending client-to-client messages:
```javascript
ws.send(JSON.stringify({
    type: "whisper",
    channel: "private-chat.1",
    event: "typing",
    data: { name: "Alice" }
}));
```

10. **Configuration** — Environment variables (BROADCAST_MAX_SUBSCRIBERS, BROADCAST_HEARTBEAT_INTERVAL, etc.)

Follow the same code-heavy, practical style as authentication.md and rate-limiting.md docs.
