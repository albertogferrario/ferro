No write execution and no authorization are introduced. The NTI envelope is an inert,
non-executing response. Write authz + tenant injection are Phase 242; execution is Phase 241.

| T-240-09 | Denial of Service (protocol) | Phase 205 regression guard | mitigate | Returning `CallToolResult::structured` (not a `-32601` JSON-RPC error) keeps every `tools/call` result a valid MCP `content[]` envelope, preventing client-side protocol breakage; covered by both the new CRUD-verb test and the unchanged list_ guard. |
