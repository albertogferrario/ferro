<task type="auto">
  <name>Task 1: Create json_ui_catalog MCP tool</name>
  <files>ferro-mcp/src/tools/json_ui_catalog.rs, ferro-mcp/src/tools/mod.rs, ferro-mcp/src/service.rs</files>
  <action>
Create `ferro-mcp/src/tools/json_ui_catalog.rs` following the same pattern as `code_templates.rs`.

The tool returns a structured catalog of all 20 JSON-UI components. Use the COMPONENT_CATALOG from `ferro-cli/src/ai.rs` as the source of truth but structure it as typed Rust structs (not a raw string).

Output types:
```
JsonUiCatalog { components: Vec<CatalogComponent>, builder_api: String, action_api: String }
CatalogComponent { name, description, props: Vec<PropInfo>, variants: Option<Vec<String>> }
PropInfo { name, type_name, required: bool, description }
```

Accept an optional `component` filter parameter. When provided, return only the matching component (case-insensitive match). When omitted, return the full catalog.

Cover all 20 components: Text, Button, Card, Table, Form, Input, Select, Alert, Badge, Modal, Checkbox, Switch, Separator, DescriptionList, Tabs, Breadcrumb, Pagination, Progress, Avatar, Skeleton.

Also include Action and ComponentNode as separate sections (builder_api and action_api fields as readable strings with builder methods).

Register in service.rs:
- Params: `JsonUiCatalogParams { component: Option<String> }`
- Tool name: `json_ui_catalog`
- Description: should explain when to use (understanding available components, building JSON-UI views, checking prop names and types) and what it combines with (json_ui_inspect, json_ui_generate, code_templates with category json_view)

Add `pub mod json_ui_catalog;` to tools/mod.rs.

Include unit tests: test_all_components_present (20 components), test_filter_by_component, test_serialization, test_unknown_component_returns_empty.
  </action>
  <verify>cargo test -p ferro-mcp --lib json_ui_catalog -- passes all tests</verify>
  <done>json_ui_catalog tool registered in service.rs, returns structured catalog of all 20 components, filters by component name, serializes to JSON</done>
</task>
