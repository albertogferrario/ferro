<objective>
Extend the renderer-free `ferro-projections` schema crate with the three surface
additions a future non-visual renderer (Phase 216) needs, satisfying CHAN-01 and
CHAN-02 at the type-surface level:

1. `BaseContext` gains `evaluated_guards: HashMap<String, bool>` and
   `verbosity: Verbosity`, with a new `Verbosity { Brief, Full }` enum (default
   `Full`). (CHAN-01, D-01/D-03/D-04/D-05)
2. `Intent::label() -> &str` returns a stable lowercase label decoupled from
   `#[derive(Debug)]`. (CHAN-02, D-06)
3. `Error::NoIntents` is added so an empty intents slice maps to a typed error
   instead of a silent `"unknown"`. (CHAN-02, D-08)

Purpose: establish the modality-agnostic surface before any adopter changes, so
the crate compiles and tests green in isolation (`cargo test -p ferro-projections`)
before Wave 2 (Plan 02) migrates downstream consumers.

Output: extended `BaseContext`, new `Verbosity` enum, `Intent::label()`,
`Error::NoIntents`, and their unit tests — all within `ferro-projections`. NO
renderer added (boundary rule: `ferro-projections/CLAUDE.md`).

Boundary: do NOT touch the seven-intent vocabulary variants in `intent.rs`
(Browse/Focus/Collect/Process/Summarize/Analyze/Track + Custom stay exactly as
they are; `label()` is purely additive). Do NOT add serde to `Verbosity`
(BaseContext has no serde derives — keep it consistent). Do NOT wire
`Error::NoIntents` into the visual render path (D-09 — that path keeps
`ProjectionError::EmptyIntents`).
</objective>
