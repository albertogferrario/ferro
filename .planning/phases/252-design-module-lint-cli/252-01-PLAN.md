```rust
/// The seven known projection intents. The drift test (feature "projections")

pub const KNOWN_INTENTS: &[&str] =
    &["browse", "focus", "collect", "process", "summarize", "analyze", "track"];

```
Implement `pub fn lint(spec: &Spec) -> Vec<Finding>` with EXACTLY this orchestration (concrete contract — downstream plans depend on it):
1. `let design = spec.design.as_ref();` `let allow: &[String] = design.map(|d| d.allow.as_slice()).unwrap_or(&[]);`
2. Resolve intent:
   - declared `Some(s)` and `KNOWN_INTENTS.contains(&s)` → `resolved = Some(s)`, no finding.
   - declared `Some(s)` NOT known → push Warning `Finding { rule: "declare-intent", element_id: None, severity: Warning, message: format!("Unknown design.intent `{s}`; expected one of the seven projection intents."), suggestion: "Use one of: browse, focus, collect, process, summarize, analyze, track." }`; `resolved = infer::infer_intent(spec)`.
   - `None` → `let inferred = infer::infer_intent(spec);` push Info `Finding { rule: "declare-intent", ..., severity: Info, message: (Some(i) => format!("No design.intent declared; inferred `{i}` from spec content."), None => "No design.intent declared and none could be inferred from spec content.".into()), suggestion: "Add a `design.intent` field to declare the page archetype." }`; `resolved = inferred`.
3. Validate allow ids — known set = `RULE_REGISTRY` ids ∪ `{"declare-intent"}`:
   `for id in allow { if !(RULE_REGISTRY.iter().any(|r| r.id == id) || id == "declare-intent") { push Warning Finding { rule: "allow", element_id: None, severity: Warning, message: format!("Unknown allow id `{id}`."), suggestion: "Remove it or fix the typo; allow ids must match a rule id." } } }`
4. Run rules: `for rule in RULE_REGISTRY { if !rule.intents.is_empty() { match resolved { Some(i) if rule.intents.contains(&i) => {}, _ => continue } } findings.extend((rule.check)(spec, resolved)); }`
5. Suppress allow-listed findings: `findings.retain(|f| !allow.iter().any(|a| a == f.rule));`
Return `findings`. Use only `.get()`/`.and_then()` on `Value` — never `.unwrap()` (Pitfall 2). `lint()` performs no I/O and never returns an error.
