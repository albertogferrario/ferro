Define the stable `--json` envelope (flat array, `file` field per finding — RESEARCH Pattern 5):
```rust
/// One finding tagged with the file it came from. This flat shape is the stable
/// `--json` contract consumed by downstream CI (gestiscilo Phase 232).
#[derive(Serialize)]
pub struct FileFinding {
    pub file: String,
    #[serde(flatten)]
    pub finding: Finding,
}
```

`pub(crate) fn lint_content(file: &str, content: &str) -> Vec<FileFinding>`:
- if `!content.contains(SCHEMA_VERSION)` → `return Vec::new()` (skip non-ferro files silently).
- `match Spec::from_json(content)`:
  - `Ok(spec)` → `lint(&spec).into_iter().map(|finding| FileFinding { file: file.to_string(), finding }).collect()`.
  - `Err(e)` → one warning file-diagnostic: `vec![FileFinding { file: file.to_string(), finding: Finding { rule: "spec-parse", element_id: None, severity: Severity::Warning, message: format!("Failed to parse spec: {e:?}"), suggestion: "Fix the spec so it parses as ferro-json-ui/v2.".into() } }]`.

`pub(crate) fn has_warning(findings: &[FileFinding]) -> bool`:
`findings.iter().any(|f| matches!(f.finding.severity, Severity::Warning))`.

`pub fn run(path: Option<String>, json: bool, deny: bool)`:
- `let root = path.map(PathBuf::from).unwrap_or_else(|| PathBuf::from("src/views"));`
- Walk `*.json` under `root` (WalkDir; `follow_links` left at the default `false` — do NOT enable symlink following, keeps the walk confined to `root`), read each with `std::fs::read_to_string`, call `lint_content(&path.display().to_string(), &content)`, collect all into `Vec<FileFinding>`.
- If `json` → `println!("{}", serde_json::to_string_pretty(&all).unwrap_or_else(|_| "[]".into()))`. Else human output: group by `file`; for each file with findings print a styled header then, per finding, a line with severity (Warning → red/yellow, Info → dim/cyan), `rule`, `message`, and an indented `suggestion`; finish with a summary count line. If no findings at all, print a styled "clean" line.
- `if deny && has_warning(&all) { std::process::exit(1); }`.

Register the module (edit `ferro-cli/src/commands/mod.rs`): add `pub mod design_lint;` in alphabetical order (between `pub mod db_sync;` and `pub mod deploy_init;`).

| on-disk `*.json` content → Spec::from_json → lint | Untrusted file content; parse must not panic |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-252-01 | Information Disclosure (path traversal / symlink escape) | WalkDir over user `path` | mitigate | WalkDir with default `follow_links(false)` — symlinks are not traversed, the walk stays within `root`; acceptance-checked (no `follow_links(true)`) |
| T-252-02 | Denial of Service | `Spec::from_json` on malformed/huge JSON files | mitigate | parse errors are caught and turned into a warning file-diagnostic (never a panic); `from_json` caps nesting depth (existing) |
| T-252-06 | Tampering (silent CI pass) | `--deny` gate | mitigate | `has_warning` trips on ANY warning-level finding incl. `spec-parse` and unknown-`allow`; info never fails — unit-tested |
