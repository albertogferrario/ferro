Add the final two `DesignRule` entries and check fns (verbatim metadata):

```rust
DesignRule {
    id: "form-default-values",
    title: "Edit-form fields pre-fill from data",
    rationale: "On an edit form every field must restore its stored value; a blank field silently discards data on save.",
    intents: &["collect"],
    check: check_form_default_values,
},
DesignRule {
    id: "destructive-confirmation",
    title: "Destructive actions require confirmation",
    rationale: "An irreversible action behind a single click is a data-loss hazard; a confirm dialog is the guard.",
    intents: &[],                       // all intents
    check: check_destructive_confirmation,
},
```

Check logic:
- `check_form_default_values`: form-field types = `["Input", "Select", "Textarea", "RichTextEditor"]`. A field "binds default_value via $data" when `el.props.get("default_value").and_then(|v| v.get("$data")).is_some()`. Compute `is_edit_form = spec.elements.values().any(|e| FIELD_TYPES.contains(&e.type_name.as_str()) && e.props.get("default_value").and_then(|v| v.get("$data")).is_some())`. If `!is_edit_form` → `return vec![]` (pure create form). Else for each `(id, el)` that is a field type where `el.props.get("default_value").map(Value::is_null).unwrap_or(true)` (missing or null default_value) → Warning `{ rule: "form-default-values", element_id: Some(id.clone()), severity: Warning, message: format!("Edit-form field `{id}` has no default_value."), suggestion: "Pre-fill the field: bind default_value via a $data path (e.g. req.old(..).or_else(|| record.field))." }`.
- `check_destructive_confirmation`: for each `(id, el)`:
  - element-level: `if el.type_name == "Button" && el.props.get("variant").and_then(Value::as_str) == Some("destructive")` then `if let Some(action) = &el.action { if action.confirm.is_none() { push Warning element_id Some(id) } }`.
  - props-embedded: for `key in ["row_actions", "items"]`: `if let Some(arr) = el.props.get(key).and_then(Value::as_array) { for entry in arr { if entry.get("destructive").and_then(Value::as_bool) == Some(true) && entry.get("confirm").is_none() { push Warning element_id Some(id) } } }`.
  Warning shape: `{ rule: "destructive-confirmation", element_id: Some(id.clone()), severity: Warning, message: "Destructive action has no confirmation.", suggestion: "Add a `confirm` (ConfirmDialog) to the action before it runs." }`. De-duplicate so one element produces at most one destructive-confirmation finding (a `let mut flagged = false;` guard per element, or push once).

Add the violating + conforming tests from the behavior block. Include the pure-create-form conforming case shaped like login.json (an Input with `data_path` + `error` but no `default_value`) to lock the app-views-clean expectation.
