In `app/src/models/users.rs`, add a `find_by_email` static method:
```rust
impl Model {
    pub async fn find_by_email(email: &str) -> Result<Option<Self>, ferro::FrameworkError> {
        Self::query().filter(Column::Email.eq(email)).first().await
    }
}
```

In `app/src/providers/auth_provider.rs`, implement the two default-no-op methods on `DatabaseUserProvider`:

1. `retrieve_by_credentials` — expects JSON with `"email"` key, queries user by email, returns as `Arc<dyn Authenticatable>`
2. `validate_credentials` — expects JSON with `"password"` key, verifies password against user's stored hash using `ferro::verify()` (the framework's bcrypt wrapper)

The validate_credentials method needs access to the password field. Since `Authenticatable` is a trait object, downcast to `Model` using `as_any().downcast_ref::<Model>()` to access `self.password`.

Import `ferro::verify` for password checking (re-exported from `framework/src/hashing/mod.rs`).

Do NOT add `use ferro::hash` here — hashing happens in the register controller (Plan 02).
