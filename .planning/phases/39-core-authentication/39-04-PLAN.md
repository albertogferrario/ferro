  <files>docs/src/features/authentication.md</files>
  <action>
Create `docs/src/features/authentication.md` following the style of existing docs pages (e.g., validation.md).

Structure:

1. **Introduction** — Session-based auth overview, what Ferro provides

2. **Quick Start** — `ferro make:auth` command, what it scaffolds

3. **Configuration**
   - Session config (env vars: SESSION_LIFETIME, SESSION_COOKIE, SESSION_SECURE, etc.)
   - Password hashing (bcrypt, DEFAULT_COST of 12)

4. **The Authenticatable Trait**
   - Implementing on your User model
   - `auth_identifier()`, `as_any()` methods
   - Example implementation

5. **User Provider**
   - `UserProvider` trait with 3 methods
   - `retrieve_by_id` (required)
   - `retrieve_by_credentials` (optional, for email-based lookup)
   - `validate_credentials` (optional, for password checking)
   - Registration in bootstrap.rs with `bind!`
   - Example `DatabaseUserProvider`

6. **Auth Facade**
   - `Auth::check()`, `Auth::guest()`, `Auth::id()`, `Auth::id_as::<T>()`
   - `Auth::login(user_id)` — session regeneration for security
   - `Auth::logout()`, `Auth::logout_and_invalidate()`
   - `Auth::attempt()` — async credential validation with auto-login
   - `Auth::validate()` — validate without login (password confirmation)
   - `Auth::user()`, `Auth::user_as::<T>()` — retrieve current user

7. **Password Hashing**
   - `ferro::hash(&password)` — bcrypt with default cost 12
   - `ferro::verify(&password, &hash)` — constant-time comparison
   - `ferro::needs_rehash(&hash)` — check if rehashing needed

8. **Middleware**
   - `AuthMiddleware::new()` — 401 for APIs
   - `AuthMiddleware::redirect_to("/login")` — redirect for web
   - `GuestMiddleware::redirect_to("/dashboard")` — protect login/register pages
   - Inertia-aware redirects (409 + X-Inertia-Location)

9. **Login & Registration Example**
   - Complete register handler (validate, hash, insert, login)
   - Complete login handler (validate, attempt, respond)
   - Complete logout handler
   - Route registration with middleware

10. **Security**
    - Session fixation protection (ID regeneration on login)
    - CSRF token regeneration
    - Bcrypt constant-time comparison
    - HttpOnly cookies
    - SameSite cookie protection

Keep the documentation scientific and concise per CLAUDE.md instructions — no marketing language.
