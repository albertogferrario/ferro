<task type="auto">
  <name>Task 1: Create auth controller with register, login, and logout handlers</name>
  <files>app/src/controllers/auth_controller.rs, app/src/controllers/mod.rs</files>
  <action>
Create `app/src/controllers/auth_controller.rs` with three handlers:

**register handler:**
- `#[handler] pub async fn register(req: Request) -> Response`
- Parse JSON body with `name`, `email`, `password`, `password_confirmation` fields
- Validate: name required, email required + valid email + unique in users table, password required + min 8 chars, password_confirmation matches password
- Hash password with `ferro::hash(&password)?`
- Insert new user via SeaORM ActiveModel
- Log in with `Auth::login(user.id as i64)`
- Return 201 JSON with user data (id, name, email — NOT password)

**login handler:**
- `#[handler] pub async fn login(req: Request) -> Response`
- Parse JSON body with `email`, `password` fields
- Validate: email required, password required
- Use `Auth::attempt()` with closure that calls `User::find_by_email()` then `ferro::verify()`
- On success: return 200 JSON with user data
- On failure: return 422 JSON with `{"email": ["These credentials do not match our records."]}`

**logout handler:**
- `#[handler] pub async fn logout(_req: Request) -> Response`
- Call `Auth::logout()`
- Return 200 JSON with `{"message": "Logged out successfully."}`

Add `pub mod auth_controller;` to `app/src/controllers/mod.rs`.

Follow existing controller patterns in the codebase. Use `serde::Deserialize` for input structs. Use `ferro::Validator` for validation with `rules![]` macro.

For the unique email validation in register, query the database directly: `User::find_by_email(&email).await?` and add a custom error if found.

<task type="auto">
  <name>Task 2: Register auth routes with middleware</name>
  <files>app/src/routes.rs</files>
  <action>
Add auth routes to the application's route file. Follow the existing route registration pattern.

Add these route groups:

**Guest routes** (only accessible to non-authenticated users):
```rust
group!("/auth")
    .middleware(GuestMiddleware::redirect_to("/"))
    .routes([
        post!("/register", auth_controller::register),
        post!("/login", auth_controller::login),
    ])
```

**Authenticated routes:**
```rust
post!("/auth/logout", auth_controller::logout).middleware(AuthMiddleware::new())
```

The logout route uses `AuthMiddleware::new()` (returns 401 for non-authenticated) rather than redirect since it's an API-style endpoint.

Import `AuthMiddleware`, `GuestMiddleware`, `group!`, `post!` as needed — check existing imports in routes.rs for the pattern used.
