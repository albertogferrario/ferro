## Accumulation mechanism

| Option | Description | Selected |
|--------|-------------|----------|
| Shared logical-line pre-pass | Join multi-line `#[service(...)]` into one logical line before both scan loops; least invasive to the offload state machine | ✓ |
| Inline paren-depth accumulation in each loop | Extend both loops' bodies to accumulate lines until balanced | |
| Migrate to `syn` AST attribute parse | Replace line-based scanning with a real parser | |

**Auto choice:** Shared logical-line pre-pass, staying line-based (D-01, D-02).
**Notes:** Reuses the paren-depth balancing already in `extract_inner_params` / `FnCollecting`.
`syn` migration rejected — contradicts Phase 249 D-04 (deliberate line-based static parsing).
