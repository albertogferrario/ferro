## Changes Made

### Modified Files
- `ferro-cli/src/templates/files/root/gitignore.tpl` - Added generated types exclusion

### What Changed
Added a new section to the gitignore template:
```gitignore
# Generated types (regenerated by ferro generate-types)
frontend/src/types/
```

This excludes the entire `frontend/src/types/` directory because:
- Both generated files (`inertia-props.ts`, `routes.ts`) live there
- Users shouldn't add manual files to this directory
- Cleaner than listing individual files

## Verification

- Template test passes: `cargo test -p ferro-cli test_gitignore_not_empty`
- Generated types exclusion present in template

## Impact

New projects created with `ferro new` will automatically have generated types excluded from git tracking. Existing projects are unaffected and can manually update their `.gitignore` if desired.
