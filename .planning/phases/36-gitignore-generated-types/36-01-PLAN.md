# Plan 36-01: Gitignore Generated Types

## Metadata
- **Phase**: 36 - Gitignore Generated Types
- **Milestone**: v2.2 CLI Improvements
- **Created**: 2026-01-18
- **Scope**: XS (~15 min, 1 task)

## Objective

Update the project template .gitignore to exclude generated TypeScript type files. These files are:
- `frontend/src/types/inertia-props.ts` - Generated from `#[derive(InertiaProps)]` structs
- `frontend/src/types/routes.ts` - Generated route definitions

These files are derived artifacts regenerated by `ferro generate-types` and automatically during `ferro serve`, so they should not be version controlled.

## Context

### Discovery Findings

**Template Location**: `ferro-cli/src/templates/files/root/gitignore.tpl`

**Current gitignore template** (line 1-20):

```gitignore
# Rust

frontend/node_modules
frontend/dist

# Build outputs
/public/assets

# IDE
.idea

.env

.env.*.local
```

**Generated files** (from `ferro-cli/src/commands/generate_types.rs`):
- Line 938: `project_path.join("frontend/src/types/inertia-props.ts")`
- Line 982: `project_path.join("frontend/src/types/routes.ts")`

### Rationale

Generated types should be excluded because:
1. They are derived from Rust source (single source of truth)
2. They are regenerated on every `ferro serve` startup
3. Including them creates noisy diffs and merge conflicts
4. They can be regenerated anytime with `ferro generate-types`
