```rust
//! Shared interactive-base class fragments. Single source of truth for the
//! focus-visible ring, disabled treatment, and frequency-tiered motion, composed
//! into each component's class string so the interactive feel cannot drift.

/// focus-visible ring from the `--color-ring` token (D-14). ring-2 + offset-2 baseline.
pub(crate) const FOCUS_RING: &str =
    "focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-ring focus-visible:ring-offset-2";

/// Fast tier (D-03): hover, toggles, controls, nav — high-frequency interactions.
pub(crate) const MOTION_FAST: &str = "transition-colors duration-fast ease-base";

/// Base tier (D-03): dropdowns, modals, toasts.
pub(crate) const MOTION_BASE: &str = "transition-opacity duration-base ease-base";

/// Uniform disabled treatment for native controls (D-16).
pub(crate) const DISABLED_BASE: &str = "disabled:opacity-50 disabled:pointer-events-none";

/// Fast-tier interactive base = fast motion + focus ring, for buttons/links/nav.
pub(crate) const INTERACTIVE_BASE: &str = concat!(
    "transition-colors duration-fast ease-base ",
    "focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-ring focus-visible:ring-offset-2"
);
```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| data attributes → runtime JS | Toast/tab runtime JS reads DOM attributes/classes the SSR emitted and toggles class strings |
| props → HTML markup | User labels rendered into interactive elements |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-251-02 | Tampering (XSS) | Toast/tab runtime JS class toggling | mitigate | JS toggles a fixed set of class-string literals (`classList.add/remove` of constants) keyed off attributes; no attribute value is interpolated into a class or into innerHTML. The `transitionend` dismissal removes the node, it does not render attribute-derived markup. |
| T-251-03 | Tampering (XSS) | Labels in migrated interactive render sites | mitigate | `html_escape` on all user content preserved while editing class strings; only server-controlled class literals change. |
| T-251-05 | Denial of Service | Toast dismissal via `transitionend` under reduced motion | mitigate | Phase 250 collapses durations to `0.01ms` (not `none`), so `transitionend` still fires; a 500ms fallback timeout guarantees removal even if the event is missed — no stuck/leaking toast nodes. |
</threat_model>
