<objective>
Establish the single canonical component vocabulary as the compiler-enforced substrate for
the whole phase. Define three shared enums — `Variant` (weight), `Tone` (status), `Size` — plus
the renamed `CardAppearance`, delete the seven per-component weight/status/size enums, normalize
the action-level `variant` fields to `tone`, and ripple the rename through every ferro-json-ui
consumer, the framework facade re-exports, the projection emitters, the toast JS/SSR lockstep,
and the sample-app JSON specs until `cargo build --workspace` is green again.

Purpose: "One word, one meaning" (DS-03). After this plan `variant` always means weight, `tone`
always means status, `size` always means sm/md/lg. The compiler drives completeness — deleting the
old enums turns every stale site into a build error.

Output: A compiling workspace on the canonical vocabulary, with the shared enums re-exported
through `ferro::`, ready for the interactive-state pass (Plan 02) and the drift guard (Plan 03).
</objective>

```rust
/// Visual weight of interactive elements (buttons, action items). `primary` is the default.
#[derive(
    Debug, Clone, Copy, Default, PartialEq, Eq, Serialize, Deserialize, JsonSchema, strum::AsRefStr,
)]
#[serde(rename_all = "snake_case")]
#[strum(serialize_all = "snake_case")]
pub enum Variant {
    #[default]
    Primary,
    Secondary,
    Outline,
    Ghost,
    Destructive,
}

/// Semantic status color of stateful display components. `neutral` is the default and
/// reproduces today's non-status look.
#[derive(
    Debug, Clone, Copy, Default, PartialEq, Eq, Serialize, Deserialize, JsonSchema, strum::AsRefStr,
)]
#[serde(rename_all = "snake_case")]
#[strum(serialize_all = "snake_case")]
pub enum Tone {
    #[default]
    Neutral,
    Success,
    Warning,
    Destructive,
}

/// Component size scale. `md` is the default.
#[derive(
    Debug, Clone, Copy, Default, PartialEq, Eq, Serialize, Deserialize, JsonSchema, strum::AsRefStr,
)]
#[serde(rename_all = "snake_case")]
#[strum(serialize_all = "snake_case")]
pub enum Size {
    Sm,
    #[default]
    Md,
    Lg,
}

/// Structural chrome of a Card — NOT a weight or status axis (renamed from `CardVariant`).
#[derive(Debug, Clone, Copy, Default, PartialEq, Eq, Serialize, Deserialize, JsonSchema)]
#[serde(rename_all = "snake_case")]
pub enum CardAppearance {
    #[default]
    Bordered,
    Elevated,
}
```
