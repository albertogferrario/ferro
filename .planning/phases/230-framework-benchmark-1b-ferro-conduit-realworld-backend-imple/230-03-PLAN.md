## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-230-08 | Spoofing | login handler | mitigate | bcrypt verify_password (constant-time); generic failure message, no user-enumeration distinction beyond Conduit spec |
| T-230-09 | Info Disclosure | password in response | mitigate | UserDto has no password field; only DTOs serialized, never raw User model (Pitfall 3) |
| T-230-10 | Tampering | update_user mass-assignment | mitigate | UpdateUserReq is an explicit allow-list of fields; no blanket model deserialization |
| T-230-11 | EoP | current_user/update without token | mitigate | JwtAuthMiddleware gate on the /api/user group; handler re-checks req.get::<UserId>() |
