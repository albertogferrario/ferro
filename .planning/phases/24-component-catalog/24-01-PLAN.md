<task type="auto">
  <name>Task 1: Add shared enums and enrich existing component props</name>
  <files>ferro-json-ui/src/component.rs, ferro-json-ui/src/lib.rs</files>
  <action>
  **Step 1: Add shared enums at the top of component.rs (before component-specific enums):**

  - `Size` enum: `Xs`, `Sm`, `Default` (default), `Lg` — shared across Button, Badge, Avatar, Input
  - `IconPosition` enum: `Left` (default), `Right` — for Button icon placement

  **Step 2: Align ButtonVariant to shadcn/ui:**
  Change from `Primary/Secondary/Danger/Ghost` to `Default/Secondary/Destructive/Outline/Ghost/Link`. Default variant is `Default` (not `Primary`).

  **Step 3: Align AlertVariant to shadcn/ui:**
  Keep `Info/Success/Warning/Error` — these already align well with shadcn/ui's `default/destructive` but Ferro's richer set is more practical for CRUD apps. Rename `Error` to `Destructive` for consistency. Final: `Default` (default), `Destructive`.
  WAIT — research says shadcn Alert only has default/destructive. But for CRUD apps we need more variety. Keep as-is: `Info` (default), `Success`, `Warning`, `Error`. This is a pragmatic deviation from shadcn.

  **Step 4: Align BadgeVariant to shadcn/ui:**
  Change from `Default/Primary/Success/Warning/Error` to `Default/Secondary/Destructive/Outline` per shadcn/ui. Default stays `Default`.

  **Step 5: Add more InputType variants:**
  Add `Date`, `Time`, `Url`, `Tel`, `Search` to the existing `Text/Email/Password/Number/Textarea/Hidden`.

  **Step 6: Enrich ButtonProps:**
  Add fields:
  - `size: Size` (default `Default`)
  - `icon: Option<String>` (Lucide icon name, skip_serializing_if None)
  - `icon_position: Option<IconPosition>` (skip_serializing_if None)

  **Step 7: Enrich CardProps:**
  Add:
  - `footer: Vec<ComponentNode>` (default empty, skip_serializing_if empty) — for action buttons in card footer

  **Step 8: Enrich InputProps:**
  Add:
  - `disabled: Option<bool>` (skip_serializing_if None)
  - `error: Option<String>` (validation error, skip_serializing_if None)
  - `description: Option<String>` (helper text, skip_serializing_if None)
  - `default_value: Option<String>` (pre-filled value, skip_serializing_if None)

  **Step 9: Enrich SelectProps:**
  Add:
  - `disabled: Option<bool>` (skip_serializing_if None)
  - `error: Option<String>` (validation error, skip_serializing_if None)
  - `description: Option<String>` (helper text, skip_serializing_if None)
  - `default_value: Option<String>` (pre-selected value, skip_serializing_if None)

  **Step 10: Enrich AlertProps:**
  Add:
  - `title: Option<String>` (skip_serializing_if None) — shadcn/ui Alert has AlertTitle + AlertDescription

  **Step 11: Enrich ModalProps:**
  Add:
  - `description: Option<String>` (skip_serializing_if None)
  - `footer: Vec<ComponentNode>` (default empty, skip_serializing_if empty) — for action buttons

  **Step 12: Enrich TableProps:**
  Add:
  - `sortable: Option<bool>` (skip_serializing_if None) — whether columns are sortable
  - `sort_column: Option<String>` (skip_serializing_if None) — currently sorted column key
  - `sort_direction: Option<SortDirection>` (skip_serializing_if None)
  Add `SortDirection` enum: `Asc` (default), `Desc`

  **Step 13: Update lib.rs re-exports:**
  Add new public types to the `pub use component::{ ... }` line: `Size`, `IconPosition`, `SortDirection`.

  **Step 14: Update ALL existing tests in component.rs:**
  Tests that construct ButtonProps, BadgeProps, etc. must use the new variant names (e.g., `ButtonVariant::Default` instead of `ButtonVariant::Primary`, `BadgeVariant::Secondary` instead of `BadgeVariant::Primary`). Add the new fields to test constructions where relevant. Test the `button_variant_defaults_to_primary` test should be renamed to `button_variant_defaults_to_default` and check `ButtonVariant::Default`.

  **Important: Use `#[serde(rename_all = "snake_case")]` on all new enums. Use `#[serde(default, skip_serializing_if = "Option::is_none")]` on all new Option fields. Use `#[serde(default, skip_serializing_if = "Vec::is_empty")]` on new Vec fields. Use `#[serde(default)]` on new enum fields with defaults.**

  All new enums need: `Debug, Clone, Default, PartialEq, Eq, Serialize, Deserialize`.
  All new props fields follow existing patterns exactly.
  </action>
  <verify>`cargo test -p ferro-json-ui` passes. `cargo check --workspace` passes.</verify>

</task>
