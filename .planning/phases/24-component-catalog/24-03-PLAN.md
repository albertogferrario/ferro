  current_page: u32
  per_page: u32

  ```
  value: u8            (0-100 percentage)
  max: Option<u8>      (skip_serializing_if None, defaults to 100 when rendering)
  label: Option<String> (skip_serializing_if None)
  ```

  **Step 5: Add AvatarProps struct:**
  ```
  src: Option<String>          (image URL, skip_serializing_if None)
  alt: String                  (always required for accessibility)
  fallback: Option<String>     (initials or text shown when no image, skip_serializing_if None)
  size: Option<Size>           (reuse shared Size enum, skip_serializing_if None)
  ```

  **Step 6: Add SkeletonProps struct:**
  ```
  width: Option<String>   (CSS width, skip_serializing_if None — e.g., "100%", "200px")
  height: Option<String>  (CSS height, skip_serializing_if None — e.g., "1rem", "40px")
  rounded: Option<bool>   (skip_serializing_if None — circular skeleton for avatars)
  ```
