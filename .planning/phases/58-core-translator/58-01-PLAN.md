**ferro-lang/src/loader.rs:**

Implement `load_translations(path: &str, fallback: &str) -> Result<HashMap<String, HashMap<String, String>>, LangError>`:

1. Read the `path` directory to discover locale subdirectories (each subdirectory name = locale identifier)
2. Normalize locale identifiers: lowercase, replace `_` with `-` (so "en_US" → "en-us", "pt-BR" → "pt-br")
3. For each locale directory, read all `*.json` files
4. Parse each JSON file with `serde_json::from_str::<HashMap<String, Value>>()`
5. Flatten nested JSON into dot-notation keys: `{"auth": {"login": "Sign In"}}` → `"auth.login" = "Sign In"`. Only string leaf values are stored; non-string values are skipped with a `tracing::warn!`
6. Merge all JSON files for a locale into a single `HashMap<String, String>`
7. Pre-merge fallback: for each non-fallback locale, insert any fallback keys that the locale is missing. This makes runtime lookup a single HashMap::get with no fallback chain needed.
8. If no translations loaded at all (empty directory), return `Err(LangError::NoTranslationsLoaded)`
9. Log `tracing::info!` with count of locales loaded and total key count

**Important:** Use `std::fs::read_dir` and `std::fs::read_to_string` (sync IO). This runs once at startup, not per-request.

The `get()` and `choice()` methods normalize the locale input before lookup (lowercase, replace _ with -).

**ferro-lang/src/interpolation.rs:**

Implement `pub fn interpolate(template: &str, params: &[(&str, &str)]) -> String`:
- Replace each `:key` in template with corresponding value from params
- Also replace `:Key` (ucfirst) and `:KEY` (uppercase) variants: if param is ("name", "john"), then `:name` → "john", `:Name` → "John", `:NAME` → "JOHN"
- Process longer param names first to avoid partial replacement (sort params by key length descending before replacing)
- If a `:param` placeholder has no matching replacement, log `tracing::warn!("Missing interpolation param '{}' in template", key)` but leave the placeholder as-is (don't error)

**ferro-lang/src/pluralization.rs:**

Implement `pub fn select_plural_form(value: &str, count: i64) -> String`:
- Split value by `|` into forms
- If only 1 form, return it
- If 2 forms: count == 1 → forms[0], else → forms[1]
- If 3+ forms: check for explicit index/range syntax first:
  - `{N}` matches exact count (e.g., `{0}` matches count=0)
  - `[N,M]` matches range N..=M
  - `[N,*]` matches N and above
  - Strip the prefix before returning the form text
  - If no explicit match, fall back to: count == 1 → forms[0], else → last form
- Trim whitespace from the selected form
