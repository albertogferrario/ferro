<objective>
Land the central plan of Phase 155: the `ProjectionRuntime<P>` body with `read`, `read_required`, `apply_event`, `register` + the `ProjectionListener<P>` implementation. After this plan, the runtime is functional for the happy path (event in → snapshot persisted → broadcast delta out) and the listener registration path (one-line wiring via `Arc::new(Runtime::new(...)).register()`).

This is the **load-bearing apply algorithm** — 7 steps locked by D-19:

1. **Compute the key** via `P::key(event)`.
2. **Acquire the per-key Mutex** via `DashMap<String, Arc<tokio::sync::Mutex<()>>>`. The DashMap shard lock (RefMut) MUST drop BEFORE the `.await` on the Mutex — failing to drop holds the shard lock across the entire apply path and collapses cross-key concurrency through the shard. Mirrors `ferro-broadcast/src/broadcaster.rs:271` pattern.
3. **Load the snapshot** via `Entity::find_by_id((P::NAME.to_string(), key.0.clone())).one(&self.db).await?`. If absent, start from `P::State::default()`.
4. **Apply the event**: `let delta = self.projection.apply(&mut state, event);` (sync, fast — inside the Mutex but never crosses await).
5. **Persist the new state** via SeaORM upsert: `Entity::insert(active_model).on_conflict(OnConflict::columns([Column::ProjectionName, Column::Key]).update_columns([Column::State, Column::Version, Column::UpdatedAt]).to_owned()).exec(&self.db).await?`. The `state` is serialized to `serde_json::Value` via `serde_json::to_value(&new_state)?`; `version` increments by 1 (load_version + 1); `updated_at = Utc::now().naive_utc()`.
6. **Broadcast the delta** via `Broadcast::new(self.broadcaster.clone()).channel(format!("projection.{}.{}", P::NAME, key.as_str())).event(self.projection.broadcast_event_name()).data(delta).send().await`. **Broadcast failure does NOT roll back state** (D-21) — log at `tracing::warn!` and surface `ProjectionError::Broadcast`.
7. **Release the Mutex** (RAII on drop) and return `Ok(())`.

`register(self: Arc<Self>)` is the killer-feature one-line wiring — D-15:
```rust
let listener = ProjectionListener { runtime: self.clone() };
ferro_events::global_dispatcher().listen::<P::Event, _>(listener);
```
The listener is `pub(crate)` only (Claude's Discretion: NO public exposure — implementation detail of `register`).

`ProjectionListener<P>` is the first in-workspace user of the `Listener<E>` struct-listener path (RESEARCH.md §Technical Concerns #8). The handle method wraps `runtime.apply_event` and maps `ProjectionError` to `ferro_events::Error::listener_failed(type_name::<Self>(), e.to_string())`. Plan 06's integration test (D-46) is the proving artefact for risk R5 (first-user-of-listener-trait risk).

Two NEW operational footguns surface in the rustdoc:
- **Register twice = applies twice** (D-36): `Arc<ProjectionRuntime<P>>::register()` is NOT idempotent on Arc identity — calling twice registers two listeners; both fire on each dispatch. Documented in the lib.rs rustdoc (plan 01); reinforced in the `register` method rustdoc here.
- **Read is unlocked** (D-33): `read` does NOT acquire the per-key Mutex. Concurrent `read` + `apply_event` is safe at the DB level because the SQL JSON column upsert is atomic; readers see either the pre- or post-upsert state.

        }

        /// Read the persisted snapshot for `key`. Returns `Ok(None)` if no
        /// row exists. Does NOT take the per-key Mutex (D-33) — readers
        /// see either the pre- or post-upsert state, no torn reads.
        pub async fn read(
            &self,
            key: &ProjectionKey,
        ) -> Result<Option<P::State>, ProjectionError> {
            let row = Entity::find_by_id((P::NAME.to_string(), key.0.clone()))
                .one(&self.db)
                .await?;
            match row {
                None => Ok(None),
                Some(model) => {
                    let state: P::State = serde_json::from_value(model.state)?;
                    Ok(Some(state))
                }
            }
        }

        /// Read with a hard error if the snapshot is absent (D-30). Wraps
        /// `read`; consumers wanting `Result<State, _>` use this instead
        /// of `Result<Option<State>, _>`.
        pub async fn read_required(
            &self,
            key: &ProjectionKey,
        ) -> Result<P::State, ProjectionError> {
            self.read(key).await?.ok_or_else(|| {
                ProjectionError::StateNotFound {
                    name: P::NAME,
                    key: key.0.clone(),
                }
            })
        }

        /// Apply a single event. Implements the 7-step D-19 sequence
        /// inside a per-key `tokio::sync::Mutex`. Cross-key applies run
        /// in parallel; same-key applies serialize.
        pub async fn apply_event(
            &self,
            event: &P::Event,
        ) -> Result<(), ProjectionError> {
            // Step 1: compute key
            let key = self.projection.key(event);

            // Step 2: acquire per-key Mutex with shard-lock-drop-before-await
            // (mirrors ferro-broadcast/src/broadcaster.rs:271 pattern —
            // RefMut MUST drop before .await or cross-key concurrency
            // collapses through the DashMap shard).
            let lock_arc: Arc<tokio::sync::Mutex<()>> = {
                self.locks
                    .entry(key.0.clone())
                    .or_insert_with(|| Arc::new(tokio::sync::Mutex::new(())))
                    .clone()
            }; // <-- RefMut drops here, shard unlocked
            let _guard = lock_arc.lock().await;

            // Step 3: load the snapshot
            let existing = Entity::find_by_id((P::NAME.to_string(), key.0.clone()))
                .one(&self.db)
                .await?;

            let (mut state, new_version) = match existing {
                Some(model) => {
                    let s: P::State = serde_json::from_value(model.state)?;
                    (s, model.version + 1)
                }
                None => (P::State::default(), 1_i64),
            };

            // Step 4: apply (sync — must not block; inside the per-key Mutex)
            let delta = self.projection.apply(&mut state, event);

            // Step 5: upsert via OnConflict on the composite PK
            let state_json = serde_json::to_value(&state)?;
            let now = Utc::now().naive_utc();
            let am = ActiveModel {
                projection_name: ActiveValue::Set(P::NAME.to_string()),
                key: ActiveValue::Set(key.0.clone()),
                state: ActiveValue::Set(state_json),
                version: ActiveValue::Set(new_version),
                updated_at: ActiveValue::Set(now),
            };

            Entity::insert(am)
                .on_conflict(
                    OnConflict::columns([Column::ProjectionName, Column::Key])
                        .update_columns([Column::State, Column::Version, Column::UpdatedAt])
                        .to_owned(),
                )
                .exec(&self.db)
                .await?;

            // Step 6: broadcast — failure does NOT roll back state (D-21)
            let channel_name = format!("projection.{}.{}", P::NAME, key.as_str());
            let event_name = self.projection.broadcast_event_name();
            let send_result = ferro_broadcast::Broadcast::new(self.broadcaster.clone())
                .channel(channel_name.clone())
                .event(event_name)
                .data(delta)
                .send()
                .await;

            if let Err(e) = send_result {
                tracing::warn!(
                    error = %e,
                    channel = %channel_name,
                    "projection broadcast failed; snapshot persisted"
                );
                return Err(ProjectionError::from(e));
            }

            // Step 7: Mutex released on drop of `_guard` after this return
            Ok(())
        }

        /// Register a `ProjectionListener<P>` into the global event
        /// dispatcher (D-15). Killer-feature one-line wiring; every
        /// `P::Event::dispatch().await` now flows through this projection.
        ///
        /// **Not idempotent on `Arc` identity (D-36).** Calling `register`
        /// twice on the same `Arc<Self>` registers TWO listeners; both
        /// fire on each dispatch (same semantic as Laravel's
        /// `Event::listen`). Register once at app startup.
        pub fn register(self: Arc<Self>) {
            let listener = crate::listener::ProjectionListener {
                runtime: self.clone(),
            };
            ferro_events::global_dispatcher().listen::<P::Event, _>(listener);
        }
    }
