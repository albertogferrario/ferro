    2. **Constructor** `S3Driver::new(bucket: String, region: String, url_base: Option<String>, endpoint_url: Option<String>) -> Self`:
       - Build credentials with `aws_sdk_s3::config::Credentials::new(key_id, secret_key, None, None, "env")` reading `AWS_ACCESS_KEY_ID` and `AWS_SECRET_ACCESS_KEY` from `std::env::var()`. Use empty string if missing (per D-02, env-var tier of credential chain).
       - Build `aws_sdk_s3::config::Builder::new()` with `.region(Region::new(region.clone()))` and `.credentials_provider(creds)`.
       - If `endpoint_url` is `Some`, set `.endpoint_url(endpoint)` and `.force_path_style(true)` (per D-03).
       - Construct client: `aws_sdk_s3::Client::from_conf(config_builder.build())`.
       - **CRITICAL:** This must be sync (not async). Do NOT use `aws_config::defaults().load().await`. See RESEARCH.md Pitfall 1.

    3. **Helper functions** (private):
       - `fn normalize_path(path: &str) -> &str` — strips leading `/`.
       - `fn normalize_dir_prefix(dir: &str) -> String` — strips leading `/`, appends trailing `/` if non-empty, returns empty string for empty input.

    4. **All 15 StorageDriver trait methods:**

       **exists(path):** `head_object` with bucket+key. On Ok => `Ok(true)`. On error, check both `is_not_found()` on service error AND raw HTTP 404 status (HEAD has no body — see Pitfall 2). Map 404 to `Ok(false)`, other errors to `Error::S3(e.to_string())`.

       **get(path):** `get_object` with bucket+key. Collect body with `.body.collect().await?.into_bytes()`. Map `NoSuchKey` (check `e.code() == Some("NoSuchKey")`) to `Error::not_found(path)`, others to `Error::S3` (per D-13).

       **put(path, contents, options):** `put_object` with bucket+key+`ByteStream::from(contents)`. Content-Type: use `options.content_type` if set, else `mime_guess::from_path(path).first().map(|m| m.to_string())`. If `options.visibility == Visibility::Public`, set `.acl(ObjectCannedAcl::PublicRead)` (per D-07). If `Visibility::Private`, omit ACL (per D-06).

       **delete(path):** `delete_object` with bucket+key. Map errors per D-13.

       **copy(from, to):** `copy_object` with `copy_source = format!("{}/{}", self.bucket, normalize_path(from))`, bucket, key=to. Do NOT manually URL-encode (Pitfall 4).

       **size(path):** `head_object`, return `output.content_length().unwrap_or(0) as u64`. Map 404 to `Error::not_found(path)` same as exists().

       **metadata(path):** `head_object`, build `FileMetadata::new(path, size)` with `.with_last_modified(last_modified.into())` if present, `.with_mime_type(content_type)` if present. Map 404 to `Error::not_found(path)`.

       **url(path):** (per D-04) If `url_base` is Some, return `format!("{}/{}", base.trim_end_matches('/'), normalize_path(path))`. Else return `format!("https://{}.s3.{}.amazonaws.com/{}", self.bucket, self.region, normalize_path(path))`.

       **temporary_url(path, expiration):** (per D-05) Build `PresigningConfig::builder().expires_in(expiration).build()`. Call `self.client.get_object().bucket(&self.bucket).key(normalize_path(path)).presigned(presigning_config).await`. Return `presigned.uri().to_string()`. Map errors to `Error::S3`.

       **files(directory):** (per D-08) `list_objects_v2` with `prefix=normalize_dir_prefix(dir)` and `delimiter="/"`. Use `.into_paginator().send()` (not manual pagination). Collect `contents()` keys, excluding CommonPrefixes. Return keys.

       **all_files(directory):** (per D-09) `list_objects_v2` with `prefix=normalize_dir_prefix(dir)` only (no delimiter). Use paginator. Collect all keys.

       **directories(directory):** (per D-10) `list_objects_v2` with `prefix=normalize_dir_prefix(dir)` and `delimiter="/"`. Extract `common_prefixes()`, strip trailing `/`.

       **make_directory(path):** (per D-11) `put_object` with key=`format!("{}.keep", normalize_dir_prefix(path))`, empty `ByteStream`.

       **delete_directory(path):** (per D-12) List all objects with `prefix=normalize_dir_prefix(path)` using paginator. Batch delete in chunks of 1000 using `delete_objects` with `Delete::builder().set_objects(Some(identifiers))`.
