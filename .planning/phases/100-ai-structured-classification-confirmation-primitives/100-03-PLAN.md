    1. Create ferro-mcp/src/tools/ai.rs with two tool implementations:

       **test_classifier tool:**
       - Takes params: system_prompt (String), user_prompt (String), schema_json (String — JSON string of the schema), model (Option<String>)
       - Reads ANTHROPIC_API_KEY from env. If missing, return JSON error with instructions.
       - Creates AnthropicProvider::from_env(), ClassifierConfig with model override if provided
       - Calls classify_raw() directly (no type deserialization — returns raw JSON for debugging)
       - Returns JSON: { success: bool, result: Value (the raw classified JSON), model: String, error: Option<String> }
       - NOTE: This makes a real API call and costs tokens. Document in tool description.

       **list_pending_confirmations tool:**
       - Takes no params
       - Since InMemoryConfirmationStore is runtime state (not source-scannable), this tool returns a hint:
         "Confirmation state is in-memory and not inspectable via source scanning. Use the store's list_pending() method in your handler or add a debug endpoint."
       - Alternative approach if simpler: scan source files for `request_confirmation(` calls and report where confirmations are used in the codebase
       - Decision: implement the source-scanning approach — scan `src/` for `request_confirmation` calls and report file:line:context. This is more useful for MCP debugging.

    2. Register in ferro-mcp/src/tools/mod.rs:
       - Add `pub mod ai;`

    3. Register in ferro-mcp/src/service.rs:
       - Add test_classifier tool:
         ```
         #[tool(
             name = "test_classifier",
             description = "Test an AI classification by sending a prompt to the configured provider.\n\n\
                 **When to use:** Debugging classification prompts, verifying schema compliance, testing prompt iterations.\n\n\
                 **Note:** Makes a real API call to Anthropic. Costs tokens.\n\n\
                 **Returns:** Raw classified JSON output matching the provided schema."
         )]
         ```
       - Add list_pending_confirmations tool:

                 **Returns:** File paths and line numbers where request_confirmation is called."
         )]
         ```
