<objective>
Remove circular import between generated `inertia-props.ts` and `shared.ts` by making the generated file fully self-contained.

Purpose: `ferro generate-types` emits `import type { ... } from './shared'` and `export type { ... } from './shared'` in `inertia-props.ts`. When `shared.ts` re-exports types from `inertia-props.ts`, this creates TS2440/TS2484 circular dependency errors under strict mode.

Output: Self-contained `inertia-props.ts` that defines all utility types inline and never imports from `shared.ts`.
</objective>
