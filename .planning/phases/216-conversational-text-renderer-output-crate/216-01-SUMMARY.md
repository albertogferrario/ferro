# Phase 216 Plan 01: RenderHint schema extension Summary

`RenderHint{AltText(String), Skip}` added to `FieldDef` in `ferro-projections` with full serde compatibility and crate-root re-exports; all 11 literal sites migrated; workspace builds green.

## What Was Built

Added `FieldDef::render_hint: Option<RenderHint>` to `ferro-projections/src/field.rs` as the schema extension required by the Plan 02 text renderer. The enum `RenderHint` carries two variants:
- `AltText(String)` — substitute the raw URL/ImageUrl value with this text.
- `Skip` — omit the field entirely from non-visual output.

`None` on `render_hint` preserves current behavior (backward-compatible serde: old JSON without the key deserializes to `None`; serialized JSON omits the key when `None`).

Re-exported `RenderHint` and `Verbosity` from the `ferro-projections` crate root so downstream crates (Plan 02 `ferro-text`, Plan 03 `framework` facade) can import them directly.
