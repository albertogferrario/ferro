<objective>
Create the `device.rs` foundation module for the RFC 8628 device grant: the `DeviceGrant`
ephemeral cache record (mirrors `store::OAuthCode`), the `DeviceGrantStatus` enum, the two
cache-key helpers (`mcp:device:{device_code}`, `mcp:usercode:{normalized_user_code}`), and the
three code primitives (`generate_device_code`, `generate_user_code`, `normalize_user_code`).

Purpose: every downstream plan (verification handlers, token device-code arm, wiring) consumes
this struct + helpers. Defining the contract first prevents the executor scavenger-hunt.

user_code format + normalization (SC-1 substrate, SC-4 single-use/TTL substrate).

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| device/CLI → POST /device_authorization | untrusted client requests a grant; consumes `generate_*` output (downstream Plan 03) |
| stored credential (cache) → token poll | the `device_code` and `user_code` keyspace this module defines must resist brute-force |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-203-USERCODE-BRUTE | Spoofing | `generate_user_code` keyspace | mitigate | 20^8 keyspace from `BCDFGHJKLMNPQRSTVWXZ` (no vowels/digits); combined with single-use + 600s TTL enforced by consumers. ASVS V6. |
| T-203-DEVICECODE-ENTROPY | Information Disclosure | `generate_device_code` | mitigate | Reuse `pkce::generate_auth_code` (256-bit `rand::thread_rng` random, URL-safe); never reimplement with weaker entropy. ASVS V6. |
| T-203-USERCODE-NORMALIZE | Tampering | `normalize_user_code` | mitigate | Single canonical normalization (uppercase + strip `-`/space) used at both store and lookup, preventing key-mismatch bypass of single-use semantics. |
</threat_model>
