## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| public client → mounted /device_authorization | endpoint reachable without session (intended; client_id validated in-handler) |
| browser → mounted /device group | must run under TenantMiddleware so tenant binding at approve time is real |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-203-MOUNT-TENANT | Elevation of Privilege | /device route group | mitigate | `/device` mounts under `SessionUserTenantResolver` + `TenantFailureMode::Allow`; without this group the approve handler's `current_tenant()` would be empty and tenant binding would silently fail. Parity with the `/authorize` group (199 D-07). ASVS V4. |
| T-203-MOUNT-PUBLIC | Information Disclosure | /device_authorization mount | accept | mounted public by design (RFC §3.1 has no session); abuse beyond RFC `slow_down`/`interval` is an explicit hardening deferral (CONTEXT Deferred Ideas). |
| T-203-REGRESSION | Tampering | full workspace gate | mitigate | `--all-features` clippy + tests gate (SC-5) blocks the phase on any warning or failing test, catching regressions in the auth-code arm or discovery from the device changes. |
</threat_model>
