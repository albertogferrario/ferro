### `ferro make:json-view`

Generate a JSON-UI view file with AI-powered component generation.

```bash
# Generate a view
ferro make:json-view UserIndex

# Generate with explicit model context
ferro make:json-view UserEdit --model User
```

**Options:**

| Option | Description |
|--------|-------------|
| `--model`, `-m` | Model name for context-aware generation |

**How it works:**

1. Scans your models and routes for context
2. Sends context to Anthropic API (Claude Sonnet) for intelligent view generation
3. Falls back to a static template if no API key is configured
4. Generates a complete view file in `src/views/`

**Requirements:**

- Set `ANTHROPIC_API_KEY` in `.env` for AI-powered generation
- Without the key, a static template with common components is generated

**Generated file:** `src/views/user_index.rs`
