## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| job payload string → handler deserialization | worker deserializes attacker-influenceable JSON; malformed JSON must not panic the loop |
| panicking handle() → WorkerLoop | a job panic must be contained, not crash the loop (availability) |
| tenant_id on JobRow → handler execution scope | cross-tenant execution prevented by TenantScopeProvider wrap |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-185-03 | Denial of Service | panic in handle() killing the loop | mitigate | futures::FutureExt::catch_unwind + AssertUnwindSafe wraps handler; panic → failed attempt, loop continues (grep verifies catch_unwind) |
| T-185-07 | Denial of Service | malformed job payload deserialization | mitigate | register::<J>() handler maps serde_json::from_str failure to Error::DeserializationFailed (not panic); job parks/retries, loop survives |
| T-185-08 | Elevation of privilege | cross-tenant job execution | mitigate | tenant_id from JobRow drives scope.with_scope(id, fut) before handler runs; preserves Phase 97 isolation (D-17) |
| T-185-09 | Tampering | dispatch sink integrity | mitigate | dispatch_to_queue serializes via serde_json and calls db::enqueue (parameterized in Plan 02); no raw SQL in dispatcher |
</threat_model>
