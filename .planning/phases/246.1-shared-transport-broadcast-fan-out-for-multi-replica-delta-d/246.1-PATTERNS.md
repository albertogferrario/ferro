### `ferro-broadcast/src/transport/memory.rs` (in-memory test transport, pub-sub)

**Analog:** `ferro-broadcast/src/broadcaster.rs` (tokio::sync::mpsc usage + `tokio::spawn` pattern, lines 10, 229–234)

**tokio::spawn pattern for background delivery** (broadcaster.rs lines 229–234):
```rust
// We can't await here, so we'll spawn a task
let channel_name = channel_name.to_string();
let broadcaster = self.clone();
tokio::spawn(async move {
    broadcaster.send_to_channel(&channel_name, &msg).await;
});
```

**What to copy:**
- `use tokio::sync::{broadcast, mpsc};` (note: `broadcast` is the multi-receiver channel; `mpsc` is the per-client sink)
- The `subscribe_loop` method receives a `mpsc::Sender<BusEnvelope>` sink and drives it via `loop { match rx.recv().await { ... } }` — same shape as the existing `send_to_client` driving a `mpsc::Sender<ServerMessage>` (broadcaster.rs lines 344–350)
- `broadcast::error::RecvError::Lagged(n)` arm needs a `tracing::warn!` (mirrors the `warn!` import and usage pattern at broadcaster.rs line 11)
- The `InMemoryTransport` struct holds only a `broadcast::Sender<BusEnvelope>`; the `subscribe` helper returns a `broadcast::Receiver` — this is the mechanism that lets two `Broadcaster` instances share one bus

**Error handling pattern** (broadcaster.rs lines 344–350):
```rust
async fn send_to_client(&self, socket_id: &str, msg: ServerMessage) {
    if let Some(client) = self.inner.clients.get(socket_id) {
        if let Err(e) = client.sender.send(msg).await {
            warn!(socket_id = %socket_id, error = %e, "Failed to send message to client");
        }
    }
}
```
Mirror: when `sink.send(envelope).await.is_err()` in `subscribe_loop`, `break` (receiver dropped = shutdown); do not `warn!` — it is a clean shutdown path.

Use `#[async_trait::async_trait]` (path form) not `#[async_trait]` — this is what broadcaster.rs uses for mock impls in tests (line 603).
