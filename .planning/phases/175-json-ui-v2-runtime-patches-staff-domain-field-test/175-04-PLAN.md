| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-175-04-01 | I (Information disclosure) | CheckboxGroup options rendered into HTML | accept | The dispatch arm reuses `render_checkbox_list`, which already passes every option's `value` and `label` through `html_escape`. F2 introduces no new emission path — escaping is inherited. |

Server-side handlers are expected to validate the submitted values against the option set (CLAUDE.md "validate-all-inputs"). The form layer is not the security boundary for option validity. |
| T-175-04-03 | E (Elevation of privilege) | CheckboxGroup catalog entry | accept | The catalog is admin-internal introspection (ferro-mcp `json_ui_catalog`). Adding an alias entry does not expand any public attack surface; the renderer was already addressable via `"type": "CheckboxList"`. |
</threat_model>
