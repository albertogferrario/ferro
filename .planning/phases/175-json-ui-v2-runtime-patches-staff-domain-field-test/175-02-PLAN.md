<objective>
Land F3: extend the existing `setupTabs()` IIFE in the ferro-json-ui runtime so that
the tab strip honors `?tab=<name>` from `window.location.search` at boot. Today the
runtime only wires click handlers; the server-render emits `class="hidden"` on
non-default panels via `default_tab`, but the URL is ignored. Result: the URL says
tab B but the server rendered tab A as default, leaving the operator on the wrong
panel.

Per D-F3-tabs in CONTEXT.md: client-side IIFE, no server changes, mirrors the
existing `initToastFromUrl` pattern in `runtime/toasts.rs` (URLSearchParams +
DOMContentLoaded).

Purpose: closes the F3 finding without a server roundtrip; preserves SPA-style
instant tab switching.

  ```rust
  pub(super) const SOURCE: &str = r#"
      // ── Tab switching ──────────────────────────────────────────────────────

      function setupTabs() {
          var containers = document.querySelectorAll('[data-tabs]');
          for (var i = 0; i < containers.length; i++) {
              initTabContainer(containers[i]);
          }
      }

      function initTabContainer(container) {
          var triggers = container.querySelectorAll('[data-tab]');
          var panels = container.querySelectorAll('[data-tab-panel]');
          if (triggers.length === 0) return;

          for (var i = 0; i < triggers.length; i++) {
              triggers[i].addEventListener('click', makeTabHandler(triggers, panels));
          }

          initTabFromUrl(container, triggers, panels);
      }

      // Reads ?tab=<name> from the URL once at boot. If present and the value
      // matches a [data-tab] trigger, activate that tab by invoking the same
      // handler the click path uses — no DOM logic duplicated. Mirrors the
      // initToastFromUrl pattern in toasts.rs (URLSearchParams + DOMContentLoaded;
      // the outer ferroRuntime() IIFE already gates this on DOMContentLoaded so
      // no extra guard is needed).
      function initTabFromUrl(container, triggers, panels) {
          var params = new URLSearchParams(window.location.search);
          var value = params.get('tab');
          if (!value) return;

          var found = false;
          for (var i = 0; i < triggers.length; i++) {
              if (triggers[i].getAttribute('data-tab') === value) {
                  found = true;
                  break;
              }
          }
          if (!found) return;

          makeTabHandler(triggers, panels)({
              currentTarget: {
                  getAttribute: function(attr) {
                      return attr === 'data-tab' ? value : null;
                  }
              }
          });
      }

      function makeTabHandler(triggers, panels) {
          return function(e) {
              var value = e.currentTarget.getAttribute('data-tab');

              for (var i = 0; i < triggers.length; i++) {
                  var t = triggers[i];
                  if (t.getAttribute('data-tab') === value) {
                      t.classList.remove('border-transparent', 'text-text-muted', 'hover:text-text');
                      t.classList.add('border-primary', 'text-primary', 'font-semibold');
                      t.setAttribute('aria-selected', 'true');
                  } else {
                      t.classList.remove('border-primary', 'text-primary', 'font-semibold');
                      t.classList.add('border-transparent', 'text-text-muted', 'hover:text-text');
                      t.setAttribute('aria-selected', 'false');
                  }
              }

              for (var j = 0; j < panels.length; j++) {
                  var p = panels[j];
                  if (p.getAttribute('data-tab-panel') === value) {
                      p.classList.remove('hidden');
                  } else {
                      p.classList.add('hidden');
                  }
              }
          };
      }
  "#;
  ```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser URL (`window.location.search`) → ferro runtime JS | The `?tab=` value is attacker-controllable via crafted links; the runtime must treat it as untrusted. |
| ferro runtime JS → DOM | The runtime sets CSS classes and toggles `hidden`; no innerHTML, no document.write. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-175-02-01 | T (Tampering) / I (Information disclosure) | `initTabFromUrl` reading `?tab=` | mitigate | Value is compared via `getAttribute('data-tab') === value` against server-rendered trigger DOM. The server only renders triggers for tabs that exist in the spec. If `?tab=<arbitrary>` does not match any trigger, the function returns early (`found = false`). No DOM injection, no `eval`, no `innerHTML` write — only class toggling on existing nodes. |
| T-175-02-02 | D (Denial of Service) | tab init loop | accept | The loop is `O(N triggers)` where N is bounded by the number of tabs the server rendered (typically ≤ 6). Worst case: a spec with 100 tabs takes microseconds. No remote input controls N. |
| T-175-02-03 | E (Elevation of privilege) | client-side tab switching | accept | The IIFE only toggles visibility of server-rendered panels. All authorization, filtering, and data masking happens server-side at render time. A hostile `?tab=` value cannot reveal content the server did not already render into the page. (If the server should not have rendered panel X to user U, that is a server-side bug, out of scope for F3.) |
</threat_model>
