<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Operator → GitHub (repo + secret creation) | Human-initiated, authenticated GitHub actions |
| PAT → tap repo write | The created token is the sole write path into the tap |
| End user machine → brew install | Untrusted download verified by the formula sha256 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-226-11 | Elevation of Privilege | HOMEBREW_TAP_TOKEN | mitigate | Operator creates it least-privilege: Contents:write, single repo (homebrew-ferro), no other scopes (RESEARCH Q7). Verified at the live `brew install` gate. |
| T-226-12 | Tampering | tap main branch | mitigate | Operator confirms no third-party write access to the tap; direct-commit-to-main is from the scoped PAT only (A4: no branch protection conflict). |
| T-226-13 | Spoofing | tap repo name | mitigate | Repo MUST be `homebrew-ferro`; a wrong name fails to resolve (fail-closed, not a silent wrong install). |
| T-226-14 | Tampering | end-user install integrity | mitigate | `brew install` verifies the downloaded tarball against the formula's sha256 (computed from the official release assets); a mismatched/substituted tarball fails the install. |
</threat_model>
