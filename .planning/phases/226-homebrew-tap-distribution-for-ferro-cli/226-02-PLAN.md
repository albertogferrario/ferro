```yaml
name: CI

on:
  push:
    branches:
      - main
  pull_request:

jobs:
  audit:
    runs-on: macos-latest
    steps:
      - uses: actions/checkout@v4

      - name: Set up Homebrew
        id: set-up-homebrew
        uses: Homebrew/actions/setup-homebrew@main
        with:
          token: ${{ secrets.GITHUB_TOKEN }}

      - name: Cache Homebrew Bundler RubyGems
        uses: actions/cache@v4
        with:
          path: ${{ steps.set-up-homebrew.outputs.gems-path }}
          key: ${{ runner.os }}-rubygems-${{ steps.set-up-homebrew.outputs.gems-hash }}
          restore-keys: ${{ runner.os }}-rubygems-

      - name: Ruby syntax check
        run: ruby -c Formula/ferro.rb

      - name: brew audit (strict, online on PR only)
        run: |
          if [ "${{ github.event_name }}" = "pull_request" ]; then
            brew audit --strict --online Formula/ferro.rb
          else
            brew audit --strict Formula/ferro.rb
          fi
```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| GitHub tag-push event → bump job execution | Only a real release tag push should trigger the formula bump |
| release.yml → secrets.HOMEBREW_TAP_TOKEN | The secret crosses into the bump job's env |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-226-05 | Spoofing/Tampering | bump job trigger | mitigate | `if: github.event_name == 'push' && !contains(github.ref_name, '-')` gates to non-prerelease tag pushes only; a manual dispatch or branch push cannot trigger a formula bump. |
| T-226-06 | Information Disclosure | HOMEBREW_TAP_TOKEN in CI | mitigate | Token injected via `env:` only and consumed inside the script; never referenced in a `run:` echo. GitHub masks secret values in logs by default. |
| T-226-07 | Elevation of Privilege | bump job repo permissions | mitigate | Job declares no `permissions: contents: write`; it cannot mutate this repo. Its only write capability is the externally-scoped PAT. |
| T-226-08 | Tampering | third-party action pinning | accept | `actions/checkout@v4`, `actions/cache@v4` pinned to major tags; `Homebrew/actions/setup-homebrew@main` is the upstream-documented ref for that action (tap-CI only, runs in the external repo). |
</threat_model>
