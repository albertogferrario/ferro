- "ultrathink about the intent taxonomy design"

This triggers maximum thinking budget (31,999 tokens) for deep architectural reasoning.

## Worktree Strategy (Phase 90)

Phase 90 validates the entire architecture. If the intent→JSON-UI mapping feels forced:

1. Spawn Agent A in worktree: current intent taxonomy → JSON-UI
2. Spawn Agent B in worktree: revised taxonomy → JSON-UI
3. Compare both branches, pick the winner
4. Merge winning branch

```bash
claude --worktree renderer-approach-a
claude --worktree renderer-approach-b
```
