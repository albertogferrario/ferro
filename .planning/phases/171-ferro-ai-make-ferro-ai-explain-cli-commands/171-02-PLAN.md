<objective>
Ship `ferro ai:make <description>` (AICLI-01, AICLI-02): load live ferro-mcp introspection
in-process, filter it to description-relevant items with a deterministic lexical filter, prompt
the LLM via `complete_with::<ServiceDef>()`, and write the produced `ServiceDef` as a single
commit-ready Rust builder file at `src/projections/<snake>.rs` (the central new component is the
`ServiceDef` → builder-source emitter). `--dry-run` prints pretty JSON and writes nothing.

Purpose: This is the produce half of the milestone killer feature — AI produces the universal
projection contract, not a multi-file scaffold (SC#3). It consumes the `complete_with` SDK
surface from Plan 01 and the established `make:projection` file-write convention.
Output: `ferro-cli/src/naming.rs` (shared sanitizers), `ferro-cli/src/relevance.rs` (lexical
filter), `ferro-cli/src/commands/ai_make.rs` (command + emitter), clap registration in main.rs.
</objective>
