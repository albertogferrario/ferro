<objective>
**This is the killer feature plan.** The v11.11 milestone's correctness claim — "race-free reservations as a first-class framework primitive" — is credible only because of the tests that land in this plan: a 20-task concurrent_hold integration test proving the capacity invariant (D-48), property-based tests sweeping random N and C values (D-49), and a cross-crate integration test (D-50) verifying that hold + commit dispatch 2 events AND write 2 audit entries with matching correlation, AND that the audit replay reconstructs the final state correctly.

Spend disproportionate effort here. Plan 05's kernel methods passed unit tests against a single tokio task; this plan proves them under adversarial concurrency. The plan also lands the sweeper (`run_sweep_once`), which closes the four-state-machine loop (`held → expired` via TTL).

Specifically, this plan delivers:

1. **`run_sweep_once`** — the TTL expiry primitive (D-21). Selects `held` rows whose `expires_at < now()` (LIMIT 500), runs a per-row GuardedUpdate `held → expired` with `exec_at_most_one` (idempotent under concurrent sweepers — D-24), emits one `ReservationEvent::Expired` and one `AuditEntry::record("reservation.expired")` per row with `AuditActor::System` (D-23), returns a `SweepReport`. Sweeper-only API documented for three scheduling patterns (D-22). 2 inline unit tests cover D-47-8 (3 expired → expired_count = 3) and D-47-9 (no eligible rows → expired_count = 0).

2. **`tests/concurrent_hold.rs`** — D-48. The capstone of the kernel's correctness claim. 20 tokio tasks issue concurrent `hold(quantity=1)` calls against `TestResource { capacity: 5 }`; exactly 5 succeed, 15 fail with `Insufficient`. The persisted row count for `status='held'` is exactly 5. The test runs N times in `for _ in 0..3` to catch nondeterminism (SQLite serial-writer should yield the same result every time, but flake-resistance is cheap).

3. **`tests/property_invariants.rs`** — D-49. proptest-driven properties:
   - **Property 1 (capacity invariant):** for any `capacity ∈ [1, 20]` and `n_tasks ∈ [1, 20]`, `successes <= capacity` and `SUM(quantity WHERE status IN ('held','committed')) <= capacity`.
   - **Property 2 (state-machine validity):** for any sequence of operations (random mix of hold/commit/release/expire) applied to a kernel, the audit log replay (via `ferro_audit::reconstruct_state`) never shows a transition from a terminal state to held. Implementation uses arbitrary operation sequences via `proptest::collection::vec`.

4. **`tests/integration_with_audit_and_events.rs`** — D-50. The showcase test for the milestone. Registers a `ferro_events::Listener` that counts `ReservationEvent::Held` and `ReservationEvent::Committed` dispatches (via `Arc<AtomicU32>`). Calls `kernel.hold(...)` then `kernel.commit(...)` with a non-trivial `ReservationContext` (user actor, correlation_id, tenant_id). Asserts (a) both event counters are 1, (b) `ferro_audit::history_for_target` returns exactly 2 entries with the same correlation_id and matching tenant_id, (c) `ferro_audit::reconstruct_state(&history)` returns `{"status": "committed"}` as the final state.

This plan also exercises the **graceful degradation** semantics: tests deliberately do NOT register any `ferro_events::Listener` for some test cases, ensuring `dispatch()` returns `Ok(())` (no-listeners is not an error in ferro-events; verified from `ferro-events/src/dispatcher.rs` lines 167–171).

    //!
    //! The sweeper is consumer-scheduled (D-22 — no `ferro-queue` runtime
    //! dependency). Three idiomatic scheduling patterns:
    //!
    //! 1. **ferro-queue `Job`** — implement a `Job` that calls
    //!    `kernel.run_sweep_once().await` and schedule via the queue.
    //! 2. **`tokio::time::interval` task** — spawn a 60-second loop on
    //!    application start.
    //! 3. **Cron-driven CLI** — `your-app reservation:sweep` calls
    //!    `kernel.run_sweep_once()` and exits.
    //!
    //! Per-row contention is safe under concurrent sweepers: each
    //! transition uses `GuardedUpdate::exec_at_most_one` (D-24), which
    //! treats 0-rows as a normal outcome (the other sweeper won).

    use ferro_orm::{GuardedUpdate, Value};
    use sea_orm::{ColumnTrait, EntityTrait, QueryFilter, QuerySelect};

    use crate::event::ReservationEvent;

    use crate::resource::Resource;

    /// Result of one sweeper invocation (D-21).
    #[derive(Clone, Debug)]
    pub struct SweepReport {
        pub expired_count: u32,
        pub scanned_at: DateTime<Utc>,
    }

    impl<R: Resource> ReservationKernel<R> {
        /// Scan and expire held rows whose `expires_at` is in the past.
        /// Per-row idempotent under concurrent sweepers (D-24).
        ///
        /// Cap: 500 rows per call (D-21). Schedule subsequent sweeps if a
        /// backlog persists.
        ///
        /// Emits one [`ReservationEvent::Expired`] + one
        /// [`ferro_audit::AuditEntry`] (action `"reservation.expired"`,
        /// actor [`AuditActor::System`] per D-23) per row that transitioned.
        /// Audit failure surfaces as [`ReservationError::Audit`] (D-30) but
        /// the DB transition is already committed; event-dispatch failure
        /// is logged at `tracing::warn!` and does NOT propagate (D-26).
        pub async fn run_sweep_once(&self) -> Result<SweepReport, ReservationError> {
            let scanned_at = Utc::now();
            let now_naive = scanned_at.naive_utc();

            let expired_rows = reservations::Entity::find()
                .filter(reservations::Column::Status.eq("held"))
                .filter(reservations::Column::ExpiresAt.lt(now_naive))
                .limit(500)
                .all(&self.db)
                .await
                .map_err(ReservationError::Db)?;

            let mut expired_count: u32 = 0;
            for row in &expired_rows {
                let result = GuardedUpdate::new(reservations::Entity)
                    .filter(reservations::Column::Id.eq(row.id))
                    .filter(reservations::Column::Status.eq("held"))
                    .set_value(
                        reservations::Column::Status,
                        Value::String(Some(Box::new("expired".to_string()))),
                    )
                    .exec_at_most_one(&self.db)
                    .await;

                match result {
                    Ok(true) => {
                        expired_count += 1;
                        // Audit (D-23 + D-28)
                        let audit = AuditEntry::record("reservation.expired")
                            .actor(AuditActor::System)
                            .target(AuditTarget::new("reservation", row.id.to_string()))
                            .before(json!({"status": "held", "quantity": row.quantity}))
                            .after(json!({"status": "expired"}));
                        // Tenant scope is preserved if the row has one
                        let audit = if let Some(tid) = row.tenant_id.as_deref() {
                            audit.tenant(tid)
                        } else {
                            audit
                        };
                        if let Err(e) = audit.write(&self.db).await {
                            // D-30: audit failure surfaces but state is committed
                            tracing::warn!(
                                reservation_id = %row.id,
                                error = %e,
                                "audit write failed for reservation.expired — state is committed"
                            );
                        }
                        // Event dispatch (D-26 best-effort)
                        if let Err(e) = ferro_events::dispatch(ReservationEvent::Expired {
                            id: row.id,
                            resource_kind: row.resource_kind.clone(),
                            resource_key: row.resource_key.clone(),
                        })
                        .await
                        {
                            tracing::warn!(
                                reservation_id = %row.id,
                                error = %e,
                                "event dispatch failed after reservation.expired — state is committed"
                            );
                        }
                    }
                    Ok(false) => {
                        // Concurrent sweeper won; skip silently per D-24
                    }
                    Err(e) => {
                        // DB error or programming-bug GuardedError — log and continue
                        tracing::warn!(
                            reservation_id = %row.id,
                            error = %e,
                            "sweeper guarded update db error — skipping row"
                        );
                    }
                }
            }

            Ok(SweepReport {
                expired_count,
                scanned_at,
            })
        }
    }
