### Data-Flow Trace (Level 4)

Phase 117.1 is a pure internal Rust refactor producing data structures (`Spec`). No UI rendering component is added — consumers of `Spec` (e.g., `ferro-mcp::render_projection`, framework handlers) are unchanged and continue to flow live `ServiceDef` input data through the pipeline. The projector is deterministic over its inputs (`service`, `intents`, `ctx`); output `Spec` elements carry data-path placeholders (`/data/{service.name}`, `/data/{field.name}`, `/data/{rel.name}`) that Phase 118's expression resolver will bind at render time. Level 4 trace is therefore not applicable to this phase — the data flow is the caller's responsibility, and Phase 118 (explicitly deferred per ROADMAP) owns it.
