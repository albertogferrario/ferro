### `ferro-json-ui/src/projection/error.rs` (error type)

**Analog:** `ferro-json-ui/src/catalog.rs` — `CatalogError` enum (lines 80-112)

**Imports pattern** (catalog.rs lines 80-81):
```rust
use thiserror::Error;
// (no extra imports needed beyond thiserror + crate types)
```

**Core error enum pattern** (catalog.rs lines 80-112):
```rust
#[derive(Debug, thiserror::Error)]
pub enum CatalogError {
    #[error("unknown component type '{type_name}' at element '{element_id}'")]
    UnknownType {
        element_id: String,
        type_name: String,
    },
    #[error("props invalid for '{type_name}' at element '{element_id}': {errors:?}")]
    PropsInvalid {
        element_id: String,
        type_name: String,
        errors: Vec<String>,
    },
    #[error("spec invalid: {errors:?}")]
    SpecInvalid { errors: Vec<String> },
    #[error("catalog build failed: {0}")]
    BuildFailed(String),
    #[error("schema serialization error: {0}")]
    SchemaSerialization(#[from] serde_json::Error),
}
```

**Apply to `ProjectionError`:** Copy the `thiserror` derive pattern. The five variants needed for `ProjectionError` are:

```rust
use thiserror::Error;
use crate::catalog::CatalogError;
use crate::spec::SpecError;

#[derive(Debug, Error)]
pub enum ProjectionError {
    #[error("intent_index {requested} out of bounds (have {available} intents)")]
    IntentIndexOutOfBounds { requested: usize, available: usize },

    #[error("cannot project service with no intents")]
    EmptyIntents,

    #[error("projector referenced unknown component '{type_name}'")]
    UnknownComponent { type_name: String },

    #[error("catalog validation failed: {}", format_catalog_errors(.0))]
    CatalogValidation(Vec<CatalogError>),

    #[error("spec build failed: {0}")]
    SpecBuild(#[from] SpecError),
}

fn format_catalog_errors(errors: &[CatalogError]) -> String {
    errors.iter().map(|e| e.to_string()).collect::<Vec<_>>().join("; ")
}
```

Note: `CatalogError` does not derive `Clone`, so `ProjectionError::CatalogValidation(Vec<CatalogError>)` stores owned values — same as `CatalogError::PropsInvalid { errors: Vec<String> }` stores owned strings. No `Clone` needed on `ProjectionError` itself.

**`Spec::from_service_def` skeleton** (orchestration, D-08 + D-11):
```rust
#[cfg(feature = "projections")]
impl Spec {
    pub fn from_service_def(
        service: &ServiceDef,
        intents: &[IntentScore],
        ctx: &VisualContext,
    ) -> Result<Spec, ProjectionError> {
        use super::intent_layout::{default_template, pick_intent_template};

        if intents.is_empty() {
            return Err(ProjectionError::EmptyIntents);
        }
        let intent_score = intents.get(ctx.intent_index).ok_or(
            ProjectionError::IntentIndexOutOfBounds {
                requested: ctx.intent_index,
                available: intents.len(),
            },
        )?;

        // D-11: Input mode collapses all intents to Form.
        let spec = if ctx.mode == RenderMode::Input {
            build_input_spec(service, ctx)?
        } else {
            let template = ctx.templates
                .as_ref()
                .and_then(|t| pick_intent_template(t, &intent_score.intent))
                .cloned()
                .unwrap_or_else(|| default_template(&intent_score.intent));
            build_display_spec(service, &intent_score.intent, &template, ctx)?
        };

        // D-06: always validate; additionally panic in debug builds.
        match global_catalog().validate(&spec) {
            Ok(()) => Ok(spec),
            Err(errors) => {
                #[cfg(debug_assertions)]
                panic!("Projector emitted invalid spec: {:?}", errors);
                #[allow(unreachable_code)]
                Err(ProjectionError::CatalogValidation(errors))
            }
        }
    }
}
```

## Shared Patterns

### `thiserror` Error Enum Pattern
**Source:** `ferro-json-ui/src/catalog.rs` lines 80-112 (`CatalogError`), `ferro-json-ui/src/spec.rs` lines 98-121 (`SpecError`)
**Apply to:** `error.rs` (`ProjectionError`)
```rust
#[derive(Debug, thiserror::Error)]
pub enum SomeError {
    // Struct variants for errors with structured fields:
    #[error("descriptive message with '{field}' interpolation")]
    Variant { field: String },
    // Tuple variants for wrapping upstream errors:
    #[error("wrapping: {0}")]
    Wrap(#[from] UpstreamError),
}
```

### `OnceLock` Global Singleton Access
**Source:** `ferro-json-ui/src/catalog.rs` — `global_catalog()` function (lines visible around line 580-599 in the build method)
**Apply to:** `builder.rs` — call `global_catalog()` once at the start of `Spec::from_service_def`, pass `&Catalog` down to helpers.
**Anti-pattern:** Do NOT call `global_catalog()` inside per-field slot emit loops — it costs an atomic read per call, and the catalog is the same object throughout the projection.

### `Catalog::validate` Call Pattern
**Source:** `ferro-json-ui/src/catalog.rs` lines 630-712
**Apply to:** `builder.rs` end of `Spec::from_service_def`

Stage 2 of validate skips elements where `el.props.is_null()` (catalog.rs line 659). Therefore every element the projector emits MUST have non-null props — the typed Props approach guarantees this.

### Feature-Gated Module Pattern

### `SpecBuilder` Usage Pattern
**Source:** `ferro-json-ui/src/spec.rs` lines 127-266; `ferro-json-ui/src/projection/mod.rs` lines 149-153
```rust
Spec::builder()
    .title(title_string)
    .element("root", Element::new("DataTable").prop("k", v).prop("k2", v2))
    .element("child_id", Element::new("Text").prop("content", ""))
    .build()
    .map_err(ProjectionError::SpecBuild)
```
First `.element()` call without `.root()` sets root automatically. `build()` runs cycle, depth, dangling-ref, and ID-format checks. MAX_NESTING_DEPTH = 3 (spec.rs line 37) — keep element trees flat; KanbanBoard and DataTable use their typed `Vec<*>` props fields, not `children` element IDs, so depth stays at 1 for these containers.
