## Decisions Made

- **Switch drift guard from `global_catalog()` to `Catalog::build_builtins_only()`.** The global catalog gets polluted by the `BadPlugin_117` plugin registration in `catalog.rs` plugin tests; depending on test execution order, the drift guard would fail with `BuildFailed("plugin 'BadPlugin_117' returned an invalid JSON Schema")`. `catalog.rs` already documents this workaround at line 1117 for its own tests; the same pattern applies here.
- **Promote `Catalog::build_builtins_only` to `pub(crate)`.** The function is still `#[cfg(test)]`-gated, so this does not expand the production surface — it just makes the existing test-isolation helper accessible from sibling modules' tests.
- **Function-based dispatch for `lookup_meaning`, not a static `&[(FieldMeaning, ComponentChoice)]` table.** `FieldMeaning::Custom(String)` is not `Copy`; "patterns are not allowed in statics" forbids a real `static` table. The decision honors D-01 (auditable single match point) while working inside Rust's type system.

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 3 — Blocking] Drift guard test polluted by `BadPlugin_117` plugin registration in sibling test**

- **Found during:** Task 2 verification, surfaced on Task 3's full-suite run.
- **Issue:** `global_catalog()` is a `OnceLock`; the `catalog::tests::build_discovers_plugins_and_rejects_invalid_schema` test registers a `BadPlugin_117` into the global plugin registry, which then fails catalog construction on any subsequent `global_catalog()` call in the same test process. Depending on test execution order, `meaning_table_components_exist_in_catalog` and `custom_meaning_fallback_uses_catalog_components` would panic with `BuildFailed("plugin 'BadPlugin_117' returned an invalid JSON Schema")` — a false positive unrelated to the projector.
- **Fix:** Switched both drift guard tests from `global_catalog()` to `Catalog::build_builtins_only()` — the same helper catalog.rs already uses to isolate its own schema-shape tests (documented workaround at `catalog.rs:1117`). Promoted the helper from private to `pub(crate)` so it is reachable from `projection::component_map::tests` while remaining `#[cfg(test)]`-gated.
- **Files modified:** `ferro-json-ui/src/projection/component_map.rs`, `ferro-json-ui/src/catalog.rs`.
- **Verification:** `cargo test -p ferro-json-ui --features projections` now reports 392 lib tests + 11 tests/round_trip + 8 tests/reject + 5 doc-tests — all passing. `cargo clippy --all --all-targets -- -D warnings` and `cargo fmt --all -- --check` both clean.
- **Committed in:** `9793b8dc` (part of Task 3).
