## Summary

Surgical two-line fix to `try_migrate_handler` in `ferro-cli/src/commands/json_ui_migrate_v1.rs` that closes WR-01 from the Phase 163 review. The original code used `top_ids.first().cloned()` with an `Option`-returning `let Some(root)` guard, which silently accepted multi-root inputs by taking only the first id and emitting a partial JSON spec. The fix replaces this with an explicit `if top_ids.len() != 1 { return HandlerResult::Unsupported; }` guard followed by a correctly-messaged `expect`.

All 6 ferro-cli integration tests pass. Clippy is clean. No changes outside ferro-cli in this phase diff. Deleted fixtures are unreferenced. D-06 compliance confirmed — no new component registered in ferro-json-ui.
