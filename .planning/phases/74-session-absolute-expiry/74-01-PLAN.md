<objective>
Implement dual timeout (idle + absolute) in the session module with `created_at` tracking and bulk session invalidation.

Purpose: OWASP mandates both idle and absolute session timeouts. Absolute expiry prevents stolen sessions from being kept alive indefinitely by generating requests. Bulk invalidation enables "logout other devices" and password-change flows.
Output: Updated SessionConfig, sessions entity, DatabaseSessionDriver with dual enforcement, `destroy_for_user` on SessionStore trait, cookie max_age fix, CLI migration template with `created_at`.
</objective>

**DatabaseSessionDriver (driver/database.rs):**
- Change struct field from `lifetime: Duration` to `idle_lifetime: Duration` + `absolute_lifetime: Duration`
- Update `new()` to accept both: `pub fn new(idle_lifetime: Duration, absolute_lifetime: Duration) -> Self`
- Update `read()`: after the idle timeout check, add absolute timeout check. If `session.created_at` is `Some(created)`, check `now > created + absolute_lifetime`. If expired, destroy and return `Ok(None)`. If `created_at` is None, skip absolute check (backward compat).
- Update `write()`: on INSERT (new session), set `created_at: Set(Some(now))`. On UPDATE (existing session), set `created_at: sea_orm::NotSet` to preserve the original value.
- Update `gc()`: change to `WHERE last_activity < idle_threshold OR (created_at IS NOT NULL AND created_at < absolute_threshold)`. Use `sea_orm::Condition::any()` with two sub-conditions.

**SessionMiddleware (middleware.rs):**
- Update `SessionMiddleware::new()` to pass both lifetimes: `DatabaseSessionDriver::new(config.idle_lifetime, config.absolute_lifetime)`
- Update `create_session_cookie()`: change `.max_age(self.config.lifetime)` to `.max_age(std::cmp::max(self.config.idle_lifetime, self.config.absolute_lifetime))`. The cookie must survive long enough to present the session ID; the server enforces the real expiry.

**Important:** The `write()` UPDATE path must NOT update `created_at` — it must be preserved from the original INSERT. Use `sea_orm::NotSet` for the `created_at` field in the update ActiveModel.

**DatabaseSessionDriver (driver/database.rs):**
- Implement `destroy_for_user`:
  ```rust
  async fn destroy_for_user(&self, user_id: i64, except_session_id: Option<&str>) -> Result<u64, FrameworkError> {
      let db = DB::connection()?;
      let mut condition = sea_orm::Condition::all()
          .add(sessions::Column::UserId.eq(user_id));
      if let Some(except_id) = except_session_id {
          condition = condition.add(sessions::Column::Id.ne(except_id));
      }
      let result = sessions::Entity::delete_many()
          .filter(condition)
          .exec(db.inner())
          .await
          .map_err(|e| FrameworkError::database(e.to_string()))?;
      Ok(result.rows_affected)
  }
  ```
