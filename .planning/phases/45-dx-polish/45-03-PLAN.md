**Paginated API resource (user_controller.rs):**
Add an `api_index` handler that returns users as a paginated `ResourceCollection`:
```rust
#[handler]
pub async fn api_index(req: Request) -> Response {
    let db = DB::get()?;
    let page: u64 = req.query("page").unwrap_or(1);
    let per_page: u64 = req.query("per_page").unwrap_or(15);

    let paginator = users::Entity::find().paginate(&*db, per_page);
    let total = paginator.num_pages().await? * per_page; // or use count
    let items = paginator.fetch_page(page - 1).await?;

    let resources = UserResource::collection(&items);
    let meta = PaginationMeta::new(page, per_page, total, &req);

    ResourceCollection::paginated(resources, meta).to_response()
}
```

Adapt to actual project patterns. Use SeaORM's paginator. Import `ferro::{ResourceCollection, PaginationMeta, Resource}`.
