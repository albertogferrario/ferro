  <action>
Create `ferro-projections/src/derive.rs` with the complete derivation engine:

**Module-level constants (top of file):**
- Signal name constants as `&str` (e.g., `SIGNAL_MONEY_FIELDS`, `SIGNAL_ENTITY_NAME`, etc.) to prevent typo bugs in matching_signals
- Baseline scores: `BASELINE_BROWSE: f64 = 0.1`, `BASELINE_FOCUS: f64 = 0.1`

**Signal type:**
```rust
/// A single signal contribution: (intent, raw weight, signal description).
type Signal = (Intent, f64, String);
```

**Public API:**
```rust
/// Derives ranked intents from a ServiceDef's structural signals.
/// Always returns at least one IntentScore. Default: Focus with 0.5 confidence.
pub fn derive_intents(service: &ServiceDef) -> Vec<IntentScore>
```

Implementation flow:
1. Collect signals from all analyzers into `HashMap<Intent, (f64, Vec<String>)>` — sum weights, collect signal names
2. Add baseline Browse/Focus scores (0.1 each) with "baseline" signal name
3. Call `normalize_scores()` to produce ranked `Vec<IntentScore>`
4. Call `apply_hints()` for IntentHint override
5. If result is empty after hints, return default Focus fallback

**Helper: `is_system_field(meaning: &FieldMeaning) -> bool`:**
Returns true for Identifier, CreatedAt, UpdatedAt — these are infrastructure, not domain signals. Used by field meaning and writability analyzers to exclude system fields.

**Analyzer 1: `analyze_field_meanings(service: &ServiceDef) -> Vec<Signal>`:**
Examine non-system fields' meanings to derive intent signals. Use PROPORTIONAL signals (count-based), not binary:
- Money/Percentage/Quantity fields → Summarize (weight: 0.3 * count)
- FreeText/ImageUrl/Url fields → Focus (weight: 0.25 * count)
- EntityName → Browse (weight: 0.2 per occurrence)
- DateTime + numeric co-occurrence → Analyze (weight: 0.35)
- Status → Track (weight: 0.25)
- Category → Browse (weight: 0.1 per occurrence)

**Analyzer 2: `analyze_writability(service: &ServiceDef) -> Vec<Signal>`:**
Examine readable/writable ratios of non-system fields:
- High writable ratio (>50% writable non-system fields) → Collect (weight: 0.35)
- Write-only fields present (readable=false, writable=true) → Collect (weight: 0.2 * count)
- Mostly read-only (>70% non-writable) → Summarize (weight: 0.2)
- More readable than writable → Focus (weight: 0.1)

**Aggregation: `aggregate_signals(all_signals: Vec<Signal>) -> HashMap<Intent, (f64, Vec<String>)>`:**
Sum weights per intent, collect signal names per intent.

**Normalization: `normalize_scores(raw: HashMap<Intent, (f64, Vec<String>)>) -> Vec<IntentScore>`:**
- Find max score across all intents
- If max <= 0.0, return empty vec (caller handles default)
- Divide each score by max → [0.0, 1.0] range
- Sort descending by confidence
- Tie-break by stable ordering: Process > Track > Collect > Browse > Focus > Summarize > Analyze (use a helper fn `intent_priority(intent: &Intent) -> u8`)

**IntentHint override: `apply_hints(scores: &mut Vec<IntentScore>, hints: &[IntentHint])`:**
- Exclude hints: remove matching intents from results
- Primary hints: remove if present, insert at position 0 with confidence 1.0 and "intent_hint_primary" signal
