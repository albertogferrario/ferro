  <action>
Add three new analyzer functions to derive.rs and wire them into `derive_intents()`:

**Analyzer 3: `analyze_state_machine(service: &ServiceDef) -> Vec<Signal>`:**
If `service.state_machine` is None, return empty vec. Otherwise:

Process vs Track discrimination by SHAPE (this is the key differentiator from research Pitfall 3):

*Process signals (branching + guards):*
- Guard density: count guarded transitions / total transitions. If > 0 → Process weight = 0.4 * ratio. Signal: "{N}/{M}_guarded_transitions"
- Branching factor: count states with >1 outgoing transition. If > 0 → Process weight += 0.15. Signal: "{N}_branching_states"
- Actions with transition_trigger present in service.actions → Process weight += 0.25 * (count / total_actions). Signal: "{N}_transition_triggers"
- Multiple non-trivial states (>2 non-final) → Process weight += 0.10. Signal: "{N}_workflow_states"

*Track signals (linear + temporal):*
- Linear progression: non-final states > 2 AND branching states == 0 → Track weight = 0.3. Signal: "{N}_linear_states"
- Has final states → Track weight += 0.1. Signal: "has_final_states"
- No guards on transitions → Track weight += 0.1. Signal: "unguarded_progression"

**Analyzer 4: `analyze_relationships(service: &ServiceDef) -> Vec<Signal>`:**
Examine relationship cardinalities:
- OneToMany or ManyToMany relationships → Browse weight = 0.35 * count. Signal: "{N}_collection_relationships"
- OneToOne with NavigationHint::Inline → Focus weight = 0.15 * count. Signal: "{N}_inline_relationships"
- ManyToOne relationships → Focus weight += 0.1 * count. Signal: "{N}_parent_references"
- Total relationship count > 3 → Browse weight += 0.1. Signal: "rich_relationship_graph"

**Analyzer 5: `analyze_actions(service: &ServiceDef) -> Vec<Signal>`:**
Examine action patterns:
- Actions with transition_trigger → Process weight = 0.15 * count. Signal: "{N}_workflow_actions"
- Actions with >2 inputs → Collect weight = 0.15 * count. Signal: "{N}_complex_input_actions"
- Actions with preconditions → Process weight += 0.1 * count. Signal: "{N}_guarded_actions"
- Total actions > 0 but no transition triggers and no preconditions → Browse weight += 0.05. Signal: "simple_crud_actions"

**Wire into derive_intents():** Add calls to the three new analyzers in the signal collection loop, alongside the existing field meaning and writability analyzers.
