pub struct RuntimeRequirementsReport {
    pub required: Vec<RequiredPackage>,      // what registry says you need
    pub dockerfile_present: bool,
    pub installed_in_dockerfile: Vec<String>,// apt packages found in Dockerfile
    pub missing_in_dockerfile: Vec<String>,  // required - installed
}

#[derive(Debug, Serialize)]
pub struct RequiredPackage {

    pub apt_packages: Vec<String>,
}

pub fn execute(project_root: &Path) -> Result<RuntimeRequirementsReport>;

    - Fixture C: ffmpeg-next in Cargo.toml + Dockerfile already installs ffmpeg → required includes ffmpeg, missing empty

    - Fixture E: Cargo.toml missing → error

  <action>
    Create `ferro-mcp/src/tools/runtime_requirements.rs`:

    1. Module doc: "runtime_requirements MCP tool — maps Cargo crate deps to apt runtime packages via the ferro-cli RUNTIME_DEP_REGISTRY (D-07..D-10). Read-only (D-11)."
    2. Imports:
       ```rust
       use crate::error::{McpError, Result};
       use crate::tools::deploy_common::{scan_runtime_dep_matches, RuntimeDep};
       use regex::Regex;
       use serde::Serialize;
       use std::fs;
       use std::path::Path;
       ```
    3. Define the types from `<interfaces>` above.
    4. Helper `fn parse_dockerfile_apt_packages(content: &str) -> Vec<String>`:
       - Regex: `(?m)apt-get\s+install[^\n]*` — for each match line, split on whitespace, keep tokens after `install` that don't start with `-` and aren't `apt-get`/`install`/`-y`/`--no-install-recommends`/`&&`/`\\`.
       - Also handle multi-line with `\` continuations: preprocess by collapsing `\\\n` into spaces before regex.
       - Return sorted, deduped list.
    5. `pub fn execute(project_root: &Path) -> Result<RuntimeRequirementsReport>`:
       - Read `Cargo.toml` (error if missing: `McpError::tool("runtime_requirements", "Cargo.toml not found")`).
       - Call `scan_runtime_dep_matches(&content)` → Vec<&'static RuntimeDep>.
       - Build `required: Vec<RequiredPackage>` from the matches.
       - Compute unique required apt set (flat_map + dedup).
       - Dockerfile path = `project_root.join("Dockerfile")`. If present: read, run parser; `dockerfile_present=true`. Else empty vec, `dockerfile_present=false`.
       - `missing_in_dockerfile`: if dockerfile_present, compute required_set - installed_set (sorted). Else empty.
       - Return report.
    6. `#[cfg(test)] mod tests` covering Fixtures A–E using `tempfile::TempDir` and inline Cargo.toml + Dockerfile strings. Include a test for the apt-parser alone with multi-line `RUN apt-get install -y \\\n    chromium \\\n    fonts-liberation`.

    Update `ferro-mcp/src/tools/mod.rs`: add `pub mod runtime_requirements;`.

    Reuses Plan 01 registry via Plan 02 re-export — do NOT duplicate the crate→apt mapping.
