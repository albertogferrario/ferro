#[derive(Debug, Serialize)]
pub struct DiffRow {
    pub key: String,
    pub local: Option<String>,   // None if missing locally
    pub remote: Option<String>,  // None if missing in app.yaml
    pub classification: Classification,
}

#[derive(Debug, Serialize, PartialEq, Eq)]
#[serde(rename_all = "snake_case")]
pub enum Classification { Aligned, MissingLocal, MissingRemote, ScopeMismatch }

#[derive(Debug, Serialize)]
pub struct DiffEnvReport {
    pub rows: Vec<DiffRow>,           // all keys (union), sorted
    pub drift_count: usize,           // rows where classification != Aligned
    pub secrets_marked_plain: Vec<String>, // key names that is_secret() but app.yaml scope != SECRET
}

pub fn execute(project_root: &Path) -> Result<DiffEnvReport>;

  <action>
    Create `ferro-mcp/src/tools/deploy_diff_env.rs`:

    1. Module doc: "deploy_diff_env — compare local env source against .do/app.yaml envs block. Read-only (D-11). 3-column table output per D-06."
    2. Imports from `crate::tools::deploy_common::{parse_env_example, is_secret, EnvEntry}`, plus `regex::Regex`, `serde::Serialize`, `std::fs`, `std::collections::BTreeMap`, `std::path::Path`.
    3. Add `pub source: String` to DiffEnvReport (values: "env" or "env_example").
    4. Helper `fn load_local_env(root: &Path) -> Option<(String, Vec<EnvEntry>)>`:
       - Try `root.join(".env")` first, then `.env.example`. Return (source_label, parsed entries) or None.
    5. Helper `fn parse_app_yaml_envs(content: &str) -> Vec<(String, String, Option<String>)>` returning (key, value, scope):
       - Use regex over the full file. Match blocks shaped like:
         ```yaml
         - key: FOO
           value: "bar"
           scope: RUN_AND_BUILD_TIME
           type: SECRET          # optional
         ```
       - Regex approach: split on `- key:` then for each segment extract `key`, `value`, `type` via `Regex::new(r"^\s*(key|value|type):\s*(.+)$")` line-by-line.
       - Do NOT pull serde_yaml — reuse regex (already in ferro-mcp deps).
       - Return scope = Some("SECRET") if `type: SECRET` present, else None.
    6. `pub fn execute(project_root: &Path) -> Result<DiffEnvReport>`:
       - Load local env (error if both missing): `McpError::tool("deploy_diff_env", "no local env source (.env or .env.example)")`
       - Load `.do/app.yaml`; error if missing.
       - Build BTreeMap<String, DiffRow>:
         - For each local entry: insert row with local=Some(value), remote=None, classification=MissingRemote.
         - For each app.yaml entry: if key exists, set remote and re-classify (Aligned if values match AND scope correct for is_secret; ScopeMismatch if is_secret(key) and scope != Some("SECRET")). Else insert new row with local=None, classification=MissingLocal.
       - Compute `drift_count` and `secrets_marked_plain`.
       - Return report with sorted rows.
