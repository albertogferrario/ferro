    1. Module doc: "deploy_check MCP tool — pre-flight deploy validation. Read-only (D-11). Structured severity report per D-01/D-02/D-03."
    2. Imports:
       ```rust
       use crate::error::{McpError, Result};
       use crate::tools::deploy_common::{
           find_ferro_path_deps, parse_env_example, EnvEntry,
       };
       use serde::Serialize;
       use std::fs;

       ```
    3. Types:
       ```rust
       #[derive(Debug, Serialize, PartialEq, Eq)]
       #[serde(rename_all = "snake_case")]
       pub enum Severity { Blocker, Warning, Info }

       #[derive(Debug, Serialize)]
       pub struct Finding {
           pub code: String,     // e.g. "missing_dockerfile"
           pub severity: Severity,
           pub message: String,  // human-readable
           pub detail: Option<serde_json::Value>, // structured extras
       }

       #[derive(Debug, Serialize)]
       pub struct DeployCheckReport {
           pub status: String,   // "ok" | "warnings" | "blocked"
           pub findings: Vec<Finding>,
           pub checked: CheckedFiles,
       }

       #[derive(Debug, Serialize, Default)]
       pub struct CheckedFiles {
           pub dockerfile: bool,
           pub app_yaml: bool,
           pub env_example: bool,
           pub cargo_toml: bool,
       }
       ```
    4. `pub fn execute(project_root: &Path) -> Result<DeployCheckReport>`:
       - Build an empty findings Vec and CheckedFiles.
       - **check_dockerfile**: if `project_root.join("Dockerfile")` missing → push blocker "missing_dockerfile".
       - **check_app_yaml**: if `project_root.join(".do/app.yaml")` missing → push blocker "missing_app_yaml".
       - **check_ferro_path_deps**: read `Cargo.toml`; call `find_ferro_path_deps`; if non-empty → blocker "ferro_path_deps" with detail = `json!({ "crates": [...] })`.
       - **check_sqlite_database_url**: read `.env.example` if present; parse with `parse_env_example`; find `DATABASE_URL` entry; if value starts with `sqlite:` (strip quotes) → blocker "sqlite_database_url".
       - **check_env_drift**: if both `.env.example` and `.do/app.yaml` present, parse env keys from both; diff. Keys in example not in app.yaml → warning "missing_env_var" (one Finding per missing key, detail = `json!({"key": "FOO"})`). Keys in app.yaml not in example → info "extra_env_var".
         - To parse app.yaml envs block, read as string and grep for `- key:` lines OR use `serde_yaml` if already a dep; otherwise use a minimal regex: `\s*-\s+key:\s*(\S+)`. Prefer regex (already in deps) to avoid adding serde_yaml.
       - **check_git_state**: shell out to `git status --porcelain` in project_root; if stdout non-empty → warning "dirty_git_tree". Then `git rev-parse --abbrev-ref HEAD` to get branch, then `git rev-list --count @{u}..HEAD` to count unpushed commits; if >0 → warning "unpushed_commits" with count. Wrap each git call in best-effort (no remote upstream = info "no_upstream", don't error). Use `Command::new("git").current_dir(project_root)`.
       - Derive `status`: "blocked" if any Blocker, "warnings" if any Warning, else "ok".
       - Return report.
    5. Add `#[cfg(test)] mod tests` with fixtures built via `tempfile::TempDir`:
       - test_missing_files_flagged: empty dir → both missing_dockerfile + missing_app_yaml blockers.
       - test_ferro_path_dep_blocks: write Cargo.toml with ferro path dep → ferro_path_deps blocker present.
       - test_sqlite_database_url_blocks: write .env.example with `DATABASE_URL=sqlite://x.db` → sqlite_database_url blocker.
       - test_env_drift_warning: example has FOO, app.yaml has only BAR → missing_env_var for FOO, extra_env_var for BAR.
       - test_clean_project_ok: write Dockerfile, .do/app.yaml (with envs matching example), Cargo.toml without ferro path deps, .env.example with postgres DATABASE_URL → status = "ok", findings empty.

    Update `ferro-mcp/src/tools/mod.rs`: add `pub mod deploy_check;` in alphabetical position.

    DO NOT write any files from the tool. DO NOT call any process that mutates state. Per D-11.
