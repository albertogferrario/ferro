<objective>
Implement webhook verification, event dispatch, and subscription sync for Stripe webhook endpoints.

Purpose: Webhooks are the primary mechanism for keeping billing state in sync. Platform webhooks handle subscription lifecycle; Connect webhooks handle tenant payment events. Both verify HMAC signatures inline, ack 200 immediately, and dispatch processing asynchronously via ferro-queue per locked decision.
Output: Webhook verification, event types, handler functions, and subscription state sync.
</objective>
