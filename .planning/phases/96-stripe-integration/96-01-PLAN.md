    - plan_satisfies("enterprise", "pro") returns true (enterprise satisfies pro)
    - plan_satisfies("pro", "free") returns true (pro satisfies free)
    - plan_satisfies("free", "pro") returns false (free does NOT satisfy pro)
    - plan_satisfies("pro", "enterprise") returns false
    - plan_satisfies("free", "free") returns true (same plan satisfies itself)
    - SubscriptionStatus serializes to snake_case JSON (e.g., "past_due", "incomplete_expired")
    - SubscriptionInfo serializes to JSON with all expected fields
    - StripeConfig loads api_key, webhook_secret, connect_webhook_secret from provided values
    - Error enum has variants for Config, Stripe, NoConnectAccount
  </behavior>
  <action>
    1. Add "ferro-stripe" to workspace members in root Cargo.toml.

    2. Create ferro-stripe/Cargo.toml:
       - name = "ferro-stripe", version.workspace = true, edition.workspace = true
       - Dependencies: async-stripe = { version = "0.41", default-features = false, features = ["runtime-tokio-hyper", "billing", "checkout", "connect", "webhook-events"] }
       - Also: thiserror 1.0, serde with derive, serde_json 1, chrono 0.4 with serde feature, tokio (sync feature), async-trait 0.1

       - Return Error::Config if required vars missing

    5. Create ferro-stripe/src/client.rs:
       - Static STRIPE_CLIENT: OnceLock<stripe::Client>
       - Static STRIPE_CONFIG: OnceLock<StripeConfig>
       - pub struct Stripe; with:
         - pub fn init(config: StripeConfig) — initializes OnceLock with stripe::Client::new(&config.api_key), stores config
         - pub fn client() -> &'static stripe::Client — unwraps OnceLock (panics if not initialized, matching ferro-notifications pattern)
         - pub fn config() -> &'static StripeConfig — unwraps config OnceLock

    6. Create ferro-stripe/src/subscription/mod.rs:
       - SubscriptionStatus enum: Trialing, Active, Incomplete, IncompleteExpired, PastDue, Canceled, Unpaid, Paused
         - Derive: Debug, Clone, PartialEq, serde::Serialize, serde::Deserialize
         - #[serde(rename_all = "snake_case")]
       - SubscriptionInfo struct with fields: stripe_subscription_id (String), plan (String), status (SubscriptionStatus), trial_ends_at (Option<chrono::DateTime<chrono::Utc>>), cancel_at_period_end (bool), current_period_end (chrono::DateTime<chrono::Utc>), stripe_connect_account_id (Option<String>)
         - Derive: Debug, Clone, serde::Serialize
       - Helper methods: on_trial(), subscribed(), on_grace_period() — per RESEARCH.md pattern
       - pub fn plan_satisfies(tenant_plan: &str, required_plan: &str) -> bool
         - Plan ordering: ["free", "pro", "enterprise"] — index-based comparison, higher index satisfies lower
         - Unknown plans: only satisfy themselves (exact match)

    7. Create ferro-stripe/src/connect/mod.rs:
       - pub struct ConnectAccount { pub account_id: String, pub onboarding_complete: bool }
       - Module stub for checkout.rs (Plan 04 fills in)

    8. Create ferro-stripe/src/lib.rs:
       - pub mod client, config, connect, error, subscription
       - Re-export key types: pub use client::Stripe, config::StripeConfig, error::Error, subscription::{SubscriptionInfo, SubscriptionStatus, plan_satisfies}, connect::ConnectAccount
       - Module-level doc comment following ferro-cache pattern

    9. Run cargo fmt, clippy, and tests.
