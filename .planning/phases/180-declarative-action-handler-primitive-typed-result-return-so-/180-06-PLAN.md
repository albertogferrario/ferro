<objective>
Add an `action_handler` code template to `ferro-mcp/src/tools/code_templates.rs` so agents introspecting the framework via MCP discover the new primitive alongside the existing CRUD handler templates.

Purpose: VISION.md identifies the agent-readable surface (MCP introspection) as part of ferro's killer feature. The `code_templates` MCP tool is the canonical "show me how to write X" answer for an agent scaffolding a new handler. If `#[action]` ships without an MCP template, agents will keep generating `#[handler]` + `error_response(...)` ladders even after the primitive lands — defeating the purpose of the phase.

Output: A single new `CodeTemplate { name: "action_handler", category: "handler", ... }` entry appended to the `handler_templates()` vec in `ferro-mcp/src/tools/code_templates.rs`, immediately after the existing `update_handler` / `delete_handler` entries (so it lands at the end of the handler list as the "newest" pattern).
</objective>
