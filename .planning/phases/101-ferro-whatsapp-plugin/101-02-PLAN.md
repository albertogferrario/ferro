  <action>
    1. Create `ferro-whatsapp/src/webhook/mod.rs`:
       - `pub mod events;`
       - `pub fn verify_whatsapp_webhook(raw_body: &[u8], signature_header: &str, app_secret: &str) -> Result<(), Error>`:
         - Strip `sha256=` prefix from signature_header, return Error::WebhookVerification if missing
         - Compute HMAC-SHA256 of raw_body using app_secret via hmac/sha2/hex crates
         - Compare computed hex digest with expected using constant_time_eq
         - Return Ok(()) or Error::WebhookVerification("Signature mismatch")
       - `fn constant_time_eq(a: &[u8], b: &[u8]) -> bool` using XOR accumulation (NOT `==`)
       - `pub fn signed_whatsapp_payload(raw_body: &[u8], app_secret: &str) -> String`:
         - Compute HMAC-SHA256 and return `format!("sha256={hex_digest}")`
         - Feature-gated: `#[cfg(any(test, feature = "test-helpers"))]`
         - Also make it available without feature gate as a regular pub fn (matching research recommendation for test suites)

    2. Create `ferro-whatsapp/src/dedup.rs`:
       - `#[async_trait] pub trait DeduplicationStore: Send + Sync { async fn check_and_insert(&self, wamid: &str) -> Result<bool, Error>; }` -- returns true if duplicate
       - `pub struct InMemoryDeduplicationStore { inner: Arc<DashMap<String, AbortHandle>> }` where AbortHandle is the TTL timer
       - Default TTL: `const DEDUP_TTL: Duration = Duration::from_secs(300)` (5 minutes)
       - `impl InMemoryDeduplicationStore`:
         - `pub fn new() -> Self` and `impl Default`
         - `check_and_insert`: if key exists return Ok(true) with `tracing::debug!("duplicate wamid: {wamid}")`. If new: insert key, spawn TTL timer that removes after DEDUP_TTL, store AbortHandle. Return Ok(false).
       - TTL pattern: `let handle = tokio::spawn(async move { sleep(DEDUP_TTL).await; store.remove(&key); }).abort_handle();`
       - Never hold DashMap guard across .await

    3. Update `ferro-whatsapp/src/lib.rs`:
       - Ensure `pub mod dedup;` and `pub mod webhook;` are properly declared (remove stubs/TODOs from Plan 01)
       - Add re-exports: `pub use dedup::{DeduplicationStore, InMemoryDeduplicationStore};`
       - Add re-exports: `pub use webhook::verify_whatsapp_webhook;`
       - Conditionally re-export: `#[cfg(any(test, feature = "test-helpers"))] pub use webhook::signed_whatsapp_payload;`

    Tests use `#[tokio::test(start_paused = true)]` for TTL expiry tests with `yield_to_register_timer()` pattern from ferro-ai.

       ```rust
       #[derive(Debug, Clone, serde::Serialize, serde::Deserialize)]

       }
       ```
       - `impl ferro_queue::Job for ProcessWhatsAppWebhook` with `async fn handle()`:
         - Parse payload_json as serde_json::Value
         - Navigate Meta envelope: `entry[0].changes[0].value`
         - If `value.messages` array exists: for each message:
           - Extract wamid from `msg["id"]`, from_phone from `msg["from"]`, timestamp from `msg["timestamp"]` (parse string to i64), text from `msg["text"]["body"]`

           - Construct WhatsAppTextReceived and call `.dispatch_sync()`
         - If `value.statuses` array exists: for each status:
           - Extract wamid from `status["id"]`, status_str from `status["status"]`, timestamp from `status["timestamp"]`
           - Deserialize status_str into DeliveryStatus
           - Construct WhatsAppStatusUpdate and call `.dispatch_sync()`
         - Unknown/unparseable entries silently ignored (same as Stripe pattern)
       - `fn name() -> &'static str { "ProcessWhatsAppWebhook" }`
