**`plugins/map.rs` — MapPlugin struct implementing JsonUiPlugin:**

1. **MapProps struct** (used internally for typed deserialization of plugin props):
```rust
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct MapProps {
    pub center: [f64; 2],
    #[serde(default = "default_zoom")]
    pub zoom: u8,
    #[serde(default = "default_height")]
    pub height: String,
    #[serde(default)]
    pub markers: Vec<MapMarker>,
    #[serde(skip_serializing_if = "Option::is_none")]
    pub tile_url: Option<String>,
    #[serde(skip_serializing_if = "Option::is_none")]
    pub attribution: Option<String>,
    #[serde(skip_serializing_if = "Option::is_none")]
    pub max_zoom: Option<u8>,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct MapMarker {
    pub lat: f64,
    pub lng: f64,
    #[serde(skip_serializing_if = "Option::is_none")]
    pub popup: Option<String>,
}
```

Defaults: `zoom = 13`, `height = "400px"`.

2. **MapPlugin::render():**
   - Deserialize `props: &Value` into `MapProps` (fallback to error div if invalid)
   - Generate a unique container ID using a simple counter or random suffix (avoid ID collisions with multiple maps)
   - Render HTML: `<div data-ferro-map='{config_json}' style="height: {height}; width: 100%;"></div>`
   - The `data-ferro-map` attribute contains the full config as JSON (center, zoom, markers, tile_url, attribution, max_zoom)
   - Use `serde_json::to_string()` for the data attribute value, HTML-escape the result

3. **MapPlugin::css_assets():**
   Return Leaflet CSS CDN link with SRI:
   ```
   url: "https://unpkg.com/leaflet@1.9.4/dist/leaflet.css"
   integrity: Some("sha256-p4NxAoJBhIIN+hmNHrzRCf9tD/miZyoHS5obTRR9BMY=")
   crossorigin: Some("")
   ```

4. **MapPlugin::js_assets():**
   Return Leaflet JS CDN link with SRI:
   ```
   url: "https://unpkg.com/leaflet@1.9.4/dist/leaflet.js"
   integrity: Some("sha256-20nQCchB9co0qIjJZRGuk2/Z9VM+kNiyxNV1lvTlZBo=")
   crossorigin: Some("")
   ```

5. **MapPlugin::init_script():**
   Return the JavaScript initialization code that:
   - Runs on DOMContentLoaded
   - Discovers all `[data-ferro-map]` elements
   - Parses the JSON config from the data attribute
   - Creates Leaflet map with `L.map(element).setView(center, zoom)`
   - Adds tile layer (OSM default, configurable via tile_url/attribution/max_zoom)
   - Adds markers with optional popups
   - Uses `IntersectionObserver` to call `map.invalidateSize()` when container becomes visible (handles Tabs/Modals)
   - Uses `L.map(element)` (DOM element reference) NOT `L.map('id')` (avoids ID collision)

6. **MapPlugin::props_schema():**
   Return a JSON Schema object describing the Map component's props for MCP/agent discovery. Include description fields for each property, required fields (center), and examples.

7. **MapPlugin::component_type():** Return `"Map"`
