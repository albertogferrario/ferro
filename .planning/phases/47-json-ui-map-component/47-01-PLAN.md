1. **Asset struct:**

    pub url: String,
    pub integrity: Option<String>,

2. **JsonUiPlugin trait** (mirrors Layout trait pattern):
```rust
pub trait JsonUiPlugin: Send + Sync {
    /// Unique component type name (e.g., "Map"). Used in JSON: {"type": "Map", ...}
    fn component_type(&self) -> &str;
    /// JSON Schema describing accepted props. Used by MCP/agents for discovery.
    fn props_schema(&self) -> serde_json::Value;
    /// Render the component to an HTML string.
    fn render(&self, props: &serde_json::Value, data: &serde_json::Value) -> String;
    /// CSS assets to load in head. Called once per page, deduplicated by URL.
    fn css_assets(&self) -> Vec<Asset>;
    /// JS assets to load before closing body. Called once per page, deduplicated by URL.
    fn js_assets(&self) -> Vec<Asset>;
    /// Inline init JS emitted once per page after assets load. None if not needed.
    fn init_script(&self) -> Option<String>;
}
```

3. **PluginRegistry** — follow the exact same pattern as LayoutRegistry in layout.rs:
- `HashMap<String, Box<dyn JsonUiPlugin>>` storage
- `register()` and `get()` methods
- Global access via `static GLOBAL_PLUGIN_REGISTRY: OnceLock<RwLock<PluginRegistry>>`
- Convenience functions: `register_plugin()`, `get_plugin()`, `registered_plugin_types()` (returns Vec of type names for MCP discovery)

4. **`collect_plugin_assets()` function** — accepts a list of plugin type names (collected during render), returns deduplicated `(css_assets, js_assets, init_scripts)` tuple. Deduplicates by URL using a HashSet.

5. **Update `ferro-json-ui/src/lib.rs`:**
- Add `pub mod plugin;`
- Re-export: `Asset`, `JsonUiPlugin`, `PluginRegistry`, `register_plugin`, `get_plugin`, `registered_plugin_types`, `collect_plugin_assets`

Do NOT register any plugins yet (Map plugin comes in Plan 03).
