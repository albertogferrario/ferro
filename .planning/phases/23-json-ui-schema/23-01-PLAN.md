3. Create `ferro-json-ui/src/component.rs` — Component enum with tagged serde:
   ```rust
   #[derive(Debug, Clone, Serialize, Deserialize)]
   #[serde(tag = "type")]
   pub enum Component {
       Card(CardProps),
       Table(TableProps),
       Form(FormProps),
       Button(ButtonProps),
       Input(InputProps),
       Select(SelectProps),
       Alert(AlertProps),
       Badge(BadgeProps),
       Modal(ModalProps),
       Text(TextProps),
   }
   ```

   Define props structs for each component. Use `Option<T>` for optional fields, `#[serde(default)]` where appropriate. Key props:
   - **CardProps**: title, description (opt), children (Vec&lt;ComponentNode&gt;)
   - **TableProps**: columns (Vec&lt;Column&gt;), data_path (String — JSONPath), row_actions (opt Vec&lt;Action&gt;), empty_message (opt)
   - **FormProps**: action (Action), fields (Vec&lt;ComponentNode&gt;), method (opt HttpMethod)
   - **ButtonProps**: label, variant (enum: Primary, Secondary, Danger, Ghost — default Primary), disabled (opt bool)
   - **InputProps**: field (String — form field name), label, input_type (enum: Text, Email, Password, Number, Textarea, Hidden — default Text), placeholder (opt), required (opt bool)
   - **SelectProps**: field, label, options (Vec&lt;SelectOption&gt;), placeholder (opt), required (opt bool)
   - **AlertProps**: message, variant (enum: Info, Success, Warning, Error — default Info)
   - **BadgeProps**: label, variant (enum: Default, Primary, Success, Warning, Error — default Default)
   - **ModalProps**: title, children (Vec&lt;ComponentNode&gt;), trigger_label (opt)
   - **TextProps**: content (String), element (opt enum: P, H1, H2, H3, Span — default P)

   Define helper types: `Column` (key, label, format opt enum: Date, DateTime, Currency, Boolean), `SelectOption` (value, label), `HttpMethod` (GET, POST, PUT, PATCH, DELETE — default POST).

   Wrap Component in `ComponentNode` struct that adds shared fields:
   ```rust
   #[derive(Debug, Clone, Serialize, Deserialize)]
   pub struct ComponentNode {
       pub key: String,
       #[serde(flatten)]
       pub component: Component,
       #[serde(default, skip_serializing_if = "Option::is_none")]
       pub action: Option<Action>,
       #[serde(default, skip_serializing_if = "Option::is_none")]
       pub visibility: Option<Visibility>,
   }
   ```

4. Create `ferro-json-ui/src/action.rs` — Action declarations:
   ```rust
   #[derive(Debug, Clone, Serialize, Deserialize)]
   pub struct Action {
       pub handler: String,  // "controller.method" format
       #[serde(default)]
       pub method: HttpMethod,
       #[serde(default, skip_serializing_if = "Option::is_none")]
       pub confirm: Option<ConfirmDialog>,
       #[serde(default, skip_serializing_if = "Option::is_none")]
       pub on_success: Option<ActionOutcome>,
       #[serde(default, skip_serializing_if = "Option::is_none")]
       pub on_error: Option<ActionOutcome>,
   }
   ```
   Define `ConfirmDialog` (title, message opt, variant: Default/Danger default Default).
   Define `ActionOutcome` with serde-tagged enum: Redirect { url }, ShowErrors, Refresh, Notify { message, variant }.

5. Create `ferro-json-ui/src/visibility.rs` — Conditional visibility:
   ```rust
   #[derive(Debug, Clone, Serialize, Deserialize)]
   #[serde(untagged)]
   pub enum Visibility {
       Condition(VisibilityCondition),
       And { and: Vec<Visibility> },
       Or { or: Vec<Visibility> },
       Not { not: Box<Visibility> },
   }

   #[derive(Debug, Clone, Serialize, Deserialize)]
   pub struct VisibilityCondition {
       pub path: String,  // JSONPath
       pub operator: VisibilityOperator,
       #[serde(default, skip_serializing_if = "Option::is_none")]
       pub value: Option<serde_json::Value>,
   }
   ```
   Define `VisibilityOperator` enum: Exists, NotExists, Eq, NotEq, Gt, Lt, Gte, Lte, Contains, NotEmpty, Empty — with snake_case serde rename.

6. Create `ferro-json-ui/src/lib.rs` — public API exports:

   ```rust
   pub mod component;
   pub mod visibility;

   pub use action::{Action, ActionOutcome, ConfirmDialog};
   pub use component::{
       Component, ComponentNode, CardProps, TableProps, FormProps,
       ButtonProps, InputProps, SelectProps, AlertProps, BadgeProps,
       ModalProps, TextProps, Column, ColumnFormat, SelectOption,
       HttpMethod, ButtonVariant, InputType, AlertVariant, BadgeVariant,
       TextElement, DialogVariant,
   };
   pub use visibility::{Visibility, VisibilityCondition, VisibilityOperator};
   ```

All variant enums should derive Default (with appropriate defaults) and use `#[serde(rename_all = "snake_case")]`.

1. Create `ferro-json-ui/src/view.rs` — Top-level view container:
   ```rust
   #[derive(Debug, Clone, Serialize, Deserialize)]
   pub struct JsonUiView {
       #[serde(rename = "$schema")]
       pub schema: String,  // "ferro-json-ui/v1"
       #[serde(default, skip_serializing_if = "Option::is_none")]
       pub layout: Option<String>,
       #[serde(default, skip_serializing_if = "Option::is_none")]
       pub title: Option<String>,
       pub components: Vec<ComponentNode>,
   }
   ```

   Add a constant: `pub const SCHEMA_VERSION: &str = "ferro-json-ui/v1";`

   Add a builder on JsonUiView:
   - `JsonUiView::new()` — sets schema to SCHEMA_VERSION, empty components
   - `.title(impl Into<String>)` — set title
   - `.layout(impl Into<String>)` — set layout
   - `.component(ComponentNode)` — push component
   - `.components(Vec<ComponentNode>)` — set all components

   Add `JsonUiView::from_json(json: &str) -> Result<Self, serde_json::Error>` — parse from JSON string.
   Add `JsonUiView::to_json(&self) -> Result<String, serde_json::Error>` — serialize to JSON string.
   Add `JsonUiView::to_json_pretty(&self) -> Result<String, serde_json::Error>` — serialize to pretty JSON.
