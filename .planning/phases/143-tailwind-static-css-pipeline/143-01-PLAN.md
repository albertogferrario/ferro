<objective>
Create the static Tailwind CSS asset pipeline for ferro-json-ui: a Tailwind v4 input file, the pre-built `ferro-base.css` output (checked into git), a Rust module that embeds the CSS at compile time via `include_str!`, a regeneration script, and a CI check that fails on drift.

Purpose: Eliminate the Tailwind browser JIT runtime dependency. Every utility class ferro-json-ui components emit must be available as static CSS so Safari/WebKit users render pages without WASM downloads.

Output: A committed `ferro-base.css`, an `assets` module exporting `FERRO_BASE_CSS: &'static str`, a re-export from the crate root, a shell script contributors can run after adding new components, and a CI job that diffs the committed CSS against freshly-generated output.

This is Wave 1 — Plan 02 (ferro-theme default.css conversion) runs in parallel; Plan 03 (framework wiring) depends on `FERRO_BASE_CSS` being exported from this plan.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| contributor → repo | Contributors run scripts/gen-ferro-base-css.sh locally; output committed into the repo. |
| CI → build artifacts | CI downloads Tailwind CLI from GitHub Releases and regenerates CSS in ephemeral /tmp for comparison. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-143-01 | Tampering | ferro-base.css committed file | mitigate | CI drift check regenerates from committed input.css and diffs; any hand-edit fails CI. |
| T-143-02 | Tampering | Tailwind CLI binary downloaded in CI | accept | Binary fetched from GitHub Releases via HTTPS to tailwindlabs/tailwindcss. Download integrity guaranteed by TLS; ASVS L1 does not require SRI/checksum pinning for build tools. |
| T-143-03 | Information Disclosure | input.css `@source` globs | accept | Input file scans `ferro-json-ui/src` and `framework/src` only — no access to env vars, secrets, or generated artifacts. Tailwind extracts plain-text tokens matching utility patterns; no code execution. |
| T-143-04 | Denial of Service | scripts/gen-ferro-base-css.sh | accept | Script runs locally/CI only; not invoked from network-facing paths. Resource use bounded by Tailwind CLI, which has no known pathological inputs for the scan patterns used here. |

All other STRIDE categories (Spoofing, Repudiation, Elevation of Privilege) are not applicable: no authentication, no auditing, no privilege boundary is crossed by build tooling.
</threat_model>
