<objective>
Convert `ferro-theme/assets/default.css` from Tailwind-CDN-specific syntax (`@import "tailwindcss"` + `@theme { ... }`) to standard CSS variable declarations (`:root { ... }`). This enables the file to be embedded verbatim into an HTML `<style>` tag and interpreted by browsers directly — no Tailwind JIT runtime required.

Purpose: Plan 03 will remove `<style type="text/tailwindcss">` injection (the magic MIME type that signals the Tailwind browser runtime to process `@theme` directives) and replace it with a plain `<style>` tag. For the switch to work, the CSS being injected must itself use standard at-rules and selectors. `@theme` is not a standard CSS at-rule — browsers ignore the entire block as an unknown at-rule, leaving pages unstyled.

Output: An updated `default.css` using `:root { ... }`, `@media (prefers-color-scheme: dark) { :root { ... } }`, and `[data-theme="dark"] { ... }` — exactly the three patterns specified in RESEARCH.md Pattern 5.

This plan is in Wave 1 and is independent of Plan 01. Plan 03 depends on both 01 and 02.
</objective>
