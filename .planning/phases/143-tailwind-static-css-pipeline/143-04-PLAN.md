<objective>
Update the `ferro make:theme` scaffolder's `tokens_css_template()` output and its tests so newly scaffolded themes ship plain CSS variable declarations (`:root { ... }`) instead of the Tailwind-CDN-specific `@import "tailwindcss"` + `@theme { ... }` syntax.

Purpose: Plan 02 converted the framework-embedded default theme file. Plan 03 removed the `<style type="text/tailwindcss">` injection path. New themes scaffolded by users must follow the same plain-CSS convention — otherwise `ferro make:theme myapp` produces a file whose `@theme` blocks are silently ignored by browsers under the new injection path.

Output: A template string that mirrors the structure of `ferro-theme/assets/default.css` (as converted in Plan 02), and four test updates that lock in the new contract.

This is Wave 3. Depends on Plan 03 (the runtime injection contract must be settled before scaffolders commit to a format).
</objective>
