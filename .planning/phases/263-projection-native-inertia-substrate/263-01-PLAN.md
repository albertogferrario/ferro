Add a pure `schema_contract(&ServiceDef) -> SchemaContract` derivation to `ferro-projections`,
the natural sibling of `derive_intents()`. It projects the field set (with access modes and
meanings), the action definitions (with preconditions and inputs), and the declared guards —

`Inertia::from_projection` props. It must live in `ferro-projections` so any future non-Inertia
renderer (generic JSON, mobile) can consume the identical contract without depending on an
output crate (OQ-1 resolved: `ferro-projections`).

    use crate::action::{ActionDef, InputDef};

    #[derive(Debug, Clone, Serialize, Deserialize)]
    pub struct SchemaContract {

    ```rust
    /// Derives the schema contract from a service definition.
    ///
    /// Pure derivation — no runtime deps, no async, no side effects. Renders nothing.
    /// Sibling of `derive_intents`. Describes fields (with access modes + meanings),
    /// action definitions (preconditions + inputs), and declared guards.
    pub fn schema_contract(service: &ServiceDef) -> SchemaContract {
        SchemaContract {
            name: service.name.clone(),
            display_name: service.display_name.clone(),
            fields: service.fields.iter().map(FieldContract::from).collect(),
            actions: service.actions.iter().map(ActionContract::from).collect(),
            guards: service.guards.iter().map(|g| g.name.clone()).collect(),
            has_state_machine: service.state_machine.is_some(),
        }
    }
    ```
