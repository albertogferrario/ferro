  <name>Task 1: Create state.rs with StateMachine, StateDef, Transition, Warning types + builders + validation</name>
  <files>ferro-projections/src/state.rs</files>
  <action>
Create `ferro-projections/src/state.rs` with the following types, following patterns from 85-RESEARCH.md code examples:

**StateMachine struct:**
- Fields: name (String), display_name (Option<String>), description (Option<String>), initial_state (String), states (Vec<StateDef>), transitions (Vec<Transition>)
- Derive: Debug, Clone, Serialize, Deserialize
- Use `#[serde(skip_serializing_if = "Option::is_none")]` on display_name and description
- Builder methods (consuming `mut self -> Self`): new(name), display_name(name), description(desc), initial(state), state(StateDef), transition(Transition)

**StateDef struct:**
- Fields: name (String), display_name (Option<String>), description (Option<String>), is_final (bool), on_enter (Vec<String>), on_exit (Vec<String>), metadata (Option<serde_json::Value>)
- Derive: Debug, Clone, Serialize, Deserialize
- Use `#[serde(skip_serializing_if = "Option::is_none")]` on optional fields. Use `#[serde(default)]` on is_final, on_enter, on_exit.
- Use `#[serde(skip_serializing_if = "Vec::is_empty")]` on on_enter and on_exit for cleaner JSON.
- Builder methods: new(name), display_name(name), description(desc), final_state(), on_enter(Vec<impl Into<String>>), on_exit(Vec<impl Into<String>>), metadata(serde_json::Value)

**Transition struct:**
- Fields: from (String), event (String), to (String), guard (Option<String>), actions (Vec<String>), description (Option<String>)
- Derive: Debug, Clone, Serialize, Deserialize
- Use `#[serde(skip_serializing_if = "Option::is_none")]` on guard and description. Use `#[serde(skip_serializing_if = "Vec::is_empty")]` and `#[serde(default)]` on actions.
- Builder methods: new(from, event, to), guard(guard), actions(Vec<impl Into<String>>), description(desc)

**Warning enum:**
- Variants: UnreachableState(String), DeadEndState(String), NoFinalStates
- Derive: Debug, Clone, PartialEq, Eq

**validate() method on StateMachine:**
- Returns `Result<Vec<Warning>, crate::Error>` using existing Error::Validation variant
- 5 checks per research: (1) initial_state non-empty, (2) initial_state exists in states, (3) all transition from/to reference existing states, (4) BFS reachability from initial, (5) dead-end non-final states, (6) no-final-states warning
- Uses std::collections::{HashSet, VecDeque} for BFS — no external dependencies

**Convenience methods on StateMachine:**
- `states_for_event(&self, event: &str) -> Vec<&Transition>` — returns all transitions triggered by a given event
- `events_from_state(&self, state: &str) -> Vec<&Transition>` — returns outgoing transitions from a state

Follow RESEARCH.md code examples closely. Do NOT add runtime execution logic (no `.send()`, no `.current_state()`). This is schema-only.
