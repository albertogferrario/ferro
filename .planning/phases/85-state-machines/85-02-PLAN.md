  <files>ferro-projections/src/state.rs</files>
  <action>
Add tests in `#[cfg(test)] mod tests` within state.rs. Follow Phase 84's test patterns (serde round-trip, builder chain, JSON structure).

**Serde tests:**
- `state_machine_serde_round_trip`: Build sample order machine (draft→pending→approved→completed with guards), serialize to JSON, deserialize, assert equality on name, initial_state, states.len(), transitions.len()
- `state_def_serde_round_trip`: Single state with all fields set (display_name, is_final, on_enter, on_exit, metadata), round-trip
- `transition_serde_round_trip`: Transition with guard and actions, round-trip
- `state_machine_json_omits_none_fields`: Minimal machine → JSON should not contain "display_name", "description", "guard", "on_enter", "on_exit", "actions"
- `state_machine_json_structure`: Validate JSON shape has "name", "initial_state", "states", "transitions" keys

**Builder tests:**
- `state_machine_builder_chain`: Full builder chain with all methods, assert all fields populated
- `state_def_builder_chain`: StateDef with all builder methods, assert fields
- `transition_builder_chain`: Transition with guard and actions, assert fields
- `state_def_defaults`: StateDef::new("x") has is_final=false, empty on_enter/on_exit, None display_name/description/metadata

**Validation tests:**
- `validate_valid_machine`: Sample order machine validates with no warnings
- `validate_missing_initial_state`: Empty initial_state → Error
- `validate_initial_state_not_in_states`: initial_state references nonexistent state → Error
- `validate_transition_source_not_in_states`: Transition from nonexistent state → Error
- `validate_transition_target_not_in_states`: Transition to nonexistent state → Error
- `validate_unreachable_state`: State with no incoming transitions (not initial) → Warning::UnreachableState
- `validate_dead_end_state`: Non-final state with no outgoing transitions → Warning::DeadEndState
- `validate_no_final_states`: Machine with no final states → Warning::NoFinalStates
- `validate_all_warnings_combined`: Machine with unreachable + dead-end + no final → all three warnings

**Convenience method tests:**
- `events_from_state_returns_outgoing`: Verify events_from_state returns correct transitions
- `states_for_event_returns_matching`: Verify states_for_event returns all transitions for an event

Use `assert_eq!`, `assert!`, `assert!(warnings.contains(...))` patterns. Create a `sample_machine()` helper function per research examples.
