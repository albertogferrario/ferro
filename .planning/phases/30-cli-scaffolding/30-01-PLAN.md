Create `ferro make:json-view` command following the same pattern as `make_controller` and `make_inertia`.

**Command behavior:**
- Takes a `name` argument (e.g., `UserIndex`, `Dashboard`, `user_index`)
- Converts to snake_case for filename, PascalCase for function/module naming
- Creates file at `src/views/{snake_name}.rs`
- Updates `src/views/mod.rs` with `pub mod {snake_name};` (create mod.rs if missing)
- If `src/views/` directory doesn't exist, create it

**Template generates a Rust file with:**
```rust
//! {Name} JSON-UI view

use ferro::{{
    Action, CardProps, Component, ComponentNode, HttpMethod, JsonUiView, TextElement, TextProps,
}};

/// Build the {Name} view.
pub fn view() -> JsonUiView {{
    JsonUiView::new()
        .title("{Title}")
        .layout("app")
        .component(ComponentNode {{
            key: "heading".to_string(),
            component: Component::Text(TextProps {{
                content: "{Title}".to_string(),
                element: TextElement::H1,
            }}),
            action: None,
            visibility: None,
        }})
        .component(ComponentNode {{
            key: "content".to_string(),
            component: Component::Card(CardProps {{
                title: "{Title}".to_string(),
                description: Some("Add your content here".to_string()),
                children: vec![],
                footer: vec![],
            }}),
            action: None,
            visibility: None,
        }})
}}
```

Where `{Title}` is derived from the snake_case name (e.g., `user_index` → `User Index`).

**Usage hint printed after generation:**
```
View {name} created successfully!

Usage:
  1. Use the view in a handler:
     use crate::views::{snake_name};

     pub async fn index() -> Response {
         JsonUi::render(&{snake_name}::view(), &json!({}))
     }
```

**Implementation details:**
1. `ferro-cli/src/commands/make_json_view.rs`: New file following `make_controller.rs` pattern exactly. Includes `run(name: String)`, `is_valid_identifier()`, `to_snake_case()`, `update_mod_file()` helpers (copy from make_controller, adapt paths to `src/views/`).
2. `ferro-cli/src/commands/mod.rs`: Add `pub mod make_json_view;`
3. `ferro-cli/src/main.rs`: Add `MakeJsonView` variant to `Commands` enum with `#[command(name = "make:json-view")]` attribute and `name: String` field. Add match arm calling `commands::make_json_view::run(name)`.
4. `ferro-cli/src/templates/mod.rs`: Add `pub fn json_view_template(name: &str, title: &str) -> String` function that returns the view file content with placeholders filled.

```rust
use ferro::{JsonUi, JsonUiView, ComponentNode, Component, CardProps, TextProps, TextElement};

#[handler]
pub async fn index() -> Response {
    let view = JsonUiView::new()
        .title("{{Title}}")
        .layout("app")
        .component(ComponentNode {
            key: "heading".to_string(),
            component: Component::Text(TextProps {

            action: None,
            visibility: None,

    JsonUi::render(&view, &json!({}))
}
```

```rust
                        visibility: None,
```
