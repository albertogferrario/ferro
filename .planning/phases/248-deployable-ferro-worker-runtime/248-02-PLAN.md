<objective>
Teach the `#[offload]` proc-macro to accept an optional `queue = "name"` argument (D-04) and
thread the declared queue into both the emitted `JobRegistrarEntry` (so
`registered_queue_names()` sees it) and the `Offloadable::offload()` body (so dispatch routes to
that queue). Default remains `"default"` when the argument is omitted. This makes fault-domain
routing declarative on the method — the single source of truth `ferro-mcp` can introspect —
rather than only at a runtime `.on_queue()` call site.

Purpose: satisfy D-04. The queue metadata emitted here is what Plan 01's `registered_queue_names()`
reads and what makes Plan 03's SC#1 (queue-scoped consumption) meaningful end to end.
Output: `ferro-macros/src/service.rs` parses the arg before stripping the attribute;
`ferro-macros/src/offload.rs` carries `declared_queue` through `collect_info`/`emit_job_items`
and emits `queue: Some("name")` + `.on_queue("name")`; the trybuild fixtures from Plan 00 go
GREEN (pass) / produce the expected error (fail), with the `.stderr` regenerated.
</objective>
