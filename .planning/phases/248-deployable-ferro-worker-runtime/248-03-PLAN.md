## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-248-03-01 | Elevation of Privilege | `--queue` string → DB claim filter | accept | Queue names filter `WorkerConfig.queues` and are passed to the parameterized claim query; never string-interpolated into SQL (RESEARCH § Security Domain). No injection surface. |
| T-248-03-02 | Denial of Service | Worker consuming an unintended queue set | mitigate | Explicit `--queue` scopes the fault domain; the "all registered queues" default is the documented safe behaviour for single-binary dev (D-03/D-05). No privilege change vs `serve`. |
| T-248-03-03 | Spoofing | worker process identity for requeue | accept | `WorkerLoop::worker_id` (UUIDv4) scopes `requeue_claimed_by` to the process — existing Phase 185 mechanism, unchanged here. |

No HIGH threats: the CLI runs under the same process model and env-sourced credentials as `serve`;
`--queue` is an operator-supplied string used only as a claim filter, never interpolated into SQL.
