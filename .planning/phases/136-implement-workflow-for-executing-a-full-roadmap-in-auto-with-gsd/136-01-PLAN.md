**Step 3 — Install Claude CLI:**

**Step 4 — Configure git identity:**

**Step 5 — Run GSD Roadmap** (the main loop):
- Use `env:` block with `ANTHROPIC_API_KEY: ${{ secrets.ANTHROPIC_API_KEY }}` and `GH_TOKEN: ${{ secrets.GITHUB_TOKEN }}`.
- Shell script (`bash`) that does:

```
MILESTONE="${{ inputs.milestone }}"
GSD_TOOLS="$HOME/.claude/get-shit-done/bin/gsd-tools.cjs"

# Phase loop: re-read roadmap state before each phase (per D-04)
while true; do
  # Get incomplete phases from roadmap analyze
  PHASES_JSON=$(node "$GSD_TOOLS" roadmap analyze 2>&1)

  # Extract incomplete phase numbers for this milestone
  # Filter: disk_status != "complete" AND belongs to target milestone
  # Use jq or node inline to parse
  PHASE_NUM=$(echo "$PHASES_JSON" | node -e "
    const data = JSON.parse(require('fs').readFileSync('/dev/stdin','utf8'));
    const incomplete = (data.phases || [])
      .filter(p => p.disk_status !== 'complete')
      .map(p => p.number);
    if (incomplete.length > 0) console.log(incomplete[0]);
    else console.log('DONE');
  ")

  if [ "$PHASE_NUM" = "DONE" ]; then
    echo "All phases complete for milestone $MILESTONE"
    break
  fi

  echo "=========================================="
  echo "Running phase $PHASE_NUM"
  echo "=========================================="

  # Per D-02: one fresh claude CLI invocation per phase
  # Use --print for non-interactive, --dangerously-skip-permissions for CI
  # Pipe the GSD autonomous command for this single phase
  # Capture output with tee for failure diagnosis
  claude --print \
    --dangerously-skip-permissions \
    --model sonnet \
    --verbose \
    -p "/gsd:autonomous --from $PHASE_NUM" \
    2>&1 | tee "/tmp/phase-${PHASE_NUM}-output.log"

  EXIT_CODE=${PIPESTATUS[0]}

  if [ $EXIT_CODE -ne 0 ]; then
    echo "Phase $PHASE_NUM failed with exit code $EXIT_CODE"

    # Per D-05 + D-06: stop and open GitHub issue
    LAST_LINES=$(tail -50 "/tmp/phase-${PHASE_NUM}-output.log")
    PHASE_DIR=$(ls -d .planning/phases/${PHASE_NUM}-* 2>/dev/null | head -1)

    gh issue create \
      --title "Phase ${PHASE_NUM} failed: GSD roadmap run" \
      --body "$(cat <<ISSUE_EOF
## Phase ${PHASE_NUM} failed

**Milestone:** ${MILESTONE}
**Exit code:** ${EXIT_CODE}
**Run:** ${{ github.server_url }}/${{ github.repository }}/actions/runs/${{ github.run_id }}

### Last 50 lines of output

\`\`\`
${LAST_LINES}
\`\`\`

### Phase directory

\`${PHASE_DIR:-unknown}\`
ISSUE_EOF
)"

    exit 1
  fi

  # Push any commits made during this phase
  git push origin HEAD || true
done
```

IMPORTANT implementation notes:
- The milestone filtering logic needs refinement: `roadmap analyze` returns ALL phases, not per-milestone. The script should filter phases that belong to the requested milestone. If `roadmap analyze` does not provide milestone info per phase, use a simpler approach: just run all incomplete phases in order (the milestone input serves as documentation/intent, and the user ensures only the target milestone's phases are incomplete).
- Per checker feedback: issue body MUST include exit code and last output lines. Use `tee` to capture output to a log file, then `tail` to extract last lines.
- The `--dangerously-skip-permissions` flag is essential for CI — no human to approve tool calls.
- Use `--print` mode (non-interactive, per D-02 fresh invocation pattern).
- After each successful phase, push commits so work is preserved even if a later phase fails.

**Permissions block:** Add `permissions: contents: write, issues: write` to the job.
