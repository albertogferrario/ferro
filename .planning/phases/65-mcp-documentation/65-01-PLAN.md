<task type="auto">
  <name>Task 1: Create list_lang_files MCP tool</name>
  <files>ferro-mcp/src/tools/list_lang_files.rs, ferro-mcp/src/tools/mod.rs, ferro-mcp/src/service.rs</files>
  <action>
Create a new MCP tool `list_lang_files` that scans the project's `lang/` directory and reports:

1. **Create `ferro-mcp/src/tools/list_lang_files.rs`:**
   - Define result structs: `LangFilesInfo` (locales vec, default_locale, fallback_locale, lang_path, total_keys, coverage report), `LocaleInfo` (locale name, files vec, key_count), `CoverageReport` (missing_keys map: locale -> vec of keys missing vs fallback)
   - `execute(project_root: &Path, locale_filter: Option<&str>) -> Result<LangFilesInfo, String>`
   - Read `.env` to extract APP_LOCALE, APP_FALLBACK_LOCALE, LANG_PATH (default "lang")
   - Scan `{project_root}/{lang_path}/` for locale directories
   - For each locale directory, read all `*.json` files, flatten nested keys with dot notation (same as ferro-lang's loader does), count total keys
   - If `locale_filter` provided, only return that locale's details
   - Build coverage report: for each non-fallback locale, find keys present in fallback but missing in that locale
   - Return structured JSON

2. **Add to `ferro-mcp/src/tools/mod.rs`:**
   - Add `pub mod list_lang_files;` in alphabetical order (after `list_jobs`)

3. **Add params struct and tool handler to `ferro-mcp/src/service.rs`:**
   - Add `ListLangFilesParams` struct with `locale: Option<String>` field
   - Add `#[tool]` handler following the pattern of `list_commands` or `list_broadcast_channels`
   - Description: "List available translation files, locales, keys, and coverage report.\n\n**When to use:** Understanding localization setup, checking available locales, finding missing translations, verifying translation coverage.\n\n**Returns:** Available locales with file names and key counts, default/fallback locale config, missing key report per locale.\n\n**Combine with:** `get_config` for locale settings, `list_commands` for make:lang CLI."

For .env parsing, use a simple line-by-line approach (read file, split by `=`, match key names). Do NOT add a dependency — keep it lightweight like other MCP tools.

For JSON key flattening, implement a simple recursive function that mirrors ferro-lang's dot-notation flattening: `{"auth": {"login": "..."}}` becomes key `"auth.login"`.
  </action>
  <verify>cargo build -p ferro-mcp 2>&1 | tail -5</verify>
  <done>
  - `list_lang_files` tool registered and compiles
  - Tool scans lang/ directory and returns locale info with key counts
  - Coverage report shows missing keys per locale vs fallback
  - Params support optional locale filter
  </done>
