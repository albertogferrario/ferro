Add 6 new Props structs following the existing pattern (Debug, Clone, PartialEq, Serialize, Deserialize, with serde skip_serializing_if on optionals):

1. **StatCardProps** — `label: String`, `value: String`, `icon: Option<String>`, `subtitle: Option<String>`, `sse_target: Option<String>` (maps to data-sse-target for live updates)

2. **ChecklistProps** — `title: String`, `items: Vec<ChecklistItem>`, `dismissible: bool` (default true via serde default), `dismiss_label: Option<String>` (default "Dismiss"), `data_key: Option<String>` (server-side state persistence key). Add `ChecklistItem` struct: `label: String`, `checked: bool` (default false), `href: Option<String>`.

3. **ToastProps** — `message: String`, `variant: ToastVariant` (enum: Info/Success/Warning/Error, default Info, rename_all snake_case), `timeout: Option<u32>` (seconds, default 5), `dismissible: bool` (default true via serde default). Toast is a declarative intent in the component tree — the JS runtime reads data attributes to display it.

4. **NotificationDropdownProps** — `notifications: Vec<NotificationItem>`, `empty_text: Option<String>` (default "No notifications"). Add `NotificationItem` struct: `icon: Option<String>`, `text: String`, `timestamp: Option<String>`, `read: bool` (default false), `action_url: Option<String>`.

5. **SidebarProps** — `fixed_top: Vec<SidebarNavItem>`, `groups: Vec<SidebarGroup>`, `fixed_bottom: Vec<SidebarNavItem>`. Add `SidebarNavItem`: `label: String`, `href: String`, `icon: Option<String>`, `active: bool` (default false). Add `SidebarGroup`: `label: String`, `collapsed: bool` (default false), `items: Vec<SidebarNavItem>`.

6. **HeaderProps** — `business_name: String`, `notification_count: Option<u32>` (unread badge), `user_name: Option<String>`, `user_avatar: Option<String>`, `logout_url: Option<String>`.

Add all 6 variants to the `Component` enum: `StatCard(StatCardProps)`, `Checklist(ChecklistProps)`, `Toast(ToastProps)`, `NotificationDropdown(NotificationDropdownProps)`, `Sidebar(SidebarProps)`, `Header(HeaderProps)`.

Update the custom `Serialize` impl for Component: add 6 new match arms using `serialize_tagged(serializer, "StatCard", p)` etc.

Update the custom `Deserialize` impl for Component: add 6 new match arms in the type_str match using `serde_json::from_value(obj.clone()).map(Component::StatCard)` etc.

<task type="auto">
  <name>Task 2: Implement render functions for all 6 new components</name>
  <files>ferro-json-ui/src/render.rs</files>
  <action>
Add render functions for each new component in render.rs, following the existing Tailwind CSS pattern. Wire them into the `render_component` match statement.

1. **render_stat_card(props)** — Renders a card-like div with: icon (if present) as text/emoji, label as small text, value as large bold text, subtitle as small muted text. If `sse_target` is set, add `data-sse-target="{sse_target}"` attribute on the value element and `data-live-value` attribute. Use classes: `bg-white rounded-lg shadow-sm p-4 border border-gray-100`.

2. **render_checklist(props)** — Renders a card with title header, optional dismiss button (X or dismiss_label). Each ChecklistItem: checkbox input (checked attr if checked), label (strikethrough class `line-through text-gray-400` if checked), optional href wrapping label in `<a>`. Add `data-checklist-key="{data_key}"` if data_key present. Add `data-dismissible` if dismissible.

3. **render_toast(props)** — Renders a toast container div with: `data-toast-variant="{variant}"`, `data-toast-timeout="{timeout}"`, `data-toast-dismissible` if dismissible. CSS: fixed position classes (`fixed top-4 right-4 z-50`), variant-specific background colors (info: blue, success: green, warning: yellow, error: red). Message text, optional dismiss X button.

4. **render_notification_dropdown(props)** — Renders a dropdown container with: bell icon button, dropdown panel (hidden by default, `data-notification-dropdown`). Each NotificationItem: icon, text, timestamp in muted small text, unread indicator if !read. If no notifications, show empty_text. Add `data-notification-count="{count}"` for unread count.

5. **render_sidebar(props)** — Renders an `<aside>` with: fixed_top items as nav links, groups as collapsible sections (each with heading and child items), fixed_bottom items. Use `data-sidebar-group` on groups, `data-collapsed` if collapsed. Active items get `bg-gray-100 text-blue-600 font-medium`, inactive get `text-gray-600 hover:text-gray-900`. Icons rendered as span with class. All user strings through `html_escape`.

6. **render_header(props)** — Renders a `<header>` with: business_name as text, notification bell icon with `data-notification-count="{n}"` badge if notification_count > 0, user section (avatar image or name initials, logout link). Use flex layout with justify-between. All user strings through `html_escape`.

Wire all 6 into the `render_component` match: `Component::StatCard(p) => render_stat_card(p)`, etc. Import new types at top of render.rs.
