<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| spec author → render output | Server-authored spec JSON (labels, icons, urls, visible_if) is rendered to HTML. Untrusted only insofar as a buggy/typo'd spec must fail safe. |
| row data → visible_if gate | Per-row truthiness decides whether a (potentially destructive) action appears on a row. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-237-01 | I (Info Disclosure / privilege) | render_action_group visible_if gate | mitigate | Fail-closed: an `ActionItem` with `visible_if` set and an absent/falsy field is HIDDEN (reuse data.rs:445 `action_visible_for_row` semantics). Pinned by `action_group_visible_if` test — a regression leaking a destructive action onto every row fails the test. |
| T-237-02 | T (Tampering / injection) | label/url/menu_id/icon interpolation | mitigate | All dynamic text routed through the existing `html_escape` path (same as render_menu_item/render_button_group). No raw `format!` interpolation of caller text into HTML. Acceptance criteria grep + decode-diagnostic comment pattern. |
| T-237-03 | T (method spoof bypass) | non-GET inline form-wrap | mitigate | Non-GET actions emit `<form method="post">` + `<input _method>` (copied from render_menu_item), NOT a bare POST button. CSRF rides the framework meta-tag + Inertia JS path (framework/src/csrf/mod.rs) — no new bypass, parity preserved. Pinned by `action_group_non_get_wraps_form`. |
