<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| inserted principal → handler | Principal is trusted only because BearerAuthMiddleware validated it upstream; sub is parsed defensively |
| Gate decision → tool result | A deny must surface as content, never as data |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-200-03 | Elevation of Privilege | tools/call gate | mitigate | `Gate::authorize_for(&user, ability, None)` runs before dispatch; agent's reach == user's reach. Uses the same registry as the web surface (no second permission system). |
| T-200-03b | Elevation of Privilege | mcp_ability=None | mitigate | None ability → deny tool error before dispatch (fail-closed). Covered by `policy_deny_no_ability` test. |
| T-200-04 | Information Disclosure | deny tool-error body | mitigate | Generic denial message only; test asserts absence of table name `orders`, column names, filter values, and row counts. JSON-RPC success envelope (not 401/403) per D-09. |
| T-200-SUB | Spoofing | sub parse | mitigate | sub parsed from the validated principal only; non-numeric/absent → 400, never a default user. |
</threat_model>
