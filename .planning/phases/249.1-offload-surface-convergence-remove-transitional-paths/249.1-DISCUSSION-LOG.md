## Single registration path

| Option | Description | Selected |
|--------|-------------|----------|
| Framework default broadcaster | Framework provides a default in-process Broadcaster when bootstrap registered none; delete the persist-only fn and None arm; one registration call. No consumer burden. | ✓ |
| Option<Broadcaster> single fn | Collapse two fns into one taking Option; persist-vs-broadcast branch moves inside the hook. Runtime branch survives. | |
| Require consumer broadcaster | Delete persist-only; worker-only must register a Broadcaster itself. Cleanest deletion, breaks existing worker-only boots. | |

**User's choice:** Framework default broadcaster
**Notes:** Resolves the self-contradicting in-tree comments (fallback "preserved for worker-only" vs "removed by 249.1"). The worker-only need is real, so removal is achieved by guaranteeing a broadcaster, not by dropping the capability. The broadcaster-aware hook already tolerates zero subscribers (best-effort, swallowed).
