<objective>
Teach the `#[service]` macro to recognize `#[offload]` on trait methods and derive, for each such
method, a public `<Trait><Method>Job` struct (its own serializable payload), an `impl Job` that runs
the original method body on a worker, and an `inventory::submit!` self-registration — delivering
OFFLOAD-01's "declare once, no hand-written Job, no manual enqueue" property.

`#[offload]` is an inert helper attribute consumed by `#[service]` (RQ-1), NOT a standalone
`#[proc_macro_attribute]`: a trait method is not a standalone item, so only the outer `#[service]`
macro — which already parses the whole `ItemTrait` — can strip the attribute and emit sibling items
in the correct module scope. The stripping mirrors `#[injectable]`'s `#[inject]` removal.

Purpose: complete the macro half of Phase 244 against the `ferro-queue` substrate Plan 01 shipped.
Output: a new `ferro-macros/src/offload.rs` helper module, the `service_impl` extension, the
`mod offload;` declaration, and a trybuild harness with pass/fail fixtures covering OFFLOAD-01-a/b/c.
</objective>
