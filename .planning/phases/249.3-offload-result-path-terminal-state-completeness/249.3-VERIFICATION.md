# Phase 249.3: Offload Result-Path Terminal-State Completeness — Verification Report

**Phase Goal:** Guarantee an `OffloadHandle` always resolves to a terminal state (completed or
failed), never an indefinite `Ok(None)`. Close two silent-drop edges — (a) sync mode
(`QUEUE_CONNECTION=sync`) `dispatch_immediately()` ignored the handle key and wrote no
snapshot; (b) reaper-parked (timeout-killed) jobs never recorded a failed envelope. Hardens
OFFLOAD-03 at its edges.
