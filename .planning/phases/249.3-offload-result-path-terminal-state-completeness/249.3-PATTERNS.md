```rust
async fn dispatch_immediately(self) -> Result<(), Error> {
    let job_name = self.job.name();

    if self.delay.is_some() {
        tracing::debug!(job = %job_name, "Job delay ignored in sync mode");
    }
    if self.tenant_id.is_some() {
        tracing::debug!(
            job = %job_name,
            tenant_id = ?self.tenant_id,
            "for_tenant() ignored in sync mode — current task tenant context applies"
        );
    }
    tracing::debug!(job = %job_name, "Executing job synchronously");

    // Fetch once — None means the queue is used without the framework boot path
    // (e.g. ferro-queue unit tests that call dispatch_immediately without Queue::init).
    // In those cases persist_offload_outcome's own guard (handle_key=None or hook
    // unregistered) would no-op anyway, but we guard here to avoid a panic on
    // Queue::connection() (Pitfall 1 from RESEARCH.md).
    let conn = if crate::db::Queue::is_initialized() {
        Some(crate::db::Queue::connection())
    } else {
        None
    };

    match self.job.handle_with_value().await {
        Ok(success_value) => {
            tracing::debug!(job = %job_name, "Job completed successfully");
            if let Some(conn) = conn {
                match success_value {
                    Some(val) => {
                        persist_offload_outcome(self.handle_key.as_deref(), Ok(val), conn).await;
                    }
                    None if self.handle_key.is_some() => {
                        // Unit-return job with a handle key: persist Ok(Null) so the
                        // handle always resolves terminally (RESEARCH.md Pitfall 4).
                        persist_offload_outcome(
                            self.handle_key.as_deref(),
                            Ok(serde_json::Value::Null),
                            conn,
                        )
                        .await;
                    }
                    None => {}
                }
            }
            Ok(())
        }
        Err(e) => {
            tracing::error!(job = %job_name, error = %e, "Job failed");
            if let Some(conn) = conn {
                persist_offload_outcome(
                    self.handle_key.as_deref(),
                    Err(e.to_string()),
                    conn,
                )
                .await;
            }
            self.job.failed(&e).await;
            Err(e) // D-03: dual signal — still return Err
        }
    }
}
```

**Key points:**
- `handle_with_value()` is defined on the `Job` trait (`job.rs:78`); the import
  already exists through `self.job`.
- `persist_offload_outcome` is already in scope in this file (defined at line 51).
- No new imports needed.

### `ferro-queue/src/db.rs` — `reaper()` (lines 486–542)

**Change:** Add a SELECT-before-park step inside the existing transaction; change
the return type from `Result<(), Error>` to `Result<Vec<(i64, String)>, Error>`.

**Self-analog — current two-statement txn body** (`db.rs:496–541`):
```rust
pub async fn reaper(
    conn: &DatabaseConnection,
    queue: &str,
    visibility_timeout: std::time::Duration,
) -> Result<(), Error> {
    let now = Utc::now();
    let duration = chrono::Duration::from_std(visibility_timeout)
        .map_err(|e| Error::custom(format!("visibility_timeout out of range: {e}")))?;
    let cutoff = (now - duration).to_rfc3339();
    let now_iso = now.to_rfc3339();

    let backend = conn.get_database_backend();
    let txn = conn.begin().await.map_err(Error::Db)?;

    // Step 1: requeue (attempts + 1 < max_retries)
    let (p1, p2, p3) = (ts_ph(backend, 1), ts_ph(backend, 2), ph(backend, 3));
    let requeue_sql = format!(
        "UPDATE jobs SET status='pending', claimed_at=NULL, claimed_by=NULL, \
         attempts = attempts + 1, available_at = {p1} \
         WHERE status='claimed' AND claimed_at < {p2} \
         AND attempts + 1 < max_retries AND queue = {p3}"
    );
    let requeue = Statement::from_sql_and_values(
        backend,
        &requeue_sql,
        [
            Value::String(Some(Box::new(now_iso.clone()))),
            Value::String(Some(Box::new(cutoff.clone()))),
            Value::String(Some(Box::new(queue.to_string()))),
        ],
    );
    txn.execute(requeue).await.map_err(Error::Db)?;

    // Step 2: park exhausted rows
    let (pp1, pp2, pp3) = (ts_ph(backend, 1), ts_ph(backend, 2), ph(backend, 3));
    let park_sql = format!(
        "UPDATE jobs SET status='failed', error='visibility timeout exceeded', failed_at={pp1} \
         WHERE status='claimed' AND claimed_at < {pp2} \
         AND attempts + 1 >= max_retries AND queue = {pp3}"
    );
    let park = Statement::from_sql_and_values(
        backend,
        &park_sql,
        [
            Value::String(Some(Box::new(now_iso))),
            Value::String(Some(Box::new(cutoff))),
            Value::String(Some(Box::new(queue.to_string()))),
        ],
    );
    txn.execute(park).await.map_err(Error::Db)?;

    txn.commit().await.map_err(Error::Db)
}
```

**`ph()` / `ts_ph()` helper pattern** (already in db.rs, used throughout the file):
```rust
// ph(backend, n)    — bare positional placeholder ($n or ?n)
// ts_ph(backend, n) — timestamptz-cast placeholder on Postgres, bare on SQLite
//
// Each Statement::from_sql_and_values call uses independent placeholder numbering
// starting from 1 (note pp1/pp2/pp3 in Step 2 restart from 1).
```

**SELECT-before-park query pattern** — copy from RESEARCH.md RF-4, using the same
`ph()` / `ts_ph()` helpers and `Statement::from_sql_and_values` pattern already in the
file; run BETWEEN Step 1 (requeue UPDATE) and Step 2 (park UPDATE) inside the same
transaction:
```rust
// Between Step 1 and Step 2 — collect park candidates that carry a handle_key.
// Independent placeholder numbering, same as pp1/pp2/pp3 pattern below.
let (sp1, sp2, sp3) = (ts_ph(backend, 1), ph(backend, 2), ph(backend, 3));
let candidates_sql = format!(
    "SELECT id, handle_key FROM jobs \
     WHERE status='claimed' AND claimed_at < {sp1} \
     AND attempts + 1 >= max_retries AND queue = {sp2} \
     AND handle_key IS NOT NULL"
);
let candidates_stmt = Statement::from_sql_and_values(
    backend,
    &candidates_sql,
    [
        Value::String(Some(Box::new(cutoff.clone()))),
        Value::String(Some(Box::new(queue.to_string()))),
    ],
);
let candidate_rows = txn.query_all(candidates_stmt).await.map_err(Error::Db)?;
let mut parked_handles: Vec<(i64, String)> = Vec::with_capacity(candidate_rows.len());
for row in candidate_rows {
    if let (Ok(id), Ok(Some(key))) = (
        row.try_get_by::<i64, _>("id"),
        row.try_get_by::<Option<String>, _>("handle_key"),
    ) {
        parked_handles.push((id, key));
    }
}
```

**`query_all` pattern** — already used in `claim_postgres` (`db.rs`) via
`conn.query_all(...)`. The `txn` object also implements `ConnectionTrait`, so
`txn.query_all(...)` is the correct form inside a transaction.

**New signature** (change return type and return the collected vec):
```rust
pub async fn reaper(
    conn: &DatabaseConnection,
    queue: &str,
    visibility_timeout: std::time::Duration,
) -> Result<Vec<(i64, String)>, Error>
```

The function ends with:
```rust
txn.commit().await.map_err(Error::Db)?;
Ok(parked_handles)
```

**Note:** The `sp3` placeholder slot is intentionally unused in the candidates query
above (only `sp1` = cutoff, `sp2` = queue are needed). Use `(sp1, sp2)` with 2-element
array — do not carry a dead `sp3`. Renaming mirrors the existing `(p1, p2, p3)` and
`(pp1, pp2, pp3)` style; use `(sc1, sc2)` to stay consistent.

## Shared Patterns

### `persist_offload_outcome` — best-effort hook entry

**Source:** `ferro-queue/src/dispatcher.rs:51–59`

**Apply to:** `dispatch_immediately()` (sync edge) and the reaper call-sites in
`worker.rs` (reaper edge). Both new call-sites mirror the existing async worker call.

```rust
pub(crate) async fn persist_offload_outcome(
    handle_key: Option<&str>,
    outcome: Result<serde_json::Value, String>,
    db: &'static sea_orm::DatabaseConnection,
) {
    if let (Some(key), Some(hook)) = (handle_key, OFFLOAD_RESULT_HOOK.get()) {
        hook(key.to_string(), outcome, db).await;
    }
}
```

The no-op guard (`handle_key=None` or hook unregistered) means all new call-sites
are safe to invoke unconditionally — non-offload jobs and test environments without
a registered hook are automatically skipped.

### `ph()` / `ts_ph()` placeholder helpers

**Source:** `ferro-queue/src/db.rs` (used throughout)

**Apply to:** The SELECT-before-park query in `db::reaper()`.

Rule: each `Statement::from_sql_and_values` call uses independent placeholder numbering
starting from 1. The SELECT step gets its own independent `(sc1, sc2)` pair, NOT
continuing `p1..p3` from Step 1.

### `#[serial]` for env-mutation tests

**Source:** `ferro-queue/src/dispatcher.rs:347`, `framework/tests/offload_delta_broadcast.rs:367`

**Apply to:** `framework/tests/sync_mode_terminal_state.rs` (mutates
`QUEUE_CONNECTION`). The reaper test also uses `#[serial]` per the broadcast file's
pattern.

### Temp-file SQLite setup

**Source:** `framework/tests/offload_result_round_trip.rs:59–69`

**Apply to:** Both new integration test files. Use `tempfile::NamedTempFile` (not
`sqlite::memory:`) because the WorkerLoop opens multiple pool connections — in-memory
databases are per-connection and invisible across them.

### `OnceLock` single-test-function pattern

**Source:** `framework/tests/offload_result_round_trip.rs:234–235`

**Apply to:** Both new test files. `Queue::init` uses `OnceLock`; running multiple
test functions in the same process races on initialization. Run all scenarios as named
sub-functions called from a single `#[tokio::test]`.
