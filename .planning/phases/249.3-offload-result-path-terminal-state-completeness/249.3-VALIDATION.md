## Observable Signals (Nyquist)

- **SC#1 signal:** after a sync-mode dispatch with a handle key, the `projection_snapshots`
  row at `(offload.result, handle_key)` exists and decodes to a `completed`/`failed` envelope
  (not absent). Sampled by `read_result::<T>(&key, db)` returning `Some(..)`.
- **SC#2 signal (persisted):** after the reaper parks a timed-out claimed row that carries a
  `handle_key`, the same snapshot row exists with a `failed` envelope whose error contains
  `"visibility timeout exceeded"`.
- **SC#2 signal (observed):** a broadcast receiver subscribed to
  `projection.offload.result.{handle}` before the reaper runs receives an `offload.result`
  event within a bounded await — proving the subscriber wakes rather than timing out.
- **SC#3 signal:** the pre-existing async offload + broadcast suites remain green, proving the
  non-degraded paths are untouched.
