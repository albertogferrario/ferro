<objective>
Close silent-drop edge (a): sync mode (`QUEUE_CONNECTION=sync`, the unset default).
Today `PendingDispatch::dispatch_immediately()` (`ferro-queue/src/dispatcher.rs:145`)
calls `self.job.handle()`, discards the return value, ignores `self.handle_key`, and
never persists a terminal envelope — so a caller holding the offload handle reads
`Ok(None)` forever (246 WR-01). This plan reworks `dispatch_immediately()` to call
`handle_with_value()` and route the outcome through the existing
`persist_offload_outcome` hook on both the success and failure branches, then adds the
SC#1 integration test.

Purpose: guarantee an `OffloadHandle` always resolves to a terminal state in sync mode.
Output: reworked `dispatch_immediately()` + `framework/tests/sync_mode_terminal_state.rs`
(SC#1 completed + failed round-trips).

Scope guardrail: this is surgical. No new envelope shape, no new transport, no new crate
dependency, no `ferro-queue → ferro-projection` dependency — persistence reaches through
the already-registered framework hook only.

```rust
async fn dispatch_immediately(self) -> Result<(), Error> {
    let job_name = self.job.name();

    if self.delay.is_some() {
        tracing::debug!(job = %job_name, "Job delay ignored in sync mode");
    }
    if self.tenant_id.is_some() {
        tracing::debug!(
            job = %job_name,
            tenant_id = ?self.tenant_id,
            "for_tenant() ignored in sync mode — current task tenant context applies"
        );
    }
    tracing::debug!(job = %job_name, "Executing job synchronously");

    // Fetch once. None means the queue is used without the framework boot path
    // (e.g. ferro-queue unit tests that dispatch without Queue::init). The guard
    // avoids a panic on Queue::connection() (RESEARCH.md Pitfall 1); persist_offload_outcome
    // would no-op anyway on an unregistered hook / None handle_key.
    let conn = if crate::db::Queue::is_initialized() {
        Some(crate::db::Queue::connection())
    } else {
        None
    };

    match self.job.handle_with_value().await {
        Ok(success_value) => {
            tracing::debug!(job = %job_name, "Job completed successfully");
            if let Some(conn) = conn {
                match success_value {
                    Some(val) => {
                        persist_offload_outcome(self.handle_key.as_deref(), Ok(val), conn).await;
                    }
                    None if self.handle_key.is_some() => {
                        // Unit-return job carrying a handle key: persist Ok(Null) so the
                        // handle always resolves terminally (RESEARCH.md Pitfall 4).
                        persist_offload_outcome(
                            self.handle_key.as_deref(),
                            Ok(serde_json::Value::Null),
                            conn,
                        )
                        .await;
                    }
                    None => {}
                }
            }
            Ok(())
        }
        Err(e) => {
            tracing::error!(job = %job_name, error = %e, "Job failed");
            if let Some(conn) = conn {
                persist_offload_outcome(self.handle_key.as_deref(), Err(e.to_string()), conn).await;
            }
            self.job.failed(&e).await;
            Err(e) // D-03: dual signal — still return Err
        }
    }
}
```
