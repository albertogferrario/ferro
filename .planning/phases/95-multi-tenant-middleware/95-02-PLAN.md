<task type="auto">
  <name>Task 1: TenantResolver trait and four concrete resolver implementations</name>
  <files>framework/src/tenant/resolver.rs, framework/src/tenant/mod.rs</files>
  <action>
Create pluggable resolver strategies:

**resolver.rs:**
- `TenantResolver` trait (#[async_trait], Send + Sync):
  - `async fn resolve(&self, req: &Request) -> Option<TenantContext>` — takes &Request (non-consuming) per user decision

- `SubdomainResolver` struct with new(base_domain_parts, tenant_lookup: Arc<dyn TenantLookup>):
  - resolve(): extract Host header via req.header("host"), strip port (split(':').next()), split by '.', if parts.len() <= base_domain_parts return None, slug = parts[0], call tenant_lookup.find_by_slug(slug)

- `HeaderResolver` struct with new(header_name, tenant_lookup):
  - resolve(): req.header(&self.header_name)?, pass value to tenant_lookup.find_by_slug()

- `PathResolver` struct with new(param_name, tenant_lookup):
  - resolve(): req.param(&self.param_name).ok()? — Note: req.param() returns Result, not Option, so use .ok()
  - Pass value to tenant_lookup.find_by_slug()

- `JwtClaimResolver` struct with new(claim_field, tenant_lookup):
  - resolve(): req.get::<serde_json::Value>()? to read pre-parsed claims from request extensions
  - claims[&self.claim_field].as_i64()? to extract tenant ID
  - Call tenant_lookup.find_by_id(id) — not find_by_slug since JWT stores numeric ID

- Tests (using TCP loopback for test requests + MockLookup):
  - SubdomainResolver: extracts slug from host, returns None for no subdomain, strips port, calls find_by_slug with extracted slug
  - HeaderResolver: extracts from header, returns None when header absent
  - PathResolver: extracts from route param, returns None when param absent
  - JwtClaimResolver: extracts from extensions, returns None without claims
  - Object-safety test: Box<dyn TenantResolver> compiles

**mod.rs updates:**
- Add `pub mod resolver;` to module declarations
- Add re-exports: `pub use resolver::{HeaderResolver, JwtClaimResolver, PathResolver, SubdomainResolver, TenantResolver};`

<task type="auto">
  <name>Task 2: TenantMiddleware with resolver chain and failure modes</name>
  <files>framework/src/tenant/middleware.rs, framework/src/tenant/mod.rs</files>
  <action>
Create the middleware that ties resolvers to task-local context:

**middleware.rs:**
- `TenantMiddleware` struct: resolvers: Vec<Box<dyn TenantResolver>>, on_failure: TenantFailureMode
- Builder API (consuming mut self -> Self):
  - `new()` — empty resolvers, NotFound default
  - `resolver(mut self, impl TenantResolver + 'static) -> Self` — pushes to vec
  - `on_failure(mut self, mode: TenantFailureMode) -> Self` — sets mode
- `impl Default` delegates to new()
- `impl Middleware` (#[async_trait]):
  - Loop resolvers, first Some(ctx) wins, break on match
  - If Some: create tenant_scope(), write ctx, call with_tenant_scope(scope, next(request))
  - If None: match on_failure:
    - NotFound: Err(HttpResponse::json({"error": "Tenant not found"}).status(404))
    - Forbidden: Err(HttpResponse::json({"error": "Access denied"}).status(403))
    - Allow: create empty tenant_scope(), call with_tenant_scope (current_tenant() returns None downstream)
    - Custom(handler): call handler()

- Tests (using TCP loopback + AlwaysResolver/NeverResolver mocks):
  - new() creates empty instance with NotFound default
  - .resolver() adds to chain (len check)
  - .on_failure() sets mode
  - Resolves tenant and stores in task-local (verify via tenant_capture_next)
  - Tries resolvers in order, first Some wins (NeverResolver then two AlwaysResolvers)
  - No match + NotFound returns 404 JSON with "Tenant not found"
  - No match + Forbidden returns 403 JSON with "Access denied"
  - No match + Allow continues with current_tenant()=None
  - current_tenant() available in downstream handler

**mod.rs updates:**
- Add `pub mod middleware;` to module declarations
- Add re-export: `pub use middleware::TenantMiddleware;`
