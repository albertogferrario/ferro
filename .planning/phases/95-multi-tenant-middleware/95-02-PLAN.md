<objective>
Implement the TenantMiddleware (Middleware trait impl) with configurable failure modes, and all four concrete resolver strategies (Subdomain, Header, Path, JWT).

Purpose: The middleware is the request-level entry point — it resolves the tenant, stores it in task-local context, and either continues the chain or returns an error. The resolvers provide the pluggable strategies that applications choose between.

Output: Working middleware and 4 resolver implementations with comprehensive tests.
</objective>

    - Define `TenantMiddleware` struct with fields: `resolvers: Vec<Box<dyn TenantResolver>>`, `on_failure: TenantFailureMode`.
    - Builder methods (consuming `mut self -> Self` per workspace convention):
      - `pub fn new() -> Self` — empty resolvers, `TenantFailureMode::NotFound` default.
      - `pub fn resolver(mut self, resolver: impl TenantResolver + 'static) -> Self` — pushes to vec.
      - `pub fn on_failure(mut self, mode: TenantFailureMode) -> Self` — sets failure mode.

      - Iterate `self.resolvers`, call `resolver.resolve(&request).await` for each.

        - `Allow` → continue with `None` tenant context
      - Wrap `next(request).await` in `with_tenant_scope(ctx, async { ... }).await`
