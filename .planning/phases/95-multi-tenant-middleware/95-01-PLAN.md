<task type="auto">

  <action>
Create the tenant lookup abstraction:

**lookup.rs:**
- `TenantLookup` trait (#[async_trait], Send + Sync):
  - `async fn find_by_slug(&self, slug: &str) -> Option<TenantContext>`
  - `async fn find_by_id(&self, id: i64) -> Option<TenantContext>`
  - `fn invalidate(&self, _slug: &str, _id: i64) {}` default no-op
- `DbTenantLookup` struct:
  - Uses boxed async finder closures (SlugFinder, IdFinder type aliases) to decouple from user DB schema
  - `cache: moka::sync::Cache<String, TenantContext>` with 5-min TTL and 10,000 max capacity
  - `new(slug_finder, id_finder)` constructor — takes closures, not DB connection
  - find_by_slug: check cache by slug string, miss -> call finder -> cache result
  - find_by_id: check cache by id.to_string(), miss -> call finder -> cache result
  - invalidate: evicts both slug and id cache entries
- Tests: object-safety (Arc<dyn TenantLookup>), mock lookup returns Some/None, DbTenantLookup empty cache, caching verified via call count (AtomicU32), invalidate evicts and forces refetch, default invalidate is no-op
