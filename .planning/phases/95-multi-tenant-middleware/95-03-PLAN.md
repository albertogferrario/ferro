    - Implement `Scope<E>` for `TenantScope<C>` where `E: EntityTrait, E::Model: Send + Sync, C: ColumnTrait`:
      ```rust
      fn apply(self, query: QueryBuilder<E>) -> QueryBuilder<E> {
          let ctx = current_tenant()
              .expect("TenantScope used outside TenantMiddleware scope — ensure this route is behind TenantMiddleware");
          query.filter(self.0.eq(ctx.id))
      }
      ```
    - This is deliberately a panic (not a Result) because using TenantScope outside middleware is a programming error, not a runtime condition. The CONTEXT.md explicitly states: "Panics with clear message if used outside TenantMiddleware scope (programming error)."

    Add `FromRequest` implementation for `TenantContext` in `framework/src/tenant/mod.rs`:
    ```rust
    #[async_trait]
    impl FromRequest for TenantContext {
        async fn from_request(_req: Request) -> Result<Self, FrameworkError> {
            current_tenant().ok_or_else(|| {
                FrameworkError::domain("No tenant context available. Ensure this route is behind TenantMiddleware.", 400)
            })
        }
    }
    ```
    Note: FromRequest takes `req: Request` (consuming), but we only read from task-local context, so we ignore the request.

    Update `framework/src/tenant/mod.rs`: add `pub mod scope;` and re-export `pub use scope::TenantScope;`.
