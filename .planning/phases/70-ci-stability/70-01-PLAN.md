# Phase 70-01: Fix CI Stability Issues

<objective>
Fix flaky test in ferro-notifications dispatcher and ensure all CI checks pass reliably. The `test_mail_config_smtp_from_env` test fails intermittently due to env var race conditions between parallel tests.
</objective>

<context>
## Background

Phase 67 previously fixed similar flaky env var tests in ferro-lang and validation. The same pattern exists in `ferro-notifications/src/dispatcher.rs` — tests use `unsafe { env::set_var }` and `unsafe { env::remove_var }` across parallel test threads, causing race conditions.

The test `test_mail_config_smtp_from_env` calls `clean_mail_env()` then `with_env_vars()`, but another test (e.g., `test_mail_config_resend_from_env`) running in parallel can call `clean_mail_env()` between those calls, removing the env vars the first test just set.

## How Phase 67 Fixed It

Phase 67 fixed similar tests in ferro-lang by adding `serial_test` as a dev-dependency and annotating env-dependent tests with `#[serial]` to prevent parallel execution.

## What Needs to Happen

Apply the same fix pattern from Phase 67 to ferro-notifications:
1. Add `serial_test` as a dev-dependency to `ferro-notifications/Cargo.toml`
2. Add `#[serial]` attribute to all env-dependent tests in `dispatcher.rs`
</context>

<tasks>

<task id="1">
<title>Add serial_test dependency and fix flaky tests</title>
<files>
- ferro-notifications/Cargo.toml
- ferro-notifications/src/dispatcher.rs
</files>
<steps>
1. Add `serial_test = "3"` to `[dev-dependencies]` in `ferro-notifications/Cargo.toml`
2. In `dispatcher.rs` test module, add `use serial_test::serial;`
3. Add `#[serial]` attribute to ALL tests that use `clean_mail_env()` or `with_env_vars()`:
   - `test_mail_config_smtp_from_env`
   - `test_mail_config_resend_from_env`
   - `test_mail_config_resend_missing_api_key`
   - `test_mail_config_default_driver`
   - `test_mail_config_no_tls`
   - Any other tests that read/write env vars
4. Run `cargo test -p ferro-notifications --lib` multiple times to verify no flakiness
5. Run `cargo fmt --all -- --check`
6. Run `cargo clippy --all --all-targets -- -D warnings`
</steps>
</task>
