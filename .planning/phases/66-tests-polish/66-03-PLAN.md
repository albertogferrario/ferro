The `is_valid_locale` function is private. Add a `#[cfg(test)] mod tests` section at the end of make_lang.rs with tests:

**Valid locales:**
- `test_valid_locale_simple`: "en" → true, "fr" → true
- `test_valid_locale_with_region`: "pt-br" → true, "zh-hans" → true
- `test_valid_locale_multi_part`: "zh-hans-cn" → true

**Invalid locales:**
- `test_invalid_locale_empty`: "" → false

- `test_invalid_locale_numbers`: "12" → false, "en1" → false

- `test_invalid_locale_three_chars_base`: "eng" → false (first part must be exactly 2)
- `test_invalid_locale_single_char_subtag`: "en-a" → false (subtags must be 2+ chars)
- `test_invalid_locale_special_chars`: "en_us" → false (underscores not valid, only hyphens)

Follow the existing test pattern in the codebase. Do NOT test the `run()` function directly (it calls process::exit and writes to stdout).
