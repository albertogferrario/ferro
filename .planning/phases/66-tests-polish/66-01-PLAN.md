**load_locale_dir tests (use tempdir):**
- `load_locale_dir_single_file`: One JSON file → correct flat map

**load_translations tests (use tempdir):**
- `load_translations_single_locale`: en/ dir only
- `load_translations_fallback_premerge`: en/ has key "a", es/ missing key "a" → es/ gets "a" from fallback
- `load_translations_empty_dir_errors`: Empty dir → NoTranslationsLoaded error
- `load_translations_normalizes_locale_dirs`: "en_US" dir → "en-us" key

**init.rs:** The existing tests verify t()/trans()/choice() return key when no translator is loaded. Add:

- `test_t_with_params_returns_key_when_no_translator`: Verify `t("app.hello", &[("name", "World")])` returns `"app.hello"` when no translator loaded (params ignored gracefully)
- `test_choice_with_count_returns_key_when_no_translator`: Verify `choice("messages.items", 5, &[])` returns `"messages.items"` when no translator loaded

Note: Testing lang_init() end-to-end requires filesystem setup (lang/ dir with JSON files) AND env vars set — this is already covered by the translator tests in ferro-lang. The init.rs tests focus on the graceful-degradation path (no translator available).
