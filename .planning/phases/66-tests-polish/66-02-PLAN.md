  <action>
Add the following tests to the existing `#[cfg(test)] mod tests` block:

**RequiredIf:**
- `test_required_if`: When other field matches value → required validation applies. When other field doesn't match → passes regardless.
```rust
let data = json!({"role": "admin"});
// role == admin, so name is required
assert!(required_if("role", "admin").validate("name", &json!(null), &data).is_err());
assert!(required_if("role", "admin").validate("name", &json!("Alice"), &data).is_ok());
// role != "user", so name is not required
assert!(required_if("role", "user").validate("name", &json!(null), &data).is_ok());
```

**Different:**
- `test_different`: Field must differ from another field. json!("a") vs other="b" → Ok. json!("a") vs other="a" → Err.

**Same:**

**Regex_:**

**Alpha:**
