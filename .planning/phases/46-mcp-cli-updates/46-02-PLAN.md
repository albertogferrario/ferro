<task type="auto">
  <name>Task 1: Create list_rate_limiters and list_broadcast_channels MCP tools</name>
  <files>ferro-mcp/src/tools/list_rate_limiters.rs, ferro-mcp/src/tools/list_broadcast_channels.rs</files>
  <action>
Create two new MCP tool modules following the established scan-and-parse pattern.

**list_rate_limiters.rs:**
- Scan `src/bootstrap.rs` (primary location) and all `.rs` files under `src/` for `RateLimiter::define(` calls
- For each rate limiter found, extract: name (first string argument to define()), the Limit configuration if parseable (max requests, duration), source file path, line number
- Also scan routes for `Throttle::named("...")` usage to show which route groups use which limiters
- Return `RateLimitersInfo { limiters: Vec<RateLimiterInfo>, route_usage: Vec<ThrottleUsage> }` where:
  - `RateLimiterInfo` has: name, max_requests (Option<u64>), window_seconds (Option<u64>), source_file, line
  - `ThrottleUsage` has: limiter_name, route_group (the route path prefix or group name), source_file, line
- Search patterns:
  - `RateLimiter::define("name"` for definitions
  - `Throttle::named("name")` for usage in routes
  - `Throttle::per_minute(N)` / `Throttle::per_hour(N)` for inline throttles

**list_broadcast_channels.rs:**
- Scan source files for broadcast channel patterns:
  - `BroadcastConfig` setup in bootstrap.rs
  - `Broadcaster::send(` or `broadcaster.send(` calls for channel names
  - `broadcasting_auth` route registration
- Return `BroadcastInfo { config_found: bool, auth_route: Option<String>, channels: Vec<ChannelInfo> }` where:
  - `ChannelInfo` has: name (channel string if extractable), source_file, line, channel_type (presence/private/public if determinable)
- Search patterns:
  - `BroadcastConfig::new(` or `BroadcastConfig {` for configuration
  - `broadcasting_auth` for auth route
  - `Broadcaster::send(` / `broadcaster.send(` for channel usage

Both tools should handle empty results gracefully. If bootstrap.rs doesn't exist or has no rate limiters, return empty arrays.
  </action>
  <verify>cargo build -p ferro-mcp</verify>
  <done>Both tool modules compile and export execute() functions with correct return types</done>
</task>
