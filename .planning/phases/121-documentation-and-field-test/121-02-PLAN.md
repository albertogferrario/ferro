<!-- v2 patterns — source of truth from 121-RESEARCH.md -->

v2 spec file format:
```json
{
  "$schema": "ferro-json-ui/v2",
  "title": "Dashboard",
  "layout": "dashboard",
  "root": "welcome",
  "elements": {
    "welcome": {
      "type": "Card",
      "props": { "title": "Welcome" },
      "children": ["orders_stat"]
    },
    "orders_stat": {
      "type": "StatCard",
      "props": {
        "label": "Orders Today",
        "value": { "$data": "/orders_today" }
      }
    }
  }
}
```

v2 handler pattern:
```rust
use ferro::{handler, JsonUi, Response};

#[handler]
pub async fn dashboard() -> Response {
    let data = serde_json::json!({ "orders_today": 42 });
    JsonUi::render_file("views/dashboard.json", data)
}
```

v2 action in element:
```json
"save_btn": {
  "type": "Button",
  "props": { "label": "Save" },
  "action": {
    "handler": "items.store",
    "method": "POST",
    "confirm": { "title": "Save this item?" }
  }
}
```

v1 → v2 mapping (ALL of these must be removed from docs):
- JsonUiView → JSON spec file
- ComponentNode → element in "elements" map
- Component::Card(CardProps { ... }) → "type": "Card", "props": { ... }
- JsonUi::render(&view, &data) → JsonUi::render_file("views/name.json", data)
- children: vec![ComponentNode { ... }] → "children": ["element_id"]
- visibility: Some(Visibility { ... }) → "visible": { "field": "...", "op": "...", "value": "..." }
</interfaces>
