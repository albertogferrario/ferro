  <files>ferro-cli/src/templates/files/do/app.yaml.tpl, ferro-cli/src/templates/files/docker/Dockerfile.tpl</files>
  <action>
Two fixes:

1. In `app.yaml.tpl` line 20: change `http_path: /health` to `http_path: /_ferro/health`. The framework's built-in health endpoint is at `/_ferro/health` (see `framework/src/server.rs:139`), not `/health`.

2. In `Dockerfile.tpl` line 19: change `FROM rust:1.75-slim-bookworm` to `FROM rust:1.88-slim-bookworm`. The workspace Cargo.toml declares `rust-version = "1.88.0"` as MSRV. Using 1.75 causes builds to fail on any Rust feature from the last 13 releases.
  </action>
  <verify>
    - `grep '/_ferro/health' ferro-cli/src/templates/files/do/app.yaml.tpl` shows the corrected path
    - `grep 'rust:1.88' ferro-cli/src/templates/files/docker/Dockerfile.tpl` shows the corrected version
  </verify>
  <done>Health check path matches framework endpoint. Rust version matches workspace MSRV.</done>
</task>
