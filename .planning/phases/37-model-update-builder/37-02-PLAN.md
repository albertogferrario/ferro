<task type="auto">
  <name>Task 1: Update scaffold controller templates to use UpdateBuilder</name>
  <files>ferro-cli/src/templates/mod.rs, ferro-cli/src/commands/make_scaffold.rs</files>
  <action>
Update the update handler code in all four scaffold controller templates to use the new builder pattern instead of raw ActiveModel manipulation.

**In `ferro-cli/src/commands/make_scaffold.rs`:**

The `update_fields` string is currently generated as:
```rust
format!("    model.{} = sea_orm::ActiveValue::Set(form.{}.clone());\n", field.name, field.name)
```

Change this to generate builder setter calls:
```rust
format!("        .set_{}(form.{}.clone())\n", field.name, field.name)
```

**In `ferro-cli/src/templates/mod.rs`:**

Update `scaffold_controller_template` update handler from:
```rust
let mut model: {snake_name}::ActiveModel = {snake}.into();
{update_fields}    model.updated_at = ActiveValue::Set(chrono::Utc::now());

model.update(db).await
```

To:
```rust
let updated = {snake}
    .update()
{update_fields}        .save()
    .await
```

The new pattern:
1. No ActiveModel conversion
2. No manual updated_at (builder handles it)
3. No `db` parameter (builder uses framework's connection)
4. Chain set_* calls from form fields
5. `.save().await` at the end

Apply the same change to all four controller templates:
- `scaffold_controller_template` (full-stack, no FK)
- `scaffold_controller_with_fk_template` (full-stack, with FK)
- `api_controller_template` (API-only, no FK)
- `api_controller_with_fk_template` (API-only, with FK)

For each template:
1. Remove `sea_orm::ActiveValue` from imports (if no longer used elsewhere in the template — check store handler still uses it for inserts)
2. Remove the `let mut model: ...ActiveModel = ...into()` line
3. Replace with builder pattern
4. Remove manual `updated_at` setting
5. Update error handling to match new return type

**Important:** The store handler still uses ActiveModel for inserts (via the create builder or raw ActiveModel). Only the update handler changes. Check that `ActiveValue` import is still needed for the store handler — if so, keep it. If the store handler also uses the builder pattern (`Model::create().set_*().insert()`), then the import can be removed.

Looking at the current store handler, it uses raw ActiveModel:
```rust
let model = {snake_name}::ActiveModel {
    id: ActiveValue::NotSet,
    {insert_fields}
    ...
};
```

So `ActiveValue` is still needed for store. Keep the import.

**Also update the template tests** in `mod.rs` — the existing test at `test_api_controller_template_substitution` passes `update_fields` in the old format. Update the test data to match the new builder setter format.

  <files>ferro-mcp/src/tools/code_templates.rs, docs/src/features/database.md</files>
  <action>
**In `ferro-mcp/src/tools/code_templates.rs`:**

1. Update the `update_handler` template (around line 194) from raw ActiveModel pattern to builder pattern:

From:
```rust
let mut model: {{entity}}::ActiveModel = existing.into();
model.name = Set(data.name);
// Update other fields

let result = model.update(db).await?;
```

To:
```rust
let result = existing
    .update()
    .set_name(data.name)
    // Chain other .set_*() calls
    .save()
    .await?;
```

2. Update the model CRUD examples (around line 384-397) to show both the create builder and update builder:

From:
```rust
// Update
let mut model: {{entity}}::ActiveModel = existing.into();
model.name = Set("New Name".to_string());
let result = model.update(db).await?;
```

To:
```rust
// Update
let result = existing
    .update()
    .set_name("New Name")
    .save()
    .await?;

// Clear an optional field
let result = existing
    .update()
    .clear_description()
    .save()
    .await?;
```

3. Remove the "Save (insert or update)" example if it references the old ActiveModel pattern, or update it.

**In `docs/src/features/database.md`:**

1. Update the "Updating Records" section (around line 162-174) to show the new builder pattern:

From:
```rust
use sea_orm::Set;
use ferro::models::user;

let user = user::Entity::find_or_fail(1).await?;
let mut active: user::ActiveModel = user.into();
active.name = Set("Updated Name".to_string());

let updated = user::Entity::update_one(active).await?;
```

To:
```rust
use ferro::models::user::User;

let user = User::find_or_fail(1).await?;
let updated = user
    .update()
    .set_name("Updated Name")
    .save()
    .await?;
```

2. Add a brief note about `clear_*()` methods for nullable fields.

3. Verify no other sections in database.md reference the old ActiveModel update pattern.
