<objective>
Add a typed UpdateBuilder to the FerroModel derive macro that tracks which fields were modified and only sends those to the database.

Purpose: Replace verbose ActiveModel manipulation with an ergonomic builder pattern: `model.update().set_title("new").save().await?`. The builder only sends modified fields (NotSet for unchanged), provides `clear_field()` for nullable fields, and prevents accidentally overwriting unchanged data.

Output: Modified FerroModel derive macro that generates `{Model}UpdateBuilder` with selective field tracking.

  <name>Task 1: Generate UpdateBuilder struct with selective field tracking</name>
  <files>ferro-macros/src/model.rs</files>
  <action>
Modify the `ferro_model_impl` function to generate an `{Model}UpdateBuilder` struct alongside the existing `{Model}Builder` (create builder).

The UpdateBuilder must:

1. **Hold a reference to the original model's id** (needed for the WHERE clause) and track which fields were explicitly set.

2. **Internal representation**: For each non-id, non-timestamp field:
   - Required field (`String`, `i32`, etc.): `Option<T>` — `None` means "not modified", `Some(v)` means "set to v"
   - Optional field (`Option<T>`): `Option<Option<T>>` — `None` means "not modified", `Some(None)` means "clear to NULL", `Some(Some(v))` means "set to v"

3. **Setter methods** for each non-id, non-timestamp field:
   - `set_field(value)` — For String fields, accept `impl Into<String>`. For Option fields, accept the inner type (wraps in Some(Some(value))).
   - `clear_field()` — Only for Option fields. Sets to Some(None) to explicitly NULL the column.
   - All setters return `Self` for chaining.

4. **`save()` method**: Builds an ActiveModel where:
   - `id` is `Unchanged(self.id)` (identifies the row)
   - Modified fields use `Set(value)`
   - Unmodified fields use `NotSet` (not sent to DB)
   - `updated_at` is always `Set(chrono::Utc::now().to_string())` if the model has an `updated_at` field (detect by field name)
   - Calls `Entity::update_one(active).await`

5. **Constructor**: The builder is created via `Model::update(self)` which consumes the model and extracts its `id`.

**Example generated code for `todos` model (title: String, description: Option<String>):**

```rust
pub struct TodoUpdateBuilder {
    id: i32,
    title: Option<String>,
    description: Option<Option<String>>,
}

impl TodoUpdateBuilder {
    pub fn set_title(mut self, value: impl Into<String>) -> Self {
        self.title = Some(value.into());
        self
    }

    pub fn set_description(mut self, value: impl Into<String>) -> Self {
        self.description = Some(Some(value.into()));
        self
    }

    pub fn clear_description(mut self) -> Self {
        self.description = Some(None);
        self
    }

    pub async fn save(self) -> Result<Model, ::ferro::FrameworkError> {
        let active = ActiveModel {
            id: sea_orm::Unchanged(self.id),
            title: self.title.map(sea_orm::Set).unwrap_or(sea_orm::ActiveValue::NotSet),
            description: match self.description {
                Some(v) => sea_orm::Set(v),
                None => sea_orm::ActiveValue::NotSet,
            },
            created_at: sea_orm::ActiveValue::NotSet,
            updated_at: sea_orm::ActiveValue::NotSet,
        };
        <Entity as ::ferro::database::ModelMut>::update_one(active).await
    }
}
```

**Remove the existing model_setters** (`set_*` methods on Model). They are replaced by the update builder. The `update()` method on Model changes from `pub async fn update(self) -> Result<Self, ...>` to `pub fn update(self) -> {Model}UpdateBuilder`.

**Keep the existing `to_active_model()` method** as a private utility (it's used by the old update path, but now we generate the ActiveModel differently in the builder).

Actually, `to_active_model()` is no longer needed after this change since:
- The update builder generates its own ActiveModel in `save()`
- Nothing else calls `to_active_model()`

Remove `to_active_model()` entirely.

**Important implementation detail for `updated_at` handling:**
- Detect if the struct has an `updated_at` field during field iteration
- If present and the field type is `String` (as in the sample app), set it to `chrono::Utc::now().to_string()` in the builder's `save()` method
- If present and the type is `DateTimeUtc`, set it to `chrono::Utc::now()`
- If not present, skip
- Use a boolean flag `has_updated_at` and track its type during field parsing

**Important implementation detail for `id` type:**
- Extract the type of the `id` field during parsing (it could be `i32`, `i64`, `Uuid`, etc.)
- Use this type for the builder's `id` field
