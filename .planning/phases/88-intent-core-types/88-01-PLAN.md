Create `ferro-projections/src/intent.rs` with three types:

**Intent enum — 7 structurally-derivable intents + Custom escape hatch:**
- Variants: Browse, Focus, Collect, Process, Summarize, Analyze, Track, Custom(String)
- Derives: Debug, Clone, Serialize, Deserialize, PartialEq, Eq, Hash, JsonSchema
- `#[serde(rename_all = "snake_case")]` on the enum
- `#[serde(untagged)]` on Custom(String) — matches FieldMeaning pattern exactly
- `#[schemars(description = "...")]` annotation listing known variants (same mitigation as FieldMeaning for anyOf shadowing)
- Custom(String) MUST be the last variant for correct serde deserialization (known variants tried first)
- Doc comments on each variant with the structural signal summary (one line each):
  - Browse: collection navigation, has_many relationships, EntityName fields
  - Focus: single-entity deep view, FreeText/ImageUrl/Url fields
  - Collect: data capture, many writable fields, write_only present
  - Process: workflow with state progression, guarded transitions
  - Summarize: overview dashboard, read-only Money/Percentage/Quantity
  - Analyze: time-series exploration, DateTime + numeric measures
  - Track: timeline/audit trail, Status + temporal ordering
  - Custom: escape hatch for intents not structurally derivable

**IntentScore struct — confidence-scored derivation result:**
- Fields: intent (Intent), confidence (f64, 0.0-1.0), matching_signals (Vec&lt;String&gt;)
- Derives: Debug, Clone, Serialize, Deserialize, PartialEq, JsonSchema
- NOT Eq (f64 doesn't implement Eq) — matches ServiceDef pattern
- Doc comment: "A scored intent with confidence and the structural signals that contributed."

**IntentHint enum — manual override:**
- Variants: Primary(Intent), Exclude(Intent)
- Derives: Debug, Clone, Serialize, Deserialize, PartialEq, Eq, JsonSchema
- `#[serde(rename_all = "snake_case")]` — externally tagged by default
- Serializes as `{"primary": "browse"}` or `{"exclude": "process"}`
- Doc comment: "Manual override for intent derivation when structural analysis is wrong."

Update `ferro-projections/src/lib.rs`:
- Add `mod intent;`
- Add `pub use intent::{Intent, IntentHint, IntentScore};`

**ServiceDef changes (service.rs):**

1. Add import: `use crate::intent::{Intent, IntentHint};`

2. Add field to ServiceDef struct:
   ```
   #[serde(default, skip_serializing_if = "Vec::is_empty")]
   pub intent_hints: Vec<IntentHint>,
   ```
   Place after `relationships` field, before `state_machine`. Initialize to `Vec::new()` in `ServiceDef::new()`.

3. Add builder method:
   ```rust
   /// Adds an intent hint for overriding structural derivation.
   pub fn intent_hint(mut self, hint: IntentHint) -> Self {
       self.intent_hints.push(hint);
       self
   }
   ```

**Warning enum changes (state.rs):**

Add two new variants to the Warning enum:
```rust
/// Primary(X) and Exclude(X) for the same intent.
ConflictingIntentHints { intent: String },
/// More than one Primary hint specified.
MultiplePrimaryIntentHints,
```

Add Display implementations matching existing pattern. The `intent` field is a String (serialized intent name) to avoid coupling Warning to intent types.

**Validation changes (service.rs validate()):**

Add intent hint validation at the end of the existing `validate()` method:

1. Check for conflicting hints: if any intent appears in both a Primary and an Exclude hint, emit `Warning::ConflictingIntentHints { intent: serialized_name }`. Serialize the intent to string for the warning message using serde_json::to_string (strip quotes).

2. Check for multiple primary hints: if more than one `IntentHint::Primary(...)` exists, emit `Warning::MultiplePrimaryIntentHints`.

Follow the existing validation pattern — warnings accumulate in the warnings vec, undefined references are hard errors.
