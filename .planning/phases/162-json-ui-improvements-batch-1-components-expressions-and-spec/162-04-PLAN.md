<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Quill editor HTML → hidden form input → server | Editor produces user-controlled HTML; server must sanitize on submit (NOT the renderer's job) |
| Quill CDN assets (jsdelivr) → browser | Third-party JS execution context; mitigated via SRI integrity hashes |
| init_script IIFE → DOM | Server-emitted JS; not user data |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-162-04-01 | Tampering (XSS on submit) | Quill HTML payload posted by form | transfer | Sanitization is the consumer's responsibility at form-handler time (e.g. via `ammonia` or similar). Rustdoc on `RichTextEditorProps` notes this contract. |
| T-162-04-02 | Tampering (supply chain) | Quill 2.0.3 CDN script | mitigate | `Asset::new(...).integrity("sha256-...")` SRI hash on both CSS and JS asset entries. The executor MUST fetch the actual SRI hash from jsdelivr (see action step "verify SRI"). |
| T-162-04-03 | Tampering (XSS via field/label) | Editor container div attributes from RichTextEditorProps | mitigate | `field` and `label` are HTML-escaped when emitted into the container's `data-ferro-field`, `id`, and `<label>` attributes. |
</threat_model>

use crate::component::RichTextEditorProps;
use crate::plugin::{Asset, JsonUiPlugin};
use schemars::schema_for;
use serde_json::Value;

/// Rich text editor plugin backed by Quill 2.0.3.
///
/// Renders a container div + hidden input; the init script attaches a Quill
/// editor to every `[data-ferro-quill]` element and mirrors the editor HTML
/// to the named hidden input on every text-change.
pub struct RichTextEditorPlugin;

impl JsonUiPlugin for RichTextEditorPlugin {
    fn component_type(&self) -> &'static str {
        "RichTextEditor"
    }

    fn props_schema(&self) -> Value {
        serde_json::to_value(schema_for!(RichTextEditorProps))
            .unwrap_or_else(|_| Value::Null)
    }

    fn render(&self, props: &Value, data: &Value) -> String {
        let parsed: RichTextEditorProps = match serde_json::from_value(props.clone()) {
            Ok(p) => p,
            Err(e) => return format!(
                "<!-- ferro-json-ui: failed to decode RichTextEditor props: {e} -->"
            ),
        };

        // Resolve initial value: data_path > default_value > empty.
        let initial = parsed
            .data_path
            .as_deref()
            .and_then(|p| crate::render::form::resolve_path(data, p))
            .and_then(|v| v.as_str())
            .map(|s| s.to_string())
            .or_else(|| parsed.default_value.clone())
            .unwrap_or_default();

        let field_esc = crate::render::html_escape(&parsed.field);
        let label_esc = crate::render::html_escape(&parsed.label);
        let initial_esc = crate::render::html_escape(&initial);

        let mut html = String::new();
        html.push_str(&format!(
            "<label for=\"{field_esc}-editor\" class=\"text-sm font-medium text-text\">{label_esc}</label>"
        ));
        html.push_str(&format!(
            "<div id=\"{field_esc}-editor\" data-ferro-quill data-ferro-field=\"{field_esc}\">{initial_esc}</div>"
        ));
        html.push_str(&format!(
            "<input type=\"hidden\" name=\"{field_esc}\" id=\"{field_esc}-value\" value=\"{initial_esc}\">"
        ));
        if let Some(ref err) = parsed.error {
            html.push_str(&format!(
                "<p class=\"text-sm text-destructive mt-1\">{}</p>",
                crate::render::html_escape(err)
            ));
        }
        html
    }

    fn css_assets(&self) -> Vec<Asset> {
        vec![
            // TODO(162-04): Verify SRI hash from jsdelivr before shipping.
            // `curl -s https://cdn.jsdelivr.net/npm/quill@2.0.3/dist/quill.snow.css | openssl dgst -sha384 -binary | openssl base64 -A`
            Asset::new("https://cdn.jsdelivr.net/npm/quill@2.0.3/dist/quill.snow.css"),
        ]
    }

    fn js_assets(&self) -> Vec<Asset> {
        vec![
            // TODO(162-04): Verify SRI hash from jsdelivr before shipping.
            Asset::new("https://cdn.jsdelivr.net/npm/quill@2.0.3/dist/quill.js"),
        ]
    }

    fn init_script(&self) -> Option<String> {
        Some(r#"(function(){
            if (typeof Quill === 'undefined') return;
            document.querySelectorAll('[data-ferro-quill]').forEach(function(el){
                var field = el.dataset.ferroField;
                var quill = new Quill(el, { theme: 'snow' });
                var input = document.getElementById(field + '-value');
                if (input && input.value) {
                    quill.root.innerHTML = input.value;
                }
                quill.on('text-change', function(){
                    if (input) input.value = quill.root.innerHTML;
                });
            });
        })();"#.to_string())
    }
}
