Entries to land (one bullet per decision actually shipped):

**Added**
- `CheckboxList` component for multi-select checkbox groups with static or data-driven options (162-01, D-01/D-02).
- `SwitchProps.compact: Option<bool>` for compact inline switch display (162-03, D-16).
- `ImageProps.inline_svg: Option<String>` and `ImageProps::inline_svg(svg, alt)` factory for server-constructed inline SVG (162-03, D-17).
- `RichTextEditor` plugin backed by Quill 2.0.3, registered via the `JsonUiPlugin` surface (162-04, D-18).
- `SpecError::FooterMissing { element_id, footer_id }` variant; spec validator now rejects footer references to unknown element IDs (162-07, D-07).
- `json_ui_verify_action` MCP tool — verifies a handler name is registered as a route, returns Levenshtein candidate on miss (162-09, D-09).
- `strum::AsRefStr` derive on `AlertVariant`, `BadgeVariant`, `ButtonVariant`, `ToastVariant`, `DialogVariant`, `NotifyVariant` — typed enums round-trip to their snake_case wire string via `.as_ref()` (162-08, D-11).
- `docs/src/json-ui/migration-v1-to-v2.md` — focused v1→v2 migration guide with 7 worked-example sections (162-10, D-20).
- `docs/src/json-ui/plugins.md` — JsonUiPlugin authoring guide (162-10, D-19).
- 7 `migration_v1_to_v2` `code_templates` entries surfaced via the ferro-mcp `code_templates` tool (162-10, D-22).

**Changed**
- DataTable `row_actions[i].action.url` now interpolates any column key from the row at render time (`{label}`, `{slug_path}`, `{status}`, …) in addition to the legacy `{row_key}` and `{id}` (162-02, D-03/D-04). Missing-key placeholders pass through unchanged. Wire format unchanged.
- Spec validator emits a stderr warning when an element ID appears in both `props.footer` and `children` of the same parent (162-07, D-08).
- `ferro-json-ui/src/catalog.rs` and `ferro-mcp/src/tools/json_ui_catalog.rs` reflect the new component shape (162-01, 162-04, 162-05, D-21).
- `docs/src/json-ui/components.md` gains a migration banner pointing at the new guide, a worked `Card` + flat `children` example, and an "Inline view/edit" section (162-10, D-13, D-14, D-15).

**Removed**
- Auth layout no longer wraps content in `bg-card rounded-lg shadow-md p-8`. Specs that use `layout: "auth"` are now responsible for declaring their own `Card` root if they want card chrome (162-06, D-05). Breaking for any spec that relied on the implicit wrapper; gestiscilo audit confirmed all auth specs already declare Card roots.

**Notes**
- Phase 162 does not publish to crates.io and does not bump the workspace version (D-23, D-24). The single publish for v12.0 happens at Phase 161 (merge of v12.0/json-ui-v2 → master).
- D-06 (`Fragment`/`Group` borderless container) explicitly NOT added — D-05 already resolves the double-card friction.
- D-10 (`#[handler(name)]` attribute) explicitly NOT added — route names live at the macro call sites; the new MCP tool reads from that single source.

Confirm CHANGELOG markdown is valid (no broken links, no orphan headings) and that the new entries are inside `[Unreleased]` (or whatever the working-section header is).
