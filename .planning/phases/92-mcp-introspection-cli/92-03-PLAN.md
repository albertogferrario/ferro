  <name>Task 1: Add projection_coverage MCP tool</name>
  <files>ferro-mcp/src/tools/projection_coverage.rs, ferro-mcp/src/tools/mod.rs, ferro-mcp/src/service.rs</files>
  <action>
  1. Create `ferro-mcp/src/tools/projection_coverage.rs`:
     - Define output types:
       ```rust
       struct CoverageReport {
           models: Vec<ModelCoverage>,
           coverage: CoverageSummary,
       }
       struct ModelCoverage {
           model_name: String,         // PascalCase (e.g., "User")
           has_projection: bool,
           projection_name: Option<String>,  // e.g., "user_service"
           projection_file: Option<String>,  // e.g., "src/projections/user.rs"
           primary_intent: Option<String>,   // e.g., "Browse" — from derive_intents
           intent_confidence: Option<f64>,
           suggestion: Option<String>,       // e.g., "ferro make:projection user --from-model"
       }
       struct CoverageSummary {
           total_models: usize,
           with_projections: usize,
           without_projections: usize,
           percentage: f64,
       }
       ```

     - `execute(project_root: &Path) -> CoverageReport`:
       a. Get all models via `list_models::execute()` — this returns ModelDetails with name, fields, table_name.
       b. Get all projections via `list_projections::execute()` — returns ProjectionInfo with name, service_name.
       c. Cross-reference: for each model, check if any projection's service_name matches the model name (case-insensitive, singular comparison). Match "User" model against service_name "user".
       d. For matched projections, reconstruct ServiceDef via render_projection's `reconstruct_service_def` (pub(crate) from Plan 02), call `derive_intents()`, extract primary intent name and confidence.
       e. For unmatched models, generate suggestion: `"ferro make:projection {snake_name} --from-model"`.
       f. Compute coverage summary.

  2. In `ferro-mcp/src/tools/mod.rs`, add `pub mod projection_coverage;`.

  3. In `ferro-mcp/src/service.rs`:
     - Add `ProjectionCoverageParams` struct (empty or with optional `include_intents: Option<bool>` defaulting true).
     - Register the tool:
       ```
       name = "projection_coverage",
       description = "Show which models have service projections and which need them. Includes derived primary intent for existing projections."
       ```
     - Implement by calling `tools::projection_coverage::execute(&self.project_root)`.

  4. Handle edge cases:
     - No models found → return empty report with 0% coverage
     - No projections dir → all models show has_projection: false
     - Projection exists but reconstruct fails → include projection name but primary_intent: None
     - Models in subdirectories (entities/) → list_models already handles this

  5. Add tests:
     - test_coverage_report_serialization: verify JSON output structure
     - test_empty_project: no models → 0 total, 0% coverage
     - test_suggestion_format: verify suggestion string format for uncovered models
  </action>
