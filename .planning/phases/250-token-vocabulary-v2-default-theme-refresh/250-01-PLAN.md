`ferro-theme`, bridge the motion/ring/display-font slots into the Tailwind utility
namespaces in `input.css`, honor `prefers-reduced-motion`, and regenerate the

vocabulary and the generated stylesheet that carries the new utilities. Phase 251
consumes these utilities; the fallback pattern is the SC1 "v1 themes render
identically" structural guarantee.

Output: `token.rs` (30 slots, v2 header), `input.css` (bridge + safelist +
reduced-motion), regenerated `ferro-base.css`, and a regression test pinning the
fallback + reduced-motion block into the committed CSS.
