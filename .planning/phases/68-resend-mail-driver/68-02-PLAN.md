<task type="auto">
  <name>Task 1: Add Resend transport and driver dispatch</name>
  <files>ferro-notifications/src/dispatcher.rs</files>
  <action>
  1. Add `ResendEmailPayload` struct (private, used only for serialization):
     ```
     #[derive(Serialize)]
     struct ResendEmailPayload {
         from: String,
         to: Vec<String>,
         subject: String,
         #[serde(skip_serializing_if = "Option::is_none")]
         html: Option<String>,
         #[serde(skip_serializing_if = "Option::is_none")]
         text: Option<String>,
         #[serde(skip_serializing_if = "Vec::is_empty")]
         cc: Vec<String>,
         #[serde(skip_serializing_if = "Vec::is_empty")]
         bcc: Vec<String>,
         #[serde(skip_serializing_if = "Option::is_none")]
         reply_to: Option<String>,
     }
     ```
     Add `use serde::Serialize;` import.

  2. Add `send_mail_resend()` method on NotificationDispatcher:
     - Takes `to: &str`, `message: &MailMessage`, `config: &MailConfig`
     - Build `from` string: use `message.from` if set, else format from `config.from_name` + `config.from`
     - Convert MailMessage to ResendEmailPayload:
       - to: vec![to.to_string()]
       - subject: message.subject.clone()
       - html: message.html.clone()
       - text: if html is Some, None (let Resend auto-generate); else Some(message.body.clone())
       - cc: message.cc.clone()
       - bcc: message.bcc.clone()
       - reply_to: message.reply_to.clone()
     - Get api_key from config.resend.as_ref().unwrap().api_key
     - POST to `https://api.resend.com/emails` with bearer_auth(api_key) and json(&payload)
     - Handle errors: map reqwest errors to Error::mail(), check response status, parse error body on failure
     - Log success with tracing::info

  3. Refactor `send_mail()`:
     - Extract existing SMTP code into `send_mail_smtp(to, message, config)` private method
     - Update `send_mail()` to match on `config.driver`:
       - `MailDriver::Smtp` → call `send_mail_smtp()`
       - `MailDriver::Resend` → call `send_mail_resend()`

  Do NOT use `Client::builder().no_default_headers()` — reqwest's default User-Agent header is required by Resend API (403 without it, per research pitfall #1).
  </action>
  <verify>cargo check -p ferro-notifications</verify>
  <done>send_mail_resend() compiles. send_mail() dispatches based on MailDriver. SMTP path unchanged. Resend path posts to API with correct payload.</done>
