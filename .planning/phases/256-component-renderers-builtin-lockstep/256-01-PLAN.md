## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| spec author props → rendered HTML | Prop values (name, price, image_url, stock_badge) are interpolated into HTML/attributes at SSR time; a hostile spec could inject markup. |
| tile button → hidden input (browser) | Tap increments a form field; field name is used in a `querySelector` attribute selector. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-256-01 | Tampering | render_tile prop interpolation | mitigate | `html_escape()` every string prop (name, price, field, image_url, stock_badge) before interpolation — existing atoms.rs pattern; numeric `price_cents`/`qty` need no escape. Test tile_escapes_categories retained. |
| T-256-02 | Tampering | color accent class | mitigate | `color: Option<Tone>` exhaustive match to full-literal border classes — no `format!("border-{}")`; unknown values are impossible (enum-enforced), closing the dynamic-class injection vector (SC-3). |
| T-256-03 | Tampering | initQtyButton field selector | accept | Field name sanitization (`replace(/["\\\]]/g,'')`) already present and untouched; the relaxation only removes the display-null early-return, adding no new injection surface. |
| T-256-04 | Tampering | render_grid row_weights | mitigate | Weights are `u8` formatted as `{n}fr` — numeric, no user string reaches the style attribute; no escape needed and no injection possible. |
</threat_model>
