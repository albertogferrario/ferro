    1. Add `"ferro-theme"` to workspace members in root `Cargo.toml`.

    2. Create `ferro-theme/Cargo.toml`:
       ```toml
       [package]
       name = "ferro-theme"
       version.workspace = true
       edition.workspace = true
       license.workspace = true
       description = "Semantic theme tokens and intent template schema for Ferro"
       repository = "https://github.com/albertogferrario/ferro"
       keywords = ["theme", "tokens", "ferro", "sdui"]

       [dependencies]
       serde = { version = "1", features = ["derive"] }
       serde_json = "1"
       thiserror = "2"

       [dev-dependencies]
       tempfile = "3"
       ```
       Note: thiserror = "2" (matching ferro-stripe, not "1.0" which is used by framework/ferro-projections — use the latest convention for new leaf crates).

    3. Create `ferro-theme/src/error.rs` — `ThemeError` enum with three variants:
       - `Io(#[from] std::io::Error)` — filesystem errors
       - `Json(#[from] serde_json::Error)` — JSON parse errors
       - `NotFound(String)` — theme directory not found

    4. Create `ferro-theme/src/token.rs` — Document the fixed token vocabulary (ferro-theme/v1, ~25 slots).
       This is a documentation module with constants for the token slot names (not enforced types — CSS handles resolution):
       - Surface tokens: `background`, `surface`, `card`, `border`, `text`, `text-muted` (6)
       - Role tokens: `primary`, `primary-foreground`, `secondary`, `secondary-foreground`, `accent`, `destructive`, `success`, `warning` (8)
       - Shape tokens: `radius-sm`, `radius-md`, `radius-lg`, `radius-full` (4)
       - Shadow tokens: `shadow-sm`, `shadow-md`, `shadow-lg` (3)
       - Typography tokens: `font-family-sans`, `font-family-mono` (2) — per discretion, start with font families only; Tailwind size scale stays as-is
       Total: 23 slots. Define as `pub const TOKEN_*: &str` constants for documentation/validation.

    5. Create `ferro-theme/src/template.rs`:
       - `IntentSlotTemplate` — `slots: Vec<String>` + `layout: Option<String>`, both `#[serde(default)]`
       - `IntentModeTemplates` — `display: IntentSlotTemplate` + `input: IntentSlotTemplate`, both `#[serde(default)]`
       - `ThemeTemplates` — 7 `Option<IntentModeTemplates>` fields (browse, focus, collect, process, summarize, analyze, track), all `#[serde(default)]`
       - All types derive `Debug, Clone, Serialize, Deserialize, Default`
       - Fixed slot vocabulary (per discretion): title, body, fields, actions, relationships, pagination, metadata, stats

    6. Create `ferro-theme/src/loader.rs`:
       - `Theme` struct with `pub css: String` and `pub templates: ThemeTemplates`
       - Derive `Debug, Clone`
       - `Theme::from_path(path: &str) -> Result<Self, ThemeError>` — reads `tokens.css` from directory, optionally reads `theme.json` (defaults to empty ThemeTemplates if absent)
       - `Theme::default_theme() -> Self` — returns embedded default CSS + empty templates
       - `const DEFAULT_THEME_CSS: &str = include_str!("../assets/default.css");`
