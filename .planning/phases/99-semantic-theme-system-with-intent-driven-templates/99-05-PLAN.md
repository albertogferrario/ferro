         ```css

         @theme {
           /* Surface tokens */
           --color-background: oklch(100% 0 0);
           --color-surface: oklch(97% 0 0);
           --color-card: oklch(95% 0 0);
           --color-border: oklch(90% 0 0);
           --color-text: oklch(15% 0 0);
           --color-text-muted: oklch(50% 0 0);

           /* Role tokens */
           --color-primary: oklch(55% 0.2 250);
           --color-primary-foreground: oklch(100% 0 0);
           --color-secondary: oklch(70% 0.05 250);
           --color-secondary-foreground: oklch(15% 0 0);
           --color-accent: oklch(65% 0.15 200);
           --color-destructive: oklch(55% 0.22 25);
           --color-success: oklch(55% 0.18 145);
           --color-warning: oklch(70% 0.18 80);

           /* Shape tokens */
           --radius-sm: 0.25rem;
           --radius-md: 0.375rem;
           --radius-lg: 0.5rem;
           --radius-full: 9999px;

           /* Shadow tokens */
           --shadow-sm: 0 1px 2px 0 rgb(0 0 0 / 0.05);
           --shadow-md: 0 4px 6px -1px rgb(0 0 0 / 0.1);
           --shadow-lg: 0 10px 15px -3px rgb(0 0 0 / 0.1);

           /* Typography tokens */
           --font-family-sans: ui-sans-serif, system-ui, sans-serif;
           --font-family-mono: ui-monospace, monospace;
         }

         @media (prefers-color-scheme: dark) {
           @theme {
             --color-background: oklch(12% 0 0);
             --color-surface: oklch(17% 0 0);
             --color-card: oklch(20% 0 0);
             --color-border: oklch(30% 0 0);
             --color-text: oklch(95% 0 0);
             --color-text-muted: oklch(60% 0 0);

             --color-success: oklch(60% 0.18 145);
             --color-warning: oklch(65% 0.18 80);
           }
         }
         ```

    2. Create `docs/src/features/themes.md`:

       **Sections:**
       - **Overview** — Theme = visual identity package (tokens.css + theme.json). Themes are CSS + JSON, no Rust needed.
       - **Quick Start** — `ferro make:theme myapp`, edit tokens.css, activate via ThemeMiddleware
       - **Token Reference** — Full table of all 23 semantic token slots:
         - Surface tokens (6): background, surface, card, border, text, text-muted
         - Role tokens (8): primary, primary-foreground, secondary, secondary-foreground, accent, destructive, success, warning
         - Shape tokens (4): radius-sm, radius-md, radius-lg, radius-full
         - Shadow tokens (3): shadow-sm, shadow-md, shadow-lg
         - Typography tokens (2): font-family-sans, font-family-mono
       - **Dark Mode** — Automatic via @media(prefers-color-scheme) and manual via data-theme="dark" attribute
       - **Intent Templates** — How to override intent layouts in theme.json. Slot vocabulary: title, body, fields, actions, relationships, pagination, metadata, stats. Example: override Browse to use card grid instead of table
       - **ThemeMiddleware Setup** — Per-request theme selection, resolver chain, fallback to default
       - **Multi-Tenant Themes** — TenantContext.theme field -> TenantThemeResolver -> per-tenant visual identity
       - **For Theme Creators** — tokens.css uses Tailwind v4 @theme syntax. Must process with Tailwind CLI for production. theme.json partial overrides — only override intents you want to change
