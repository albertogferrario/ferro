<objective>
Add ThemeMiddleware to the framework with resolver chain, task-local context, and CSS injection into the JSON-UI rendering pipeline.

Purpose: Enables per-request theme selection for multi-tenant white-labeling. ThemeMiddleware mirrors the existing TenantMiddleware pattern exactly -- resolver chain with first-match semantics, task-local storage, and framework re-exports behind a feature flag. The JSON-UI render pipeline injects the active theme's CSS into LayoutContext.head so the browser resolves semantic token classes.

Output: framework/src/theme/ module with ThemeMiddleware, ThemeResolver trait, current_theme() accessor, framework Cargo.toml/lib.rs wiring, and CSS head injection in json_ui/mod.rs.

  <action>
    Wire `current_theme()` into the JSON-UI render pipeline so the active theme's CSS is injected into LayoutContext.head.

    In `framework/src/json_ui/mod.rs`, in the `render_html` method, after the Tailwind CDN script and custom_head are appended to `head`, inject the theme CSS:

    ```rust
    // After existing head assembly (tailwind_cdn + custom_head):
    #[cfg(feature = "theme")]
    {
        use crate::theme::context::current_theme;
        if let Some(theme) = current_theme() {
            head.push_str(&format!("<style>{}</style>", theme.css));
        }
    }
    ```

    This injects the theme's CSS (which contains `@theme` directives) as an inline `<style>` tag. The Tailwind CDN script (loaded before it in the `<head>`) processes the `@theme` block at runtime, registering the custom properties and generating utility classes like `bg-primary`, `text-surface`, etc.

    The injection MUST happen:
    - AFTER the Tailwind CDN `<script>` tag (so CDN can process `@theme`)
    - AFTER custom_head (user's custom head content takes lower priority)
    - BEFORE plugin CSS assets (plugins should layer on top of theme)

    Use `#[cfg(feature = "theme")]` guard so json_ui still compiles without the theme feature.

    For tests: use the existing `render_html` test pattern. When theme feature is enabled, set up a theme scope with `with_theme_scope` wrapping the render call, verify the output HTML contains the theme's CSS within a `<style>` tag. When no theme is in scope, verify no extra style tag appears.
