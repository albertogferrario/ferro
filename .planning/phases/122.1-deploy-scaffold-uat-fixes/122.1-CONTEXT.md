<decisions>
## Implementation Decisions

### Bug 1 — Inline comment stripping
- **D-01:** `parse_env_example` strips trailing `\s+#.*$` from unquoted values.
- **D-02:** `#` inside quoted values (`"foo#bar"`) is preserved.
- **D-03:** `#` as first non-whitespace char after `=` with no leading space is preserved as literal.
- **D-04:** Unit tests cover all four comment scenarios.

### Bug 2 — DO app name hyphenation
- **D-05:** New helper `sanitize_do_app_name(pkg: &str) -> String` in `ferro-cli/src/templates/do.rs`.
- **D-06:** Transform: lowercase, `_` → `-`, strip non-`[a-z0-9-]`, collapse consecutive `-`.
- **D-07:** Wired into `AppYamlContext` construction in `commands/do_init.rs`.
- **D-08:** Unit tests: `mkmenu_ferro` → `mkmenu-ferro`, `MyApp_v2` → `myapp-v2`, `foo__bar` → `foo-bar`, `app.name` → `appname`.

### Bug 3 — Dev-default placeholder substitution
- **D-09:** Envs block replaces literal `value:` with `${KEY}` placeholder when value:
  - Contains `localhost`, `127.0.0.1`, or `0.0.0.0`
  - Starts with `file:` or is a relative path (`./foo`, `data/foo`)
  - Is empty or whitespace-only
- **D-10:** Exception: `*_PORT` keys with dev port literals (3000, 5173, 8080) keep literal values.
- **D-11:** When substituted, emit a comment above the entry: `# Override in DO App Platform secrets (was: <original>)`.
- **D-12:** `DATABASE_URL` is unchanged — already handled by the databases block.
- **D-13:** Unit tests cover each heuristic branch.

### Bug 4 — Worker filtering for test/dev binaries
- **D-14:** Exclude `[[bin]]` entries whose name starts with `test_`, `test-`, `dev_`, `dev-`, `debug_`, `debug-`.
- **D-15:** Exclude bins with `required-features` set (not typical for production workers).
- **D-16:** Exclude bins whose `src/bin/<name>.rs` path matches a test-like name.
- **D-17:** First `[[bin]]` matching the package name → web service; other non-excluded bins → workers.
- **D-18:** Unit tests: `gestiscilo` + `screenshot-worker` → 1 service + 1 worker; `mkmenu_ferro` + `test_parser` → 1 service + 0 workers.

### Claude's Discretion
- Internal module layout — planner can factor `sanitize_do_app_name` into a `deploy::naming` module if useful, or keep it inline in `do.rs`.
- Exact comment format for placeholder substitution (D-11) — keep consistent with existing comment style in the template.

</decisions>
