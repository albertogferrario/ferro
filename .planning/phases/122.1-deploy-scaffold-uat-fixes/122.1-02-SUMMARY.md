# Phase 122.1 Plan 02: DO app name hyphenation Summary

**sanitize_do_app_name helper converts Cargo package names to DO-compliant kebab-case, wired into do_init so `mkmenu_ferro` emits `name: mkmenu-ferro` in `.do/app.yaml`.**

## Performance

- **Duration:** 6 min
- **Tasks:** 2
- **Files modified:** 2

## Accomplishments
- `sanitize_do_app_name(pkg)`: lowercase, `_`→`-`, strip non `[a-z0-9-]`, collapse consecutive `-`
- do_init uses sanitized name for `AppYamlContext.package_name`
- Server bin entry renamed to sanitized name so workers filter still matches it
- New unit test: `sanitize_do_app_name_cases` (5 transformation cases)
- New integration test: `writes_app_yaml_sanitizes_package_name`

1. **Task 1: Add sanitize_do_app_name helper + tests** - `3b08d223` (feat)
2. **Task 2: Wire into do_init + integration test** - `2feb14b2` (feat)

## Files Created/Modified
- `ferro-cli/src/templates/do.rs` - Added `sanitize_do_app_name` pub fn + unit tests
- `ferro-cli/src/commands/do_init.rs` - Wired helper into `run` and `run_for_test`, renamed server bin, added integration test

## Decisions Made
- Rename server bin entry from raw `pkg` to sanitized `app_name` instead of modifying `build_workers_block` signature. Keeps `templates::do_spec` pure; the bin->server matching logic in the renderer is unchanged.

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 3 - Blocking] Server bin mismatch after sanitization**
- **Found during:** Task 2 (initial test run)
- **Issue:** `build_workers_block` filters bins where `bin.name != ctx.package_name`. After passing the sanitized name as `package_name`, the default server bin (named after the raw package, e.g. `mkmenu_ferro`) no longer matched and was emitted as a worker, breaking the new test.
- **Fix:** In `do_init::run` and `run_for_test`, rename any bin matching raw `pkg` to `app_name` before building the context.
- **Files modified:** `ferro-cli/src/commands/do_init.rs`
- **Verification:** `writes_app_yaml_sanitizes_package_name` now passes; `writes_app_yaml_with_region_and_envs` still passes.
- **Committed in:** `2feb14b2`
