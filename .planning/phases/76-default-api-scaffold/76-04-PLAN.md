**# REST API Scaffold**

Brief intro: One command generates a production-ready REST API with CRUD endpoints, API key auth, rate limiting, and auto-documented OpenAPI specs.

**## Quick Start**
```bash
# Generate API for all models
ferro make:api --all

# Generate for specific models
ferro make:api User Post

# Skip confirmation prompts
ferro make:api --all --yes
```

Then: add mod, register routes, migrate, generate key.

**## Generated Files**
Table of all files generated by `make:api` with descriptions.

**## API Key Authentication**
- Key format: `fe_live_...` / `fe_test_...`
- Generation: `generate_api_key("live")`
- Storage: prefix (unhashed) + hashed_key (SHA-256)
- Verification flow: extract from Authorization header → prefix lookup → constant-time hash compare → scope check
- ApiKeyProvider trait: how to customize
- Show raw key once at creation

**## API Key Management**
- Creating keys programmatically
- Revoking keys (set revoked_at)
- Key expiration
- Scope-based permissions (read, write, *)

**## Endpoints**
Standard CRUD patterns with examples:
- `GET /api/v1/{resource}` — List with pagination
- `POST /api/v1/{resource}` — Create
- `GET /api/v1/{resource}/{id}` — Show
- `PUT /api/v1/{resource}/{id}` — Update
- `DELETE /api/v1/{resource}/{id}` — Delete

Include curl examples for each.

**## OpenAPI Documentation**
- `/api/docs` — ReDoc UI
- `/api/openapi.json` — Raw spec
- Auto-generated from route registry
- How specs are built from RouteInfo

**## Rate Limiting**
- Default: 60 requests/minute per API key
- Customizing: modify the `RateLimiter::define("api", ...)` call
- Reference to rate-limiting.md for full docs

**## MCP Integration**
- CRUD tools: `crud_create`, `crud_list`, `crud_update`, `crud_delete`
- Usage examples for each tool
- How agents use these to manage data without UI

**## Customization**
- Adding custom endpoints beyond CRUD
- Modifying response format
- Adding relationships/includes
- Custom validation rules
- Custom scopes

Keep the tone scientific and minimalistic per project conventions. No marketing language.
