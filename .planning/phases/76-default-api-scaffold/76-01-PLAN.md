  <name>Task 1: Create API key module with generation, hashing, verification, and middleware</name>
  <files>framework/Cargo.toml, framework/src/api/mod.rs, framework/src/api/api_key.rs, framework/src/lib.rs</files>
  <action>
1. Add dependencies to `framework/Cargo.toml`:
   - `sha2 = "0.10"` (API key hashing)
   - `subtle = "2.5"` (constant-time comparison)
   - `utoipa = { version = "5", default-features = false }` (OpenAPI spec builder — added now so both tasks share one Cargo.toml edit)
   - `utoipa-redoc = { version = "6", default-features = false }` (ReDoc HTML docs UI)

2. Create `framework/src/api/mod.rs`:
   ```rust
   pub mod api_key;
   pub mod openapi;
   ```

3. Create `framework/src/api/api_key.rs` with:

   **Key generation:**
   - `generate_api_key(environment: &str) -> GeneratedApiKey` — generates key in format `fe_{env}_{43 random base62 chars}`
   - `GeneratedApiKey` struct with `raw_key: String`, `prefix: String` (first 16 chars for DB lookup), `hashed_key: String` (SHA-256 hex)
   - Use `rand::Rng` (0.8 API: `gen_range`) and `sha2::Sha256` for hashing
   - `hash_api_key(raw_key: &str) -> String` — standalone SHA-256 hash function
   - `verify_api_key_hash(raw_key: &str, stored_hash: &str) -> bool` — constant-time comparison using `subtle::ConstantTimeEq`

   **ApiKeyProvider trait:**
   ```rust
   #[async_trait]
   pub trait ApiKeyProvider: Send + Sync + 'static {
       async fn verify_key(&self, raw_key: &str) -> Result<ApiKeyInfo, ()>;
   }
   ```
   - `ApiKeyInfo` struct: `id: i64`, `name: String`, `scopes: Vec<String>`

   **ApiKeyMiddleware:**
   - Implements `Middleware` trait
   - Extracts API key from `Authorization: Bearer {key}` header
   - Resolves `ApiKeyProvider` from service container via `App::make::<Box<dyn ApiKeyProvider>>()`
   - Calls `provider.verify_key(raw_key)` — returns 401 on failure
   - Stores `ApiKeyInfo` in request extensions for downstream access
   - Optional `required_scopes: Vec<String>` field — if non-empty, checks key scopes against required

   **Error responses:**
   - Missing Authorization header → 401 `{"error": "API key required", "hint": "Include Authorization: Bearer <key> header"}`
   - Invalid key format → 401 `{"error": "Invalid API key format"}`
   - Key not found / verification failed → 401 `{"error": "Invalid API key"}`
   - Insufficient scopes → 403 `{"error": "Insufficient permissions", "required": [...], "provided": [...]}`

   **Tests:** Unit tests for `generate_api_key`, `hash_api_key`, `verify_api_key_hash`, and key format validation.

4. Add `pub mod api;` to `framework/src/lib.rs` and re-export key types:
   ```rust
   pub use api::api_key::{
       ApiKeyInfo, ApiKeyMiddleware, ApiKeyProvider,
       GeneratedApiKey, generate_api_key, hash_api_key, verify_api_key_hash,
   };
   ```

   Important: Do NOT add the openapi exports yet — Task 2 will add those.

<task type="auto">
  <name>Task 2: Create OpenAPI spec builder and documentation handler helpers</name>
  <files>framework/src/api/openapi.rs, framework/src/lib.rs</files>
  <action>
1. Create `framework/src/api/openapi.rs` with:

   **OpenAPI spec builder:**
   - `build_openapi_spec(config: OpenApiConfig, routes: &[RouteInfo]) -> utoipa::openapi::OpenApi`
   - `OpenApiConfig` struct: `title: String`, `version: String`, `description: Option<String>`, `api_prefix: String` (default "/api/")
   - Filter routes to only those matching `api_prefix`
   - For each matching route, build an `Operation` with:
     - `operation_id` from route name (if set)
     - `tag` extracted from path segment after /api/v1/ (e.g., "/api/v1/users/{id}" → tag "users")
     - `summary` auto-generated from method + path (e.g., "GET /api/v1/users" → "List users", "POST /api/v1/users" → "Create user", "GET /api/v1/users/{id}" → "Get user", "PUT /api/v1/users/{id}" → "Update user", "DELETE /api/v1/users/{id}" → "Delete user")
     - Path parameters extracted from `{param}` patterns in route path
   - Add security scheme for API key: `SecurityScheme::ApiKey(ApiKey::Header(ApiKeyValue::new("Authorization")))`
   - Use `utoipa::openapi::*` builder types: `OpenApiBuilder`, `InfoBuilder`, `PathsBuilder`, `PathItemBuilder`, `OperationBuilder`

   **Handler helpers:**
   - `openapi_json_handler(config: OpenApiConfig) -> impl Fn() -> HttpResponse` — returns closure that serves OpenAPI JSON (spec cached in OnceLock)
   - `openapi_docs_handler(config: OpenApiConfig) -> impl Fn() -> HttpResponse` — returns closure that serves ReDoc HTML via `utoipa_redoc::Redoc::new(spec).to_html()`
   - Both use `std::sync::OnceLock` to cache the generated spec (generated once on first call)

   **Auto-summary logic:**
   ```rust
   fn auto_summary(method: &str, path: &str) -> String {
       let resource = extract_resource_name(path); // last non-param segment
       match (method, has_path_param(path)) {
           ("GET", false) => format!("List {resource}"),
           ("GET", true) => format!("Get {resource}"),
           ("POST", _) => format!("Create {resource}"),
           ("PUT" | "PATCH", _) => format!("Update {resource}"),
           ("DELETE", _) => format!("Delete {resource}"),
           _ => format!("{method} {path}"),
       }
   }
   ```

   **Tests:** Unit tests for `auto_summary`, `extract_resource_name`, tag extraction, and spec building from mock RouteInfo data.

2. Add openapi exports to `framework/src/lib.rs`:
   ```rust
   pub use api::openapi::{build_openapi_spec, OpenApiConfig};
   ```
   Also re-export utoipa and utoipa_redoc for advanced users:
   ```rust
   pub use utoipa;
   pub use utoipa_redoc;
   ```

3. Run full framework checks.
