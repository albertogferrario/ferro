  <name>Task 1: Create make_api command with model detection and CRUD controller generation</name>
  <files>ferro-cli/src/commands/make_api.rs</files>
  <action>
1. Create `ferro-cli/src/commands/make_api.rs` with the `run` function:

   **Command signature:**
   ```rust
   pub fn run(models: Vec<String>, all: bool, yes: bool)
   ```
   - `models`: Specific model names to generate API for (e.g., "User", "Post")
   - `--all`: Generate API for all detected models
   - `--yes` / `-y`: Skip confirmation prompts

   **Model detection:**
   - If `--all`: scan `src/models/` for files containing `#[derive(DeriveEntityModel)]` or `#[derive(FerroModel)]`, extract model names
   - If specific models: validate they exist in `src/models/`
   - Use the same model parsing approach as `make_scaffold.rs` (walk `src/models/`, parse with syn)
   - Extract: model name (PascalCase), table name (from `#[sea_orm(table_name = "...")]`), fields with types

   **For each model, generate:**

   a) **API controller** at `src/api/{model_snake}_api.rs`:
   ```rust
   use ferro::*;
   use crate::models::{model_snake}::{self, Entity as {ModelName}};
   use crate::resources::{model_snake}_resource::{ModelName}Resource;
   use crate::requests::{model_snake}_request::{Create{ModelName}Request, Update{ModelName}Request};

   #[handler]
   pub async fn index(req: Request) -> Response {
       let page: u64 = req.query("page").unwrap_or(1);
       let per_page: u64 = req.query("per_page").unwrap_or(15).min(100);
       let paginator = {ModelName}::find().paginate(&ferro::DB::connection().await, per_page);
       let total = paginator.num_items().await.map_err(|e| HttpResponse::json(serde_json::json!({"error": e.to_string()})).status(500))?;
       let items = paginator.fetch_page(page - 1).await.map_err(|e| HttpResponse::json(serde_json::json!({"error": e.to_string()})).status(500))?;
       let resources: Vec<serde_json::Value> = items.iter().map(|m| {ModelName}Resource::from(m).to_resource(&req)).collect();
       let meta = PaginationMeta::new(page, per_page, total);
       Ok(ResourceCollection::paginated(resources, meta).to_response(&req))
   }

   #[handler]
   pub async fn show(req: Request, {model_snake}: {model_snake}::Model) -> Response {
       Ok({ModelName}Resource::from(&{model_snake}).to_wrapped_response(&req))
   }

   #[handler]
   pub async fn store(req: Request, form: Create{ModelName}Request) -> Response {
       let model = {ModelName}::create()
           {set_fields_from_form}
           .insert().await
           .map_err(|e| HttpResponse::json(serde_json::json!({"error": e.to_string()})).status(500))?;
       Ok({ModelName}Resource::from(&model).to_wrapped_response(&req).status(201))
   }

   #[handler]
   pub async fn update(req: Request, {model_snake}: {model_snake}::Model, form: Update{ModelName}Request) -> Response {
       let updated = {model_snake}.update()
           {set_fields_from_form_option}
           .save().await
           .map_err(|e| HttpResponse::json(serde_json::json!({"error": e.to_string()})).status(500))?;
       Ok({ModelName}Resource::from(&updated).to_wrapped_response(&req))
   }

   #[handler]
   pub async fn destroy({model_snake}: {model_snake}::Model) -> Response {
       {model_snake}.delete().await
           .map_err(|e| HttpResponse::json(serde_json::json!({"error": e.to_string()})).status(500))?;
       Ok(HttpResponse::json(serde_json::json!({"message": "Deleted"})).status(200))
   }
   ```

   Where `{set_fields_from_form}` generates `.set_field(form.field)` for each non-PK field, and `{set_fields_from_form_option}` wraps in `if let Some(v) = form.field { builder.set_field(v) }` for the update request.

   b) **API resource** at `src/resources/{model_snake}_resource.rs` (only if it doesn't already exist):
   - Uses `#[derive(ApiResource)]` pattern
   - Maps all model fields to resource fields
   - Implements `From<&{model_snake}::Model>` for the resource

   c) **API request types** at `src/requests/{model_snake}_request.rs` (only if it doesn't already exist):
   - `Create{ModelName}Request` with `#[request]` macro — all non-PK, non-auto fields required
   - `Update{ModelName}Request` with `#[request]` macro — all fields optional (partial updates)
   - Basic validation rules: `required()` for create fields, `string()` for text, `email()` for email fields, `integer()` for numeric

   **Field type mapping for request types:**
   - `String` → `String` with `required(), string()`
   - `i32/i64` → `Option<i32>/Option<i64>` with `required(), integer()`
   - `bool` → `bool` with `required(), boolean()`
   - `Option<T>` → `Option<T>` with `nullable()`
   - `DateTime` → `String` with `required(), string()`
   - Field named "email" → add `email()` rule

2. **Do NOT generate routes or API setup files in this task** — Task 2 handles that.

3. Print summary of generated files per model with clear messaging.

1. Add to `make_api.rs` the generation of API infrastructure files:

   a) **API route file** at `src/api/mod.rs` (only if it doesn't exist):
   ```rust
   // Auto-generated API routes
   pub mod {model_snake}_api;
   // ... one line per model
   ```

   b) **API routes registration** at `src/api/routes.rs` (only if it doesn't exist):
   ```rust
   use ferro::*;
   use crate::api::*;

   pub fn api_routes() -> GroupBuilder {
       group!("/api/v1")
           .middleware(ApiKeyMiddleware::new())
           .middleware(Throttle::named("api"))
           .routes([
               // {ModelName} CRUD
               get!("/{model_plural}", {model_snake}_api::index).name("api.{model_plural}.index"),
               post!("/{model_plural}", {model_snake}_api::store).name("api.{model_plural}.store"),
               get!("/{model_plural}/:{pk}", {model_snake}_api::show).name("api.{model_plural}.show"),
               put!("/{model_plural}/:{pk}", {model_snake}_api::update).name("api.{model_plural}.update"),
               delete!("/{model_plural}/:{pk}", {model_snake}_api::destroy).name("api.{model_plural}.destroy"),
           ])
   }
   ```
   If the file already exists, append new model routes inside the existing routes array (parse and modify, or instruct user to add manually with clear code snippet).

   c) **API docs routes** at `src/api/docs.rs` (only if it doesn't exist):
   ```rust
   use ferro::*;

   pub fn docs_routes() -> Vec<RouteDefBuilder> {
       vec![
           get!("/api/docs", api_docs).name("api.docs"),
           get!("/api/openapi.json", openapi_json).name("api.openapi"),
       ]
   }

   #[handler]
   pub async fn api_docs() -> Response {
       let config = OpenApiConfig {
           title: env("APP_NAME", "API"),
           version: "1.0.0".to_string(),
           description: Some("Auto-generated API documentation".to_string()),
           api_prefix: "/api/".to_string(),
       };
       let routes = get_registered_routes();
       let spec = build_openapi_spec(config, &routes);
       let html = utoipa_redoc::Redoc::new(spec).to_html();
       Ok(HttpResponse::html(html))
   }

   #[handler]
   pub async fn openapi_json() -> Response {
       let config = OpenApiConfig { ... };
       let routes = get_registered_routes();
       let spec = build_openapi_spec(config, &routes);
       Ok(HttpResponse::json_raw(spec.to_json().unwrap()))
   }
   ```

   d) **API key migration** at `src/migrations/` with timestamped name `m{YYYYMMDD_HHMMSS}_create_api_keys_table.rs`:
   - Table `api_keys` with columns:
     - `id` (PK, auto-increment)
     - `name` (string, not null) — human-readable key name
     - `prefix` (string(16), not null, indexed) — first 16 chars for fast lookup
     - `hashed_key` (string(64), not null) — SHA-256 hex
     - `scopes` (text, nullable) — JSON array of scope strings
     - `last_used_at` (timestamp, nullable)
     - `expires_at` (timestamp, nullable)
     - `revoked_at` (timestamp, nullable)
     - `created_at` (timestamp, not null, default now)

   e) **API key model** at `src/models/api_key.rs`:
   - Standard SeaORM entity with `#[derive(DeriveEntityModel, FerroModel)]`
   - All columns matching migration

   f) **ApiKeyProvider implementation** at `src/providers/api_key_provider.rs`:
   - Implements `ferro::ApiKeyProvider` trait
   - `verify_key`: lookup by prefix, constant-time hash comparison, check expiry/revocation
   - Registered via `#[service(ApiKeyProviderImpl)]` pattern

   g) **Rate limiter setup** — add to generated bootstrap or print instruction:
   ```rust

   ```
