```rust
// Polarity note: the `typeof … === 'undefined'` early-return below is the
// inverse of the guard used in `plugins/map.rs` §306. That site uses a
// positive `!== 'undefined'` wrapper because the guard sits inside a
// per-element callback; here it sits at the top of a setup function, so
// the early-return polarity matches every other sibling primitive.
pub(super) const SOURCE: &str = r#"
    // ── Lazy hero video promotion ─────────────────────────────────────────

    function setupLazyHeroes() {
        if (typeof IntersectionObserver === 'undefined') return;
        var els = document.querySelectorAll('video[preload="none"][data-lazy-hero]:not([data-lazy-hero-promoted])');
        if (!els.length) return;
        var groups = {};
        for (var i = 0; i < els.length; i++) {
            var m = (els[i].getAttribute('data-lazy-hero-margin') || '200px 0px').replace(/^\s+|\s+$/g, '');
            (groups[m] = groups[m] || []).push(els[i]);
        }
        for (var key in groups) {
            var io = new IntersectionObserver(function(entries, obs) {
                for (var j = 0; j < entries.length; j++) {
                    var e = entries[j];
                    if (e.isIntersecting && !e.target.hasAttribute('data-lazy-hero-promoted')) {
                        e.target.setAttribute('preload', 'auto');
                        e.target.setAttribute('data-lazy-hero-promoted', '1');
                        try { e.target.load(); } catch (_) {}
                        obs.unobserve(e.target);
                    }
                }
            }, { rootMargin: key });
            for (var k = 0; k < groups[key].length; k++) {
                io.observe(groups[key][k]);
            }
        }
    }
"#;
```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Page author → browser DOM | Tenant page sets `data-lazy-hero` attribute on `<video>` elements. The primitive reads `data-lazy-hero-margin` (a page-author-supplied attribute, not external input) and passes it as `rootMargin` to `new IntersectionObserver({…})`. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-182-01 | Tampering | `setupLazyHeroes` `rootMargin` parser | mitigate | A malformed `data-lazy-hero-margin` value (whitespace, invalid CSS margin syntax) could make the `new IntersectionObserver({rootMargin})` constructor throw `SyntaxError` (Safari is strictest). The implementation `.trim()`s the value via the inline regex `replace(/^\s+|\s+$/g, '')` so leading/trailing whitespace cannot trigger SyntaxError. A genuinely invalid CSS margin shorthand still throws — that throw aborts only the per-margin bucket, not the outer setup function, because each `new IntersectionObserver` is constructed inside a `for (var key in groups)` iteration and an uncaught throw there only abandons subsequent buckets. To prevent that, the executor SHOULD NOT wrap the constructor in try/catch (D-10 size budget + Anti-Pattern "no try/catch around the happy path"); page-author misuse of the attribute is acceptable failure mode. |
| T-182-02 | Denial-of-Service | `setupLazyHeroes` per-page execution | accept | A tenant could place thousands of `<video preload="none" data-lazy-hero>` elements with thousands of distinct `rootMargin` values to inflate observer count. Accepted as low risk: tenant pages are first-party content; the `querySelectorAll` and group-by-margin work is O(N) on N hero elements; observer count is bounded by distinct margin values (typically 1-2 per page). Real scenarios documented in CONTEXT.md describe 4 heroes per page. |
| T-182-03 | Information Disclosure | `<video>.load()` cross-origin | accept | `<video>.load()` triggers fetching the same `<source src="…">` URL the tenant page already authored. No new origin reached; no credential added. The `try { e.target.load(); } catch (_) {}` wrap (RESEARCH Pitfall 2) suppresses Safari's `InvalidStateError` without exposing throw details. No PII, no auth, no third-party reach. |

No auth, no authz, no untrusted input across a trust boundary, no PII handling, no cryptography. The primitive's only effect is to call browser-native APIs (`querySelectorAll`, `IntersectionObserver`, `setAttribute`, `<video>.load()`) on same-page elements the page author already declared.
</threat_model>
