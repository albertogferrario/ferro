<task type="auto">
  <name>Task 1: Fix make:api generated code templates</name>
  <files>ferro-cli/src/commands/make_api.rs</files>
  <action>
Fix three confirmed bugs in the code generation templates:

1. **DB::connection().await → DB::connection()?**: `DB::connection()` is sync, returns `Result<DbConnection, FrameworkError>`. Find ALL occurrences of `DB::connection().await` in the generated template strings and replace with `DB::connection()?`. Known locations:
   - Controller index handler (paginator line ~282)
   - Controller show/store/update/destroy handlers
   - Generated ApiKeyProviderImpl (~line 1216)
   Search for every `connection().await` in template strings.

2. **ResourceCollection type mismatch**: The generated index handler maps resources to `Vec<serde_json::Value>` then passes to `ResourceCollection::paginated()`. But `serde_json::Value` does not implement `Resource`. Fix by passing the typed resource vec directly:
   ```
   let resources: Vec<{pascal}Resource> = items.iter().map(|m| {pascal}Resource::from(m)).collect();
   Ok(ferro::ResourceCollection::paginated(resources, meta).to_response(&req))
   ```

3. **Verify all other generated handler patterns** — scan every generated handler template for correctness:
   - show: DB::connection()? not .await
   - store: DB::connection()? not .await, proper insert pattern
   - update: DB::connection()? not .await
   - destroy: DB::connection()? not .await
  </action>
  <verify>cargo fmt --all -- --check && cargo clippy --all --all-targets -- -D warnings && cargo test --all-features</verify>
  <done>All generated template strings use DB::connection()? (sync), ResourceCollection receives typed Resource vec, all handlers follow correct patterns. cargo build clean.</done>
</task>
