**Type conversion tests (json_to_sea_value or equivalent):**
- JSON string → sea_orm::Value::String
- JSON integer → sea_orm::Value for i32/i64 field types
- JSON float → sea_orm::Value for f32/f64 field types
- JSON bool → sea_orm::Value::Bool
- JSON null → appropriate null value
- Number where string expected (graceful handling)
- `Option<T>` field types — both value and null cases

**Placeholder generation tests:**
- Postgres format: $1, $2, $3
- SQLite format: ?, ?, ?

**Required field validation tests:**
- Missing non-nullable field → error with field name
- Nullable field → can be omitted
- Primary key field → not required (auto-generated)
- created_at/updated_at fields → not required (database defaults)

**Error message tests:**
- Unknown model → error lists available models
- Unknown column → error lists available columns
- Empty update data → error
- Delete without primary key → error

**Pagination edge cases:**
- page=0 → clamped to 1 or handled gracefully
- per_page=0 → uses default
- per_page > 100 → capped at 100

Adjust test names and assertions based on actual function signatures discovered when reading the source.
