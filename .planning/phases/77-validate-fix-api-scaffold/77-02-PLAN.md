Add a `#[cfg(test)]` module to crud_operations.rs with tests for the pure logic functions:

**Model metadata tests:**
- `find_model_case_insensitive` — "user" matches "User" model
- `find_model_not_found` — unknown model returns error with available model list
- `validate_column_valid` — known column name accepted
- `validate_column_invalid` — unknown column rejected with available columns in error

**Type conversion tests (json_to_sea_value):**
- `json_string_to_sea_value` — JSON string → sea_orm::Value::String
- `json_i64_to_sea_value` — JSON number (integer) with i64 field type
- `json_i32_to_sea_value` — JSON number with i32 field type
- `json_f64_to_sea_value` — JSON float with f64 field type
- `json_bool_to_sea_value` — JSON bool → sea_orm::Value::Bool
- `json_null_to_sea_value` — JSON null → appropriate null value
- `json_number_for_string_field` — number passed where string expected (should handle gracefully)

**Placeholder generation tests:**
- `postgres_placeholder_format` — returns $1, $2, $3
- `sqlite_placeholder_format` — returns ?, ?, ?

**Required field validation tests:**
- `missing_required_field_returns_error` — omitting non-nullable, non-PK field fails
- `nullable_field_not_required` — nullable field can be omitted
- `primary_key_not_required` — PK field auto-generated, not required in input
- `timestamp_fields_not_required` — created_at/updated_at skipped

**Error message tests:**
- `create_missing_field_error_lists_field` — error message includes the missing field name
- `update_empty_data_returns_error` — empty update data rejected
- `delete_missing_pk_returns_error` — delete without primary key value fails

Only fix issues that actually manifest during testing. If the existing code handles these correctly, document that in the test names.
