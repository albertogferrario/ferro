# Plan 35-01: CLI Seed Command

## Objective

Add `ferro db:seed` CLI command to run database seeders, completing the seeder workflow that was started with `make:seeder`.

## Context

### Current State

The seeder infrastructure is complete:
- `Seeder` trait and `SeederRegistry` exist in `framework/src/seeder/mod.rs`
- `ferro make:seeder` command scaffolds new seeders
- App template includes `db:seed` command handling in `main.rs.tpl`
- `Application` builder handles `db:seed` via `.seeders()` method

**What's missing:** The `ferro db:seed` CLI command that delegates to the app binary.

### Pattern Reference

Other CLI commands delegate to the app binary:
- `ferro migrate` → `cargo run --quiet -- migrate`
- `ferro migrate:rollback` → `cargo run --quiet -- migrate:rollback --step N`

### Files to Modify

| File | Change |
|------|--------|
| `ferro-cli/src/commands/db_seed.rs` | New - CLI command implementation |
| `ferro-cli/src/commands/mod.rs` | Add `pub mod db_seed;` |
| `ferro-cli/src/main.rs` | Add `DbSeed` variant and handler |

## Tasks

### Wave 1: Implement CLI command

- [ ] **1.1** Create `ferro-cli/src/commands/db_seed.rs`
  - Check `src/seeders` directory exists
  - Delegate to `cargo run --quiet -- db:seed`
  - Support `--class` flag for specific seeder
  - Show helpful error messages

- [ ] **1.2** Register command in `ferro-cli/src/commands/mod.rs`
  - Add `pub mod db_seed;`

- [ ] **1.3** Add command to CLI in `ferro-cli/src/main.rs`
  - Add `DbSeed` variant to `Commands` enum with `--class` option
  - Add match arm in `main()` to call `commands::db_seed::run()`

### Wave 2: Test and verify

- [ ] **2.1** Build and test
  - `cargo build` to verify compilation
  - Test `ferro db:seed --help` shows correct usage
  - Test error message when not in a Ferro project
