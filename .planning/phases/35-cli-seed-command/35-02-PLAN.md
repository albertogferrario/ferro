<objective>
Normalize all database-related CLI commands under the `db:` namespace for consistency.

Purpose: Currently migration commands use `migrate` / `migrate:*` prefix while other database operations use `db:*` prefix (`db:seed`, `db:sync`, `db:query`). This inconsistency hurts discoverability and violates the convention that database operations live under `db:`. The Claude commands already reference the normalized names (`db:migrate`, `db:rollback`), creating a mismatch with the actual CLI.

Output: All database CLI commands unified under `db:` namespace:
- `migrate` → `db:migrate`
- `migrate:rollback` → `db:rollback`
- `migrate:status` → `db:status`
- `migrate:fresh` → `db:fresh`
- `db:seed`, `db:sync`, `db:query` — unchanged
</objective>
