## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| classifier output -> turn core | `ToolSelection { tool_name, arguments }` is UNTRUSTED model output (prompt-injection surface). It must enter the identical `tools/call` pipeline as any direct call — no trust shortcut. |
| NL message -> tenant/auth | `tenant_id` is derived from the authenticated principal (param), NEVER from classified `arguments`. |
| confidence score -> write authorization | A high confidence is NOT user consent; destructive writes must still round-trip the Phase 220 confirmation gate. |
