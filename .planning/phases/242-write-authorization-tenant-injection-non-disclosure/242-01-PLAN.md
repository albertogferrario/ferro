<objective>
Fill the `tenant_column` slot in `derive_crud_plan` (currently always `None`) from
`svc.tenant_column`. This is the schema-side half of server-side tenant injection (CRUD-05,
SC#2): the serializable `CrudPlan` carries only the column NAME — the runtime `tenant_id`
value is bound later in the framework kernel (Plan 02). When a projection declares no tenant
column, the plan stays `None` (non-tenant projection — unscoped, matching the read path's
explicit non-tenant case, D-04).

Purpose: Without this, `execute_crud_plan` has no column to predicate on and tenant injection
cannot happen. This is the Wave 1 prerequisite that Plan 02 (framework kernel) consumes.
Output: `derive_crud_plan` returns `tenant_column: Some(...)` for tenant-scoped projections;
6 derivation unit tests proving Some/None for all three verbs.
</objective>
