```rust
/// Resolve every `$data` and `$template` expression in `spec.elements[*].props`.
/// Mutates in place. Infallible.
pub fn resolve_expressions(spec: &mut Spec);
```

Behavioral contract (from PLAN 01):
- `{"$data": "/slash/path"}` → JSON value at path, type preserved; missing → `Value::Null`.
- `{"$template": "literal {/path}"}` → `Value::String` with placeholders substituted; missing placeholder → empty.
- Malformed shapes (non-string value, sibling keys) → literal passthrough.
- Only walks `Element.props`; never touches `Spec.data`, `Spec.title`, `Spec.layout`, `Element.children`, `Element.action`, `Element.visible`.
- Single-pass — no recursion into resolved output.

| `spec.data` → `el.props` via `$data`/`$template` | Server-side substitution. No client participation. HTML escaping remains Phase 116 walker's responsibility. |

Resolver emits `Value::String` (for templates) or the source JSON value (for `$data`), all of which pass through the existing HTML escaping in Phase 116's walker. Severity: informational. |
