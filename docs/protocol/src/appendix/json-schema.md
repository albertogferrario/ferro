# JSON Schema Reference

All protocol types are defined as JSON Schema 2020-12 documents, generated from the Rust source types via [schemars](https://graham.cool/schemars/). Schemas are never manually edited -- the Rust types in `ferro-projections` are the single source of truth.

## Schema Generation

Schemas are generated by an integration test:

```bash
cargo test -p ferro-projections --test generate_schemas
```

This produces individual schema files and a combined bundle in `docs/protocol/schemas/`.

**Pipeline:**

```
Rust types (#[derive(JsonSchema)])
  -> schemars::schema_for!()
  -> JSON Schema 2020-12 files
  -> docs/protocol/schemas/
```

## Schema Versioning

Schema `$id` URLs use date-based versioning following the MCP pattern:

```
https://ferro-rs.dev/protocol/{date}/{type}.json
```

For example:

```json
{
  "$schema": "https://json-schema.org/draft/2020-12/schema",
  "$id": "https://ferro-rs.dev/protocol/2026-03-01/service-def.json",
  "title": "ServiceDef"
}
```

Date-based versioning signals a revision point without implying breaking-change semantics. New protocol versions produce new date-prefixed URLs.

## Validation

To validate a `ServiceDef` JSON document against the schema:

```bash
# Using ajv-cli (Node.js)
npx ajv validate -s docs/protocol/schemas/service-def.json -d my-service.json --spec=draft2020

# Using jsonschema (Python)
pip install jsonschema
python -c "
import json, jsonschema
schema = json.load(open('docs/protocol/schemas/service-def.json'))
data = json.load(open('my-service.json'))
jsonschema.validate(data, schema)
"
```

The `protocol.json` combined schema can be used for tooling that needs all type definitions in a single file, with cross-references resolved via `$defs`.
